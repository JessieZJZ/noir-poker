# PR70 原有界面译文的待办

本轮新增的商店介绍、海报标题、字幕、旁白按对应语言改写。App 界面采用 PR70 的真实安装版本，未在画面中替换文字。下列是实录中已见的问题，不能把这些原有界面译文标记为已通过母语审校。

| 语言     | 画面中已见的译文                                           | 含义/建议表达                                                                                  |
| -------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 西班牙语 | El Consejo aún no ha sido emitido.                         | 源文是“公共牌尚未发出”，可改为 Aún no se han repartido las cartas comunitarias.                |
| 西班牙语 | Tiene un fold, según la información antes de fold.         | 可改为 Te has retirado. El análisis se basa en la información disponible antes de tu decisión. |
| 葡萄牙语 | Você tem fold, de acordo com as informações antes de fold. | 可改为 Você desistiu. A análise considera as informações disponíveis antes da decisão.         |
| 葡萄牙语 | Verificação（行动日志）                                    | 扑克 check 应统一用 Passar 或 Check，与该版本的按钮术语一致。                                  |
| 俄语     | Ручная деятельность                                        | 源文是“本手动态”，可改为 Ход раздачи。                                                         |
| 俄语     | Перезагрузите эту руку                                     | 源文是“重打本手”，可改为 Переиграть раздачу。                                                  |
| 俄语     | Маленький слеп / Большой слепый                            | 扑克术语应为 Малый блайнд / Большой блайнд。                                                   |

这些建议不改动金额、牌面、位置或规则含义。界面代码修正并确定新录制版本后，需要重新构建 App 并替换对应界面画面；不能在旧视频上改字，冒充已经实现的 App 界面。
