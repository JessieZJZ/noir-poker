# 风格数量与合并复核

当前应用的4种是量化与盲评中的候选阵容，并非数量已经验收。用户指出合并过多后，停止继续收缩，先重新确认产品需要的丰富度。当前4种的测量结果与正在完成的第八轮保留，不能用于宣称恢复后的阵容也已通过。

## 合并中的问题

原17种同时包含范围与进攻程度、特定战术、相近的不同个人参考。去除缺乏证据的真人画像合理，但训练战术具有独立价值，并不要求它代表某个人一生的固定打法。

早期9种50手观察的分类较低，能说明当时实现和测试配置未形成足够鲜明的体验，不能单独证明这些概念必须删除。特别是过牌诱导、干燥面小持续下注、低价Float后进攻，机会率和条件行动率需要分别看。多数普通牌局行动相似，不等于特定机会下的策略也相同。

当前4种将战术放进共享策略，减少了可选择的训练对象。下一步不能把更少的标签、更高的分类比例当作产品本身更好的充分证据。

## 用户确定的八种方向

用户选择“约8种，优先保证主风格区分明显”。下一候选固定为包含均衡在内的8种：均衡、多街施压、宽松取值、范围纪律、强牌诱导、小注控池、听牌施压、延迟进攻。下表的小注持续作为小注控池内的明确路线，不单独计一类。恢复数量后仍需重新模拟与盲评，不继承旧4种的通过结论。

## 定位与需要重测的区别

这是一份讨论候选，不是已经恢复的代码或通过验收的阵容。

| 候选     | 独立训练目的                                     | 与最相近对象需要检验的区别                                   |
| -------- | ------------------------------------------------ | ------------------------------------------------------------ |
| 均衡     | 常规范围、尺度与价值/控池的基准                  | 作为对照，不声称最优或GTO                                    |
| 多街施压 | 较宽参与，选择合适的后街继续施压                 | 与听牌进攻区分，不能只有命中听牌才显特色                     |
| 宽松取值 | 愿意便宜跟入，成强牌后扩大价值投入               | 与多街施压比较主动性、承受价格及价值尺度                     |
| 范围纪律 | 选择起手牌与昂贵防守，入池后仍正常取值           | 与强牌诱导比较范围，不将两者都做成紧弱等待                   |
| 强牌诱导 | 在安全、足够深且有人可下注的局面保留对手进攻     | 与普通控池比较真实强牌的过牌/跟注路线，湿面和浅码保护另测    |
| 小注控池 | 较小投入获得信息与薄价值，管理中等牌力底池       | 与小持续下注比较所处街道、牌力和后续减速，不能仅统一缩小下注 |
| 小注持续 | 作为翻前主动方，在适合的干燥高牌面小尺度持续下注 | 与小注控池比较主动权条件及翻牌后街计划                       |
| 听牌施压 | 利用有继续潜力的听牌主动争夺，保留全下与价格边界 | 与多街施压比较听牌条件下的行动率，同时报告自然机会有多常见   |
| 延迟进攻 | 合适的低价有位置跟入后，在对方下一街示弱时争夺   | 与小注控池比较前街跟注后后街接管，不以无条件空气跟注制造特色 |

如果两个候选经过明确定位仍高度重合，再提出具体合并及证据。若特色只在极少机会出现，也必须如实报告，不能用条件下很大的百分比掩盖自然牌局体验不足。

## 后续验证边界

用户仍要求自然连续牌局，不增加情境玩法、不筛牌、不强制Hero参与。角色数量确认后，先固定每种的核心机会、行动与最近混淆对象，再做新牌序验证和匿名体验。维持公开信息决策、原赔率及合法动作边界，不为拉开差异而安排不合理操作。

旧4种28,800次完整执行、6对通过仅属于旧候选。恢复菜单、继承旧插画或沿用共同质量修复，都不能代替新阵容自己的模拟、迁移、本地化与跨端验证。
