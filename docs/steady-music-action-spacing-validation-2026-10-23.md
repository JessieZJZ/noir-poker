# 操作音乐与行动提示间距验收（2026-10-23）

操作音效播放时保持背景音乐音量，不再临时压低。微信原有的 0.45 音量与 650 ms 恢复定时器、共享控制器的降音量入口已移除。保留进入页面时的 2400 ms 渐入、恢复播放时的 700 ms 渐入，以及声音偏好和前后台暂停。Web 与原生仍共用同一音频实现和本地母带。

「轮到你行动」和右侧「牌力表」共同居于上方亮线与下方可见加注控件之间。宽屏固定提示和金额说明行高，手机及微信按滑块圆点的可见边缘计算间距。没有改变行动按钮高度或牌桌高度预算。微信实测上下间距均为 5.25 CSS px，Web 六种视口的差值不超过 1 CSS px。
