# 公开范围与连续行动策略

机器人与复盘共用 `src/engine/public-strategy.js`，输入仅为行动前的公开状态和行动者底牌。模型不读取其他玩家底牌、实际剩余牌堆、后续行动或最终赢家。

## 四类量分开估计

- **范围优势**：根据双方公开历史、位置与可见训练风格建立两组可能底牌，用假设公共牌比较整体权益与较强部分的占比。它与当前这手底牌的权益分开计算，不把翻前主动权直接当成范围优势。
- **尺度与继续范围**：对四分之一池、半池、四分之三池、一池和一点五池的合法筹码尺度分别估计弃牌、跟注、加注。较弱成牌跟注质量与听牌付费单列；对方已经全下时，弃牌概率和后续付款均为零。
- **隐含收益**：先比较当前跟注成本和可争夺底池，再按下一张改善机会、剩余有效筹码、改善后较弱牌愿意付款的机会与反向风险估计额外收入。当前跟注不保证看完后续公共牌。未来付款上界也受底池与有效筹码限制。
- **连续行动**：`bot-strategy-plan.js` 从真实公开历史识别过牌加注与上一街进攻，在每次行动时重新估计牌面、继续范围和价格。坚果同花听牌、组合听牌、薄价值、范围施压与抓诈唬有分别的条件；不预先承诺连打多街，不把拿着 AK/JJ 当作任何深度都必须接全下的理由。

普通／困难机器人接入新模型，简单难度保留原来的学习曲线。风格影响候选行动的选择，价格、合法加注权和筹码预算仍单独限制行动。计划不保存隐藏的未来动作，因此重打、下一手和重置不会携带旧意图。

## 模型的边界

这些是作者设定的范围先验、响应规则和有限抽样，既非求解器结果，也非职业牌手或真实用户的已测频率。抽样区间只描述抽样波动，不涵盖先验和响应模型可能出错的部分。

多人范围比较是成对近似；未来下注、不同可争夺筹码上限与多人响应也有近似。复盘只在证据足够的单挑局面表述整体范围优势，不将内部启发式收益当作已证明的长期 EV。既有完整后续模拟不会再叠加隐含收益，以免重复计入未来收益。

缓存有数量上限，随机流仅由公开快照确定。Web、原生 App 和微信共用该策略；微信 Worker 不依赖 `structuredClone`，以纯数据复制兼容较旧运行环境。

## 复盘与术语

复盘按实际牌面说明付费对象、听牌是否补中以及下一次决定的条件。补充说明保留独立翻译片段，在界面组成连贯段落，避免重复动作金额。玩法指南分别解释主动权、范围优势、继续范围、弃牌权益、隐含收益、反向隐含收益、坚果听牌、抓诈唬和过牌加注。
