# 复盘逻辑：输入、计算与结论

## 只站在决策当时分析

每次合法的玩家行动会先复制底牌、当前公共牌、位置、公开筹码、合法行动和此前行动，再执行选择。复盘分析只读取这个快照。最终结果用于显示净变化，不用于给这一步判对错。

因此“AA 全下后来被逆转”不会仅因输了就被判错；深筹码 QQ 直接全下、所有对手弃牌，也能在赢牌后讨论更正常的价值尺度。

## 按什么区分建议

`context.js` 区分超对、顶对及踢脚、非顶对、暗三条、成牌来自公共牌等情况；同时提取公共牌对子、同花色密度、顺子连接、未弃牌人数、位置、尚可行动人数、有效剩余筹码、当前 SPR、历次加注与连续跟注。

有效剩余筹码取玩家与最深的仍在局中对手之间的可覆盖额度；不表示玩家能与每位对手都争夺相同金额。分池资格在权益模块单独计算。当前 SPR 用当前剩余筹码除以当前底池，是情境描述，不冒充标准“翻牌开始时 SPR”。

`analysis.js` 的分支包括：免费过牌时弃牌、弱牌早位入池、强牌深筹码过大全下、过贵跟注、强牌平跟或弃牌、多人湿润牌面顶对、价值过牌、缺乏支持的大额下注、连续跟注和公共牌成牌。

输出包括具体数字、触发依据、合法候选行动、练习重点和后续条件。一个分支只提出候选练习路线，不声称计算了最优下注尺度。

## 跟注价格与边池

先按当前投入建立各池，再投影本次跟注后的各池。只统计玩家有资格争夺的池，扣除独有超额投入的退还差额。

```text
有效成本 = 本次跟注额 - 跟注后应退还额 + 当前应退还额
盈亏平衡权益 = 有效成本 / 跟注后可争夺底池
```

如果已有底池 100、对手下注 50、需要跟注 50：最终可争夺 200，门槛是 `50 / 200 = 25%`。如果短筹码没有资格争夺更高的边池，那些金额不会被拿来降低门槛。

权益按每个池的资格分别比较；平分计算份额，未被跟注退还不是底池收益。这里的权益是预期获得可争夺底池的比例，不只是赢牌次数。

## 两种对手模型

1. 随机模型：未见牌中所有合法对手底牌组合等权。
2. 行动加权模型：翻牌前主动加注者偏向较强起手牌；翻牌后根据目前的成牌和部分听花潜力增加权重。未加注者通常较宽。

这两种模型用于比较假设敏感性，**不是范围置信区间**。权重只是可修改的启发式，没有按真实电脑策略反推精确范围，也没有完整按每一街的下注金额更新贝叶斯范围。多人的加权模型按玩家顺序、剔除已分配牌之后条件抽样；它不是完整的联合范围求解。

河牌单挑时，已知 7 张牌，剩余 45 张，完整枚举 `45 × 44 / 2 = 990` 种对手底牌组合。枚举消除组合抽样误差，但不会消除范围假设误差。

其他场景每种模型默认抽样 600 次，使用由决策快照生成的固定种子，重复打开复盘得到相同结果。Worker 不可用时降为 180 次。界面显示实际次数及保守误差保护带；判明显缺少权益支持时也保留这个保护带，避免小样本极端结果被当成确定事实。

## 听牌数

枚举下一张未见牌，识别能够直接形成更强顺子或同花、且底牌实际参与的牌。顺花共用的候选牌只计一次，已经成顺子不会再标成顺子听牌。

例如 `A♠ K♠`，翻牌 `Q♠ J♠ 2♥`：9 张同花候选、4 张 T 顺子候选，其中 T♠ 重合，合计 **12** 张，下一张比例 `12 / 47`。这些是直接成牌候选，**不保证成牌后获胜**，不是已扣除对手更强牌的净 outs。

只展示下一张的比例；不把翻牌到河牌两张机会的成牌概率当成只付一次跟注即可获得。

## 已知边界

- 不读取真实对手底牌、剩余牌序、最终赢家。
- 不完整求解后续下注、对手弃牌率、隐含赔率、反向隐含赔率或牌力实现率。
- 展示的跟注 EV 只针对当前金额和给定范围，不是整条未来策略的 EV。
- “重点改进”表示规则成本明确或在两种模型和误差保护下价格明显欠缺；其他战略判断保留为“值得讨论”。
- 当前没有大模型 API、训练数据库或 GTO 求解服务。扩展时应保留可验证数字、输入隔离和结论强度说明。

测试位于 `review-check.test.js` 和 `review-context.test.js`，覆盖结果隔离、确定性、合法建议、分池成本、公共牌平分、听牌去重和价值牌误判。
