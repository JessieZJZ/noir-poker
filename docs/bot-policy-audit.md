当前实现分为范围与公开行动估计、条件决策和风格/情绪控制，但没有部署求解器生成的 GTO 翻前策略表。`starting-range.js` 是按实际组合加权的起手牌排序启发式；位置、价格、有效筹码与行动历史在决策时继续参与判断。翻后计算范围加权权益及分尺度收益估计，没有单独使用 HS、NP、PP 分解的 EHS。权益不是动作收益，模型仍受自编范围先验和响应概率误差影响。性格参数及专属线路已经实现，不能据此声称职业选手等效强度或数学最优。

普通/困难常规权益预算分别是 28/52 次，翻前全下或高承诺情境默认提高至 512 次；范围/响应策略另有自己的有界抽样预算。1–3 秒是展示节奏，不是计算耗时测量。查表、抽样次数或行为树的形式都不能单独保证没有可利用漏洞，仍以完整对抗、独立复现和真实客户端性能证据判断。

## 本轮策略改动

现有位置/行动线范围、分尺度收益估计和八种风格继续作为基础。本轮补上受样本量约束的公开行为观察，避免把连续无差别施压仍长期解释成极窄强牌范围，也避免向持续跟注者高估诈唬的弃牌机会。

- 每个座位保留最近 64 手的公开行动计数，不记录对手底牌、实际输赢或未来牌。只在本手结算后追加；行动前快照冻结此前记录，重打撤回并重新结算一次，换盲注重新开始。
- 至少 8 手后才把翻前入池、加注和大额投入频率混入范围先验，使用相当于 24 手的先验收缩。大额投入按本局大盲倍数识别，不用固定筹码值；一次全下不等于已经知道对手在诈唬。
- 至少 8 手且 16 次翻后行动后，频繁下注/加注才逐步提高弱牌施压在完整行动线中的可能性；仍保留价值牌，继续比较价格和多人响应风险。
- 至少 8 手且 12 次真正面对下注后，跟注/弃牌观察才有限地修正分尺度继续概率。免费过牌不算愿意付费的证据；这只是全局倾向修正，不是已校准到每种尺度的精确概率。原有牌力、听牌、价格和大尺度选择性仍生效，不能把一次跟注推广成任意额度都会跟。
- 简单难度不采用这些新增观察。风格的条件线路和参数仍分别保留，不能为了抵抗全下就让所有风格无差别接注。
- 牌谱复查又定位到旧固定范围门槛与公开范围估计冲突的部分 AJ/AQ 防守。新增的豁免只适用于有足够持续宽加注记录的单挑、没有待响应者、当前投入不超过原始后手 20% 且保留后续筹码的情境；对权益另作位置相关的实现折扣和余量。它只撤去旧入池否决，不绕过价格、合法性和价值加注检查，不把所有强起手牌改成强制跟注。

对手复盘只在实际决策记录带有匹配的当前策略依据时解释观察影响，例如结合此前多手大额加注保留更多非顶级起手牌。旧记录、外部脚本动作和不匹配的理由不补写这种动机。说明以行动者为主体，不加入对行动者下一步的教学建议。新文案覆盖全部 11 个 Web/App 语言；小程序继续使用中文。

## 对抗范围与动作定义

- 覆盖五、六、七、八、九人起始牌桌，并补查真实淘汰后的二至四人残局。
- 五类对手脚本：任何底牌都持续最小合法加注、半池加注、满池加注、全下，或持续跟注/免费过牌。不能加注时仅依法跟注或过牌，不凭测试需要重新开放加注权。
- 半池/满池按产品同一 `fractionRaiseTo` 计算：在当前最高下注上，增加跟注后底池的对应比例，再按本局面额和合法上限取整。到达上限的动作仍记录为实际全下，不能当作无限次固定尺度。
- 记录普通、困难难度作为主要防漏洞评估；简单难度及单一风格、情绪变化另列压力测试。混合阵容轮换全部八种风格，不能沿用只包含四种风格的旧矩阵。
- 主要定深度样本每手各座恢复 100BB，重新构造游戏，不继承淘汰标记；默认只在每个独立块内延续公开观察和情绪，每个新块重置记忆，`--memory=none` 可另查冷启动。生产连续对局另外评估买入、补码、有效深度和短桌，不能混算两种盈亏。
- 固定脚本不读取底牌、公共牌牌力、机器人私有决定或未来牌。机器人使用生产默认计算预算，跳过的只有展示等待。

## 统计与验收

主要结果是玩家净收益 BB/100，同时报告赢到底池比例、盈利手比例、摊牌手数及摊牌获池率。退款不算获胜；获池次数多不代表净收益为正。

每个配置由多个独立牌序块构成，块内按钮轮换。洗牌、策略和展示等待分别使用随机流；同配置前后版本使用相同发牌种子作配对，但后续策略行动不会被强行固定。配置、源码摘要和每手发牌摘要写入报告，恢复任务时不能混用新旧源码。

初期开发矩阵为每格 8 块 × 25 手，专门定位问题，不作为长期结论。正式留出至少每格 32 块 × 100 手，固定一批新种子后开始；若收益区间仍跨零，结论为未确定，并按事先独立分组追加样本，不能反复抽牌到显著为止。改动后重新调参用过的牌序不能继续充当留出集。

区间按独立牌序块做等长块 bootstrap，报告点态 95% 区间及块数。脚本的稳定正收益需在新牌序中复现；上界仍为正时不能宣称已经排除盈利漏洞。多配置比较、牌序共享和自然情绪样本不足分别注明。即使五种脚本全亏，也只排除了所测条件下这些固定套路，没有证明任意玩家都不能盈利。

每一步验证合法动作、非负整筹码和筹码守恒；另用保存的原始行动独立重放，核对发牌、结算和机器人行动前公开快照。复盘必须解释实际采用的策略证据，保留八种风格差异，不能用通用的“怕更大牌”替代原因。

```sh
# 开发诊断；正式评测改变种子、块数和每块手数，另建输出目录。
node scripts/measure-bot-exploits.mjs --blocks=8 --hands=25 --output=.artifacts/bot-policy-audit/development
node scripts/audit-bot-exploits.mjs .artifacts/bot-policy-audit/development
# 相同配置/牌序的版本对比；协议或抽样配置不同会拒绝合并。
node scripts/compare-bot-exploits.mjs .artifacts/bot-policy-audit/before .artifacts/bot-policy-audit/after
# 实际连续对局，保留引擎淘汰与玩家补码次数；达到手数上限另列为截断。
node scripts/measure-bot-sessions.mjs --sessions=8 --cap=200 --output=.artifacts/bot-policy-audit/product-sessions
node scripts/audit-bot-sessions.mjs .artifacts/bot-policy-audit/product-sessions
node scripts/summarize-bot-sessions.mjs .artifacts/bot-policy-audit/product-sessions
# 仅分析完整已冻结的开发/留出牌谱，逐手统计风格，并按块抽查对手复盘。
node scripts/analyze-bot-exploit-traces.mjs --input=.artifacts/bot-policy-audit/development --output=.artifacts/bot-policy-audit/development-review
# 仅修改复盘文字时，同一份冻结打法牌谱另核当前复盘源码，保留独立 reviewDigest。
node scripts/analyze-bot-exploit-traces.mjs --input=.artifacts/bot-policy-audit/development --review-root=src/review --output=.artifacts/bot-policy-audit/development-current-review
```

定深度脚本支持 `--players=5,6,7,8,9`、`--policies=minimum,half-pot,pot,all-in,call`、`--difficulties=normal,hard`、`--profiles=mixed` 或八种风格的单一 ID、`--emotions=off`、`--memory=block|none`、`--seed=` 和 `--engine=/绝对路径/src/engine/poker.js`。连续对局脚本支持相同人数、套路、难度、情绪、种子和源码参数，使用混合阵容，另有 `--sessions=`、`--cap=`。断点保留每个完整块/局的结果和 gzip 原始牌谱；临时文件不会计入完成样本。

## 当前证据

第一版开发基线已完成五至九人 × 普通/困难 × 五种固定套路，共 10,000 手；独立重放核对了 141,499 个实际动作和 111,780 个机器人行动前快照。它使用初版不延续记忆的测试协议，不能改名成后来加入块内记忆的版本。50 格的玩家平均收益均为负，但部分 95% 区间跨零，不能据此宣称排除了长期盈利。

新增策略的开发矩阵、正式新牌序留出、单一风格/情绪压力、连续对局及客户端验证仍在推进。连续对局工具的初步冒烟已经通过原始行动重放，并实际覆盖了淘汰后的二、三、四人局；这不代替完整连续对局样本。所有失败、被替换的候选版和构造情境与自然样本分别保留。

候选三另完成了 10,000 手与同协议旧版的配对开发对照，独立重放核对 141,997 个动作和 112,186 个机器人行动前快照。全部 50 格玩家样本均值为负，11 格区间仍跨零；19 格的开发配对差值区间低于零，没有差值区间完全高于零的格子。每格只有 8 个牌序块，这些仍是开发观察。

候选三的真实连续对局开发样本另有 400 局、13,585 手，全部自然结束；重放覆盖二至九人残局及真实补码，独立核对 151,589 个动作。六人普通桌持续全下的 8 局中夺冠 4 局、净赢 400BB，但终局平均收益的近似 95% 区间为每局 −206.3 至 +306.3BB，尚不能认定稳定盈利；已登记独立新种子复查。其余格子也保留原始收益、补码与夺冠记录，不能用合计亏损掩盖个别配置。

候选四完成另一次 10,000 手开发矩阵，独立核对 142,147 个动作和 112,276 个机器人行动前快照。50 格玩家收益均值仍全为负，9 格区间跨零；同协议配对中 18 格的收益差值区间低于零，没有完全高于零的格子。这些仍是开发样本。独立新种子的六人普通持续全下复查另有 64 局、1,851 手，全部自然结束：夺冠 11 局，玩家净亏 15,700BB、买入收益率 −66.24%，没有复现先前 8 局的小样本盈利。两次样本与不同源码版本分别保留，不混成同一次测量，也不推导任意策略都无法盈利。

对候选三的全部 112,186 次机器人决定做风格与条件统计，并在每个牌序块末手抽查 4,522 条对手解释，其中 2,092 条包含公开观察依据；关键词筛查没有发现对行动者的建议语，隐藏牌/未来牌污染抽查未改变解释。这不等于人工盲评或全面语义验收。额外标出的 143 次强牌弃牌是待核条件命中，含相同牌序的不同套路，不能计为 143 个独立牌局。候选四用相同公开快照与随机检查值回放，143 次旧决定均可重现，其中 26 次在新增有边界的观察防守下转为继续；完整新对局矩阵另行运行。

候选四完整开发矩阵的风格/复盘审查覆盖 112,276 次决定、4,522 条解释和 266 次隐藏信息污染检查。剩余 117 次强牌弃牌筛查命中按首要边界拆为：92 次仍有多位对手、16 次跟注超过原始后手 20%、5 次未通过权益实现折扣与余量、4 次不足 8 手观察；这些是边界归因，不是对每次弃牌收益正确性的证明。八种风格的总体入池率相对旧版增加约 0.2–0.8 个百分点，翻前加注率基本不变，条件指标及分母仍单独保留。

另逐条阅读了八种风格各两条分层抽样解释，发现听牌过牌和全下跟注有重复句。仅修改复盘文字后，用相同 4,522 条记录重新生成解释：141 条缩短，4,381 条不变，共减少 2,985 个字符；实际决定与行动标题保持一致，建议语筛查仍为零、266 次隐藏信息污染检查仍通过。复盘修订有独立摘要，不改写冻结打法版本，也不称作真人或 AI 盲评。

客户端证据也按版本区分：候选三通过 1,304 项单元、桌面/手机网页 8 项专项，以及微信实际包内决定与复盘展示 2 项构造情境检查；iOS 编译成功。候选四更改策略后需要重新构建与验收，以上不能自动作为候选四的客户端通过记录。当前正式新牌序计划为每版本 160,000 手，参数与源码摘要在本机登记后开始，未用开发牌序替代。
