# 后位争夺与均衡：战术线路与自然互动复核

用户指出构造局面仍难识别后，已另做[风格成组对照重评](style-contrast-retest-2026-10-24.md)，单独统计自然与构造辨识。本页原始协议、评分和失败不覆盖。

本轮修复了风格战术已被选中、又被通用随机判断取消的问题，并补齐合理的后街继续与停手机制。最终候选为本地冻结的v5，保留全部八种风格、自然发牌与原玩法。自然互动密度和稳定辨识尚未达到预设目标，局部分支修复不能写成整体验收通过。上一轮原始结论见[定向打磨记录](style-refinement-2026-10-24.md)。

## 修改及边界

- 后位争夺：在真实有位置、实际在池的对手已过牌时，统一选择取值、听牌施压、后门潜力试探或延迟进攻。自己的翻牌下注遇到有利转牌时可继续，没有改善的纯空气牌重新评估并停手。不能把第三方下注当作自己的前一枪，也不向尚未行动的对手强行试探。
- 均衡：组织常规价值下注、适当持续下注、合适价格的中等成牌防守与控池。河牌对手连续示弱时，合适的中等成牌保留小额薄价值。原翻前主动开池方式保留，均衡不是每手被动跟到底。
- 每条线路只进行一次行动抽样。合法动作、全下、公开价格与非价值累计投入预算继续单独约束。强价值牌在低底池筹码比下交回原承诺选择器，避免新线路把本可正常投入的强牌强制变成过牌。

决策只读行动前的本人底牌和公开牌面、位置、历史与范围权益估计。未改规则引擎、发牌、筹码结算、六种其他风格的选择器或翻前承诺逻辑，没有加入产品情境模式。新增的线路轨迹用于本地诊断，不是玩家界面文案。

另有600次整桌当前策略冒烟，覆盖5–9人、两种难度、关闭/细微/明显情绪，并轮换五种配置情绪。该轮包含八种风格，但不是每种风格的完整独立矩阵，也不是情绪随历史演变的长期测量。

## AI自主互动复核

第一阶段绑定冻结v3，三位独立AI评审各完成三种匿名风格20手自然牌局和6个构造局面，共180手自然、18个构造局面、410次事前写理由的自主Hero行动。自然内各代号连续携带筹码，淘汰与短筹码轨迹保留。原稿冻结后才发相同八风格菜单，允许不确定与空分，不把猜对当体验好。这是AI体验，不是真人验收。

| v3实际身份 | 三位自然体验分   | 三位训练价值分 | 首选识别 |
| ---------- | ---------------- | -------------- | -------: |
| 均衡       | 4 / 3 / 4        | 3 / 2 / 4      |      0/3 |
| 后位争夺   | 4 / 3 / 无法判断 | 3 / 2 / 2      |      1/3 |
| 范围纪律   | 3 / 3 / 3        | 2 / 3 / 3      |      1/3 |

合计2/9，未达到预设至少7/9。共同反馈是目标直接翻后交手太少，第三方常是主要进攻者。评审能够解释部分取值、跟注与停手线路，但没有足够体验目标面对Hero反加或连续施压的响应。自然与构造结果分开，未改变失败原分数。

最终v5另行安排三位各两种匿名风格10手自然牌局和4个构造局面。构造只固定第一次目标行动的策略随机值0.4，权益照常计算，用于观察前门听牌与后门潜力分支，不测自然频率。此阶段结果另列，不能替换v3评分或声称为全新无背景的评审。

v5追加复核实际完成60手自然牌局、12个构造局面，共168次自主Hero行动，其中自然136次、构造32次，接口错误0。自由原稿先冻结，再发与第一阶段相同的中性问卷。评分如下：

| v5实际身份 | 三位自然体验分 | 三位训练价值分 | 首选识别 |
| ---------- | -------------- | -------------- | -------: |
| 均衡       | 3 / 3 / 3      | 2 / 3 / 2      |      0/3 |
| 后位争夺   | 3 / 3 / 3      | 3 / 3 / 3      |      0/3 |

构造的后位争夺六次首次响应均实际下注，分别进入真实听牌施压或后门试探，均衡六次首次响应均过牌。部分后续有第二枪、停手或面对Hero主动下注的跟弃，证明分支能实际运行，评审也有可选择的价格。但这是固定首次随机值、同一牌面骨架的诊断，不能替代自然辨识。自然阶段仍有不少合理翻前退出、多人过牌和第三方主导的下注，目标交手覆盖很窄。

v5首选合计0/6，未达到自然体验/训练价值至少4分的目标。两阶段使用不同发牌与筹码轨迹，且第二阶段复用同三位AI，不作分数升降的同牌因果结论，不用定向分支改善覆盖失败的自然评分。两阶段共240手自然、30个构造局面、578次自主Hero行动，全部保留分阶段计数。

本轮技术修复与策略边界已验证，整体自然体验没有达标。下一步的实质问题是常见多人底池中的合理争夺、目标对Hero下注的应对及这些机会的出现频度。单一窄分支的重复抽样或更强的随机进攻不足以解决已观察到的交锋覆盖问题。固定小样本复核到此结束，未追加到出现满意结果。

## 失败保留与测量修正

v1/v2各3200次开发执行发现：目标座位与按钮同步移动，短样本在7–9人桌偏向盲位和前位。修正排位后，20手内Hero及目标均覆盖每个位置至少向下取整的20/人数次。v3重新执行3200次，旧结果只作探索材料保留。v4修复低底池筹码比强价值牌误被线路封顶拦住的问题，v5扩展合理的有位置取值、听牌、后门潜力和选择性薄价值。

所有候选、失败、初次测试快照不匹配、测量更正、自由报告与接口原始记录都保留。没有只展示最好轮次、回填评分、追加到通过，或用定向局面替代自然体验。
