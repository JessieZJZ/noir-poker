# 风格成组对照重评

本轮按用户提出的质疑重新设计测量，固定测试`e8c6583`的机器人实现，不在评审过程中修改打法。此前[线路复核](style-lines-validation-2026-10-24.md)的0/6是自然与构造体验后的综合首选命中数，原结果保留。本轮把两类辨识分开，不能直接把分数变化当作策略改善。

## 协议与盲法

执行前固定源码、局面、种子、样本量与评分口径。三位新启动、没有历史任务上下文的独立AI评审，先各完成两个匿名目标各10手自然牌局，再各完成24个构造局面。自然合计60手，构造合计72次执行。它们通过公开行动接口自主选择Hero动作，逐次事前写理由，属于文本决策体验，不是真人试玩或界面操作验收。

自然阶段为5人、进阶、无情绪的连续筹码练习，目标以外的陪测也使用同一冻结版本。目标淘汰或Hero出局导致的新练习保留记录。自然原稿哈希冻结后才解锁构造阶段。两阶段使用独立匿名代号与映射，不能据代号推断同一身份。全部自由原稿冻结后才统一给出八风格菜单，允许重复标签、未知和空分。每阶段首选辨识预设目标为至少5/6，体验与训练价值目标为至少4/5。

自然单独评自然体验，构造单独评线路连贯性。两阶段分别评价训练价值与标签辨识，同样的三位评审参与两个阶段，因此它们不是两组统计独立的评审人群。自然分数在构造结束后依据已冻结的自然原稿填写，仍不能排除跨阶段学习对分类理解的影响。未筛牌、重打、补到满意或反馈正确答案。

构造组包含六类配对，每类两个条件，每种匿名风格各经历一次：

| 配对     | 主要改变的条件                                        |
| -------- | ----------------------------------------------------- |
| 开池位置 | 同一起手牌，前位未开启底池/按钮未开启底池             |
| 争夺主动 | 同一牌面与手牌，Hero过牌/Hero已下注                   |
| 转牌延续 | 同一合法前街下注跟注历史，新转牌带来真实听牌/没有改善 |
| 成牌强弱 | 同一公开牌面，目标顶对强踢脚/目标中等口袋对子         |
| 跟注价格 | 同一目标中等对子，面对较小下注/较大下注               |
| 底池人数 | 同一目标顶对，单挑/三人实际跟入后都过牌               |

共12个初始条件，跨两种风格和三位评审重复，不能称为72类独立局面。所有前置动作标为setup，不计Hero自主动作，也不称为机器人自主选出的完整前街线路。位置改变同时改变合法的已行动/待行动历史，增加真实跟入者也会增加底池，所以这些是合法条件对照，不是完全隔离单变量的实验。

对手隐藏牌在构造结束后仍不展示。不同执行的未见后续牌分别产生，避免从前一局摊牌推下一局未来。首次策略行动使用预先固定种子的正常随机流，配对共享策略随机流，未固定为0.4。后续Hero自由行动，整条线路不再保证逐动作完全一致，因果比较限于匹配的首次响应。逐动作检查合法性、非负整筹码和总量守恒。

## 成组量化结果

在同一12个合法初始状态下，标准/进阶、全部八种风格，每状态32组权益抽样、每组8次策略选择，共768个公开视角与49152次条件选择。采用产品的权益抽样设置，不替换真实范围估计。它们是构造状态的重复决策，不是49152手新牌，也不增加自然独立牌序数量。

### 阈值边界的稳健性补查

发现上述边界后，另行固定全部169类起手牌、前位/按钮、标准/进阶、八种风格，每类8组权益抽样与8次策略选择，共346112次条件选择。对子/同花/不同花类分别按6/4/12个实际组合加权，总计1326组合。它是已发现问题后的开发诊断，不是原先预设的独立留出，不替换原12状态或盲评局面。

| 风格与难度    | 前位加注率 | 按钮加注率 |     按钮减前位 |

同一按钮条件下，后位争夺比均衡的加注率高38.24个百分点（标准）、35.08个百分点（进阶）。其前后位响应差异比均衡大41.22和38.67个百分点。这个完整起手类检查支持后位争夺确有位置特征，也说明原单手标准差异0.39不能外推为整个风格缺少位置差异。这里仍是构造条件的加权决策率，不是自然开池机会率、完整牌局胜率或AI识别通过。

自然首选合计1/6，构造合计3/6，均未达到各自5/6目标。构造阶段三位对两个目标都选了均衡，首选置信度仅0.30–0.35。因此均衡的3/3不能解释为其独有特征已被认出，也可能是两者都被当成通用合理打法。三位对两种构造对手的辨识度均只给2/5。

构造组的训练价值全部达到4/5，说明成组练习让评审有机会比较应对，但没有解决标签区分。自然训练价值仍为2–3/5，未达目标。自由稿的共同反馈是可见交锋偏少、很多响应相似、暂时无法形成稳定且不同的反制方案。第三位评审的12组首次响应里有11组动作类别相同，下注尺度也应结合而非只看是否加注。

轨迹核对还发现，后位争夺在三次改善转牌中均满足听牌延续条件，但正常随机流只抽中一次下注，另外两次选择过牌。这不是线路被后续代码取消，也不能据此改种子补到下注。它表明单个条件每人仅一次时，底层较高的行为率仍可能没有充分出现在互动样本中。同时它与听牌施压重合，放大此分支也不能单独证明后位身份。

三位实际完成的Hero自主动作分别为102、112、105次，共319次，其中自然121次、构造198次。六次构造执行在轮到Hero之前结束，仍保留在72次执行分母中。客户端与服务端逐条对账无缺失或错误，原自然报告及原始HTTP前缀未改变。另将记录的132次完整执行、1537个含setup/机器人/Hero的动作送回原引擎独立重放，合法性、非负整筹码、总量守恒及最终账目全部一致。这是执行审计，不是重新生成机器人选择或依据隐藏牌给Hero评分。

### 结论

本轮把“底层行为有差异”“构造练习有训练价值”“自然互动能辨认身份”区分开了。完整起手类诊断支持后位争夺存在显著的位置特征，但当前小样本互动没有可靠呈现其专有身份，均衡也仍容易成为无法区分时的通用标签。不能宣布风格或自然体验验收通过。

下一步开发应优先检查自然交锋中位置特征的实际可见机会，以及均衡在中等成牌时是否被通用价值分支覆盖。应按机会统计同类牌面、价格与位置下的行为和尺度，保留合理弃牌及随机混合，不为猜标签强迫下注。后续已读局面只能作回归，新验收要另锁未见局面和种子。本轮没有继续修改策略，所以这些是定位后的开发方向，不是已完成的优化。
