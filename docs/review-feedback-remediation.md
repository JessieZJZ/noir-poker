# 复盘评委反馈修订

本轮针对既有复盘的表达与因果链修订。保留行动前公开快照、原始意见和失败版本，不以最终输赢、其他玩家暗牌或未来公共牌评价当时决策。未改机器人策略、下注规则、范围权重或模拟精度。

## 修改内容

- 统一正文、详情标签和候选动作的确定程度。较小加注可能优于过大的全下，并不等于该加注已证明盈利；缺少依据时仍须比较。
- 区分实际全下与假设较小投入。实际全下后不再要求本人后街付费，较小替代路线仍需说明剩余筹码、再次加注及后街费用。
- 解释加注需要谁弃牌、哪些较弱牌可能继续，不能把阻断牌、主动权或起手牌级别单独当作盈利证明。
- 补全原开池者、平跟者及本轮仍待回应者；已经行动但需要再次回应，不等于在本人身后尚未行动。
- 对手解释保留实际价格、行动路线与判断依据，不混入对该对手未来操作的教学建议。多人弃牌原因需连接真实下注和跟注路线，不能仅列出可能更大的牌。
- 合并相同的过牌后取值与付费范围解释；听牌跟注不一定来自更弱的牌。中暗三条或补中后的额外收入只在依赖这条获利路径时讨论。
- 清理内部标题与路线元数据，同时区分它们和页面实际显示字段。内部标题修订不能被报告成已重现的界面错误。

## 复测口径

完整重新执行文字与上下文分析，复用原有两种范围估算和候选模拟数值。已先在旧冻结源码证明 1,833 条完整输出及哈希一致，再用于新版重生成；并逐条核对数值未变。因此无需重复原约十小时的抽样，也不增加样本量。

原始 8,489 条记录包括 6,656 条构造翻牌／转牌对手解释，以及 1,833 条玩家翻前复盘。它们对应 1,559 个精确不同公开单元。四角色分别复核自己的原问题，并使用固定控制项。重复修订和同题复测不计为新的独立样本。

原始完整牌谱、私有映射、每轮完整输出、逐题评委反馈与独立备份仅保留本地。机械哈希完整性、AI 文本审查、网页验收、客户端编译和真机体验是不同证据层；本轮不据此声称精准读牌、最优策略或自然牌局胜率得到新证明。

## 后续修正：恢复具体动作建议

用户反馈“需要比较”覆盖了具体动作，使复盘无法直接回答应该怎样行动。此前选择的动作和金额仍在数据中，但评价文案替代了主要建议，部分正文分支也因此不再陈述建议动作。

主要标签和建议字段现统一显示“建议弃牌、建议过牌、建议跟注、建议全下、建议加注至某金额”。首次下注仍用“下注至”，全下跟注和短全下保留规则上的区别。详细理由继续区分开池与隔离加注，金额沿用引擎输出。

判断把握程度与主要建议分开保存：`assessmentLabel` 保留原评价，`recommendationConditional` 标记需要范围条件支持的建议。正文先明确行动，再说明需要哪些较弱牌付费、多少弃牌空间或哪些诈唬留在对手范围内。未将有条件建议改判为已证明盈利，也未改变候选动作选择、数值核心、机器人打法或规则。

重新使用本地保存的 1,833 条 R5 玩家翻前公开输入与完整结果生成建议字段，逐条确认动作、金额、附带条件、评价类别与 EV 类别不变，且输入和保留的数值核心没有被修改。1,279 条弃牌、377 条跟注、166 条加注、11 条过牌均有具体建议。全下属于相应加注或跟注类别。本次核对没有新增牌局、数值抽样或独立样本，也没有重新进行四角色评委审查。原 R1–R5 反馈、失败版本、报告和备份保持原样。
