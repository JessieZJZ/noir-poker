# 玩家观察与范围判断

本轮在 `codex/bot-policy-hardening` 上开发，起点为 PR64 的 `32634e0`，交付前快进纳入该 PR 已发布的 `70a4048`，保留其中三项布局与验收修正；这三项没有改变统计使用的引擎。旧引擎及原始失败和牌谱保留在本地冻结目录；新旧版本的结果分别统计。

## 玩家画像

`noir-player-observations-v1` 保存版本、修订号、累计完成手数和最近最多 64 手的公开行动计数，保守序列化预算为 64 KiB。计数区分入池、加注、翻前大额投入、翻后进攻，以及实际面对下注后的继续或弃牌。原生 App 通过 Preferences 持久化，Web 使用本机站点存储，微信使用本机小程序存储；不同设备、应用和网站来源不互相同步。

从首手收集公开行为，下一手有一手历史就开始带不确定性的范围修正。当前手的公开行动单独用于行动线判断，不把未完成手再次混入频率先验。频率先验保留收缩，单次全下不会立即变成“任何底牌都在诈唬”的确定结论。

新局、刷新、退出后重开和换盲注会恢复玩家画像。所有风格观察同一份玩家数据，自身风格参数、情绪和筹码不由画像覆盖。新局中的其他机器人不继承上局另一个座位的个人统计。

结算增加一个样本；重打撤回该样本并使用更大的写入修订号，重新结算只替换一次。只读对局详情不读写学习状态。记录恢复检查点也保留画像修订号和累计手数，画像单独存储失败时仍可恢复这部分公开信息。坏存储、空间不足不会阻止练习；同修订号的并行页面冲突会拒绝覆盖，不声明已经实现多窗口学习合并。

原生启动仅对观察记录比较 Native Preferences 与 WebView 的有效版本，按修订号恢复较新副本；同修订号冲突保留 Native 优先，不拼接成虚构样本。两份输入都须通过白名单、版本与大小校验。异步写失败在队列结束后可读取，较新本机副本仍可供下一次启动恢复；提升副本写失败不妨碍其他设置读取。故障注入回归覆盖这些路径，不把它当作已经在实体手机观察到的故障。

画像只含白名单计数，不含底牌、公共牌、原始牌谱、牌序、输赢或用户标识，不上传。清除本机相应站点或 App 数据会清除画像；普通新对局保留画像。

## 行动线与主动打法

单街过牌和跟注也参与候选牌组的行动似然；已完成整街过牌的信息对每位过牌者生效。湿面上的过牌会降低部分强牌的权重，同时保留慢玩、过牌加注、中对和听牌。单街信息不获得多街专用精确枚举或防守豁免。

顶对或超对的保护下注要求真实过牌到自己、尚未完成的听牌面、较弱付费范围、可控再加注风险，以及相对过牌的正模型收益。多人组合权益与逐个付费者的权益分别判断，不把单挑的百分比直接套在多人底池。已完成同花、配对面、四连张和更多对手保留额外限制。

强听牌在公开范围更支持中等成牌或未成牌时，可按弃牌机会、被跟后的权益、下注成本和自身风格选择主动施压。上一街真实全员过牌后，前位转牌领打另有标记；新牌完成明显听牌或对手实际加压时重新判断。复盘只解释实际采用的公开依据，不以最终补中或获胜反推此前正确，也不给“对手为什么这样打”加入下一步教学建议。

## 配对评测

主要学习评测固定 64 个独立块，均衡和混合各 32 块。每块用独立训练种子执行 16 手，再用不同的验收种子执行 10 手，比较旧版冷启动、新版冷启动、新版导入画像三种条件，共 2,944 手。每手恢复九座 100BB，块内延续公开观察和情绪；它与保留真实后手的连续对局分开解释。

主要终点是玩家首次合法翻前全下后，所有仍在局对手真实弃牌的条件率；盲注直接获胜、已淘汰者和全下输家不计为弃牌。新旧使用相同验收牌序作独立块配对。预设至少降低 10 个百分点，且差值的点态 95% 区间上界低于零，才称该终点有明确改善。区间跨零就保留不确定，不反复追加直到显著。

翻后定向评测使用 13 个公开局面、8 种风格和 32 个种子比较旧／新版本，共 6,656 次构造决定。保护和半诈唬正例与完成花面、配对面、四连张及强反击等反例分别报告。构造决定不计作自然牌局或真人体验；反例检查错误新增分支，不要求所有局面一律过牌。所有测量保留生产计算，只跳过展示等待，并独立核对公开快照、合法行动和筹码守恒。

### 独立离线诊断

复核全部 9,973 次翻前应对，没有发现绕过“价格加待响应风险、再结合风格容差”门槛的继续动作。导入观察后的机器人实际继续 770／3,327 次（23.14%），仍弃牌 76.86%；后 50% 起手牌继续 0／1,322 次。全桌全部弃牌率降低，不等于每名机器人都在宽跟。17,668 个验收快照中的基础风格轴没有被画像覆盖。这只核对模型约束的执行，不证明估计权益或期望收益正确。

每个验收手固定取首位实际回应全下的机器人，对 637 个合法推注机会／臂全量离线评分；实际玩家底牌只在候选组合概率归一化完成后用作标签，未输入机器人或复盘。真实组合的对数损失（越低越好）为旧版 9.575、新版冷启动 8.986、导入观察 7.943；后两者差值为 -1.043，独立块配对 95% 区间为 -1.179～-0.906。在同一新版冷启动公开局面中只替换热历史，也得到 7.9432。

这是看过主结果后的诊断，不另称确认性验收。热模型仍不及这个固定无脑全下对手的均匀组合诊断基线 7.111，强牌预测约 5.20%，样本实际约 1.73%，说明先验依然保守。没有为了追齐该特定对手而去掉不确定性收缩，也不把这项翻前结果外推为任意玩家或翻后的读牌准确率。
