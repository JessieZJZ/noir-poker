# 训练风格

风格详细内容在 `src/data/characters.json`，按入池选择、翻牌与转牌、河牌取舍、特色操作、应对思路组织。均衡与其余十六种风格统一列入介绍，以打法特点命名。内容与既有策略参数、公开信息决策约束相匹配，数值和策略分支不变。

Web/App 全部十一语言完整翻译，微信使用同一份中文内容。设置、指南、复盘和隐私说明统一使用风格名称。均衡保留文字生成的头像，其余使用十六张本地成熟插画，不携带旧真人照片或人物介绍。

内部标识保持稳定，旧设置与历史记录在读取时迁移，牌局、收益和统计不变。

本轮跨端证据与未通过项见 [改版验收](training-styles-validation-2026-10-20.md)。
