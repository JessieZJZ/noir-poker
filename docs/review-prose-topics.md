# 复盘内容的语义分工

原先的总结依次拼接基础行动解释、情境说明和策略补充。每个生成器都独立处理“跟注后还能否下注”和“听牌还需支付什么”，因此唯一对手全下、玩家尚有后手时，同一关闭下注事实会出现四遍。开放转牌跟注也可能同时生成三条后街提醒。

`prose-topics.js` 记录已经实际输出的事实，不根据最终文字是否包含某个关键词猜测。主复盘通过 `coveredTopics` 告知策略补充已解释的内容；补充层保留新信息，不能把完整风险句当作旧标题删除。

| 内容                           | 主要生成位置                       | 合并规则                                                             |
| ------------------------------ | ---------------------------------- | -------------------------------------------------------------------- |
| 当前动作、实际投入、可争夺底池 | `actualActionReason`               | 同动作推荐不再原样复述；改动作建议仍保留                             |
| 跟注价格门槛                   | `coaching.explanation`             | 与补中概率区分，不把改善概率当作胜率                                 |
| 本人全下或已无后续下注         | 基础跟注解释                       | 只解释一次；不能据此声称其他玩家无法继续争边池                       |
| 直接成牌候选与改善机会         | 基础听牌解释                       | 策略层只补尚未说明的坚果性质或具体风险                               |
| 后街计划                       | 具体条件计划优先，通用街次说明兜底 | 能看到河牌与河牌是否继续下注是不同事实，前者保留，后者只讲一次       |
| 本轮仍有人加注与后街再次付费   | 当前回应与后街成本分别标记         | 本轮重新定价不能替代河牌的新增成本；尚有活跃边池对手时两项都要保留   |
| 补中后还需弱牌付费             | 隐含收益补充                       | 保留不确定的未来收入，已说明后街成本时不再重复该成本                 |
| 配对面上的葫芦／四条风险       | 具体风险说明                       | 即使一般补牌上限已说明，这项新风险也必须保留                         |
| 河牌取值与诈唬范围             | 已有具体范围理由优先               | 有具体牌组和价格依据后，不再追加同义泛泛抓诈唬说明                   |
| 行动线、牌面变化、全下状态     | `situationEntries` 分类接口        | 不能再把情境数组第一项盲当作行动线；旧 `situationNotes` 接口保留兼容 |

“有人全下”不等于全局关闭下注。本人全下、全部对手全下、河牌最后行动、尚有对手可争边池分别按行动前快照处理。翻牌对唯一全下者跟注时，可看转牌和河牌；至少出现一张当前候选牌的概率仍不是最终获胜概率。

策略补充按已输出话题去重，同一分析重复调用补充器不会再次追加同一话题。Web/App 的复盘缓存及微信 worker 版本均包含引擎和复盘源文件摘要；此次组合逻辑变化会使旧派生结果失效，原始牌局不会删除。

回归入口为 `tests/unit/review-semantic-topics.test.js`、`review-prose-coverage.test.js`、`coaching-prose-coverage.test.js`，网页入口为 `tests/e2e/review-semantic-topics.spec.js`。重建的截图近似局面有明确的合法下注账本，只作为构造回归，不冒充用户未提供的原始存档。

旧输出、失败记录、原始模拟输入及新版复盘保留在本地 `.artifacts/review-semantic-dedup-20261028/`。重生成复盘不增加自然牌局样本量；全量覆盖、分层抽样、自动语义检查和评委定性审查分别报告。

## 同输入重生成结果

本轮实际重生成 6,656 条对手解释、64 条固定分层玩家首决策和 8 个构造语义案例。玩家分析保留生产的 600 次权益采样、40 次路线采样。先用 8 条独立双算验证数值核心复用与完整分析一致，再对后续记录复用已保存核心，调用新版真实解释器重生成文案；不降低参数，不把重渲染计作新牌局。原有 25 条独立双算文件保留原始字节，其余 39 条的计算方式逐条标记。

| 范围             | 结果                                          | 能支持的结论                                             |
| ---------------- | --------------------------------------------- | -------------------------------------------------------- |
| 6,656 条对手解释 | 新旧全文一致，均长 169.44 字符                | 此次玩家总结消重没有改坏这些对手解释；不能声称它们变短   |
| 64 条玩家首决策  | 均长 234.33 字符，建议动作与评价均未改变      | 这些实际保存的首决策没有回归；全部为翻前，不外推翻后体验 |
| 8 个构造语义案例 | 均长 350.50 → 305.13 字符，6 条更短、2 条不变 | 针对性案例平均缩短约 13%，不能外推全体复盘               |

专项检查保留跟注价格、真实补牌、配对面风险、可见剩余公共牌和真实后续投入边界。旧版中把配对面补 A 误称为顶对的表述也一并纠正。玩家自己全下、唯一对手全下、尚有活跃边池对手、翻牌可看两张和转牌只剩一张分别覆盖。

德扑教练、普通玩家、职业牌手和专业解说四个 AI 角色审查同一匿名题包。24 个旧政策样本用于质量回归；8 个同快照、同动作案例才比较消重前后文案，两组不合并计偏好。评委指出一处新版删掉河牌新增成本的遗漏；修正后保留本轮再加注与下一街付费两个独立事实，再对同题复核。旧控制侧的错误、原始反馈和失败版本全部保留。复测不增加独立样本，也不当作真实玩家盲测或总体无损的统计证明。

原自动审查只限制重复次数，没要求该成本事实必须存在，因此漏过此问题。新增必要事实下界后，8 个专项全部通过；这些门槛是评审后的回归补充，没有冒充事先登记的统计终点。完整来源、输入摘要、计算模式、三版文案、评委记录和报告位于本地 `replay09/`、`replay10/`。
