# 复盘、策略能力与难度

本次改动基于 #49 的完整源码，提交到面向 main 的独立 PR，包含尚未合入的依赖。运行时仍在本地分析，不引入在线模型、账号或付费接口。

## 复盘呈现

保留顶部决策时间线。移除底部上一步、下一步及重复的后续响应段落。每个视角依次展示：

1. 自己的起手牌、成牌和私人听牌，以及行动时的公共牌结构。翻前合并为一组“对手可能牌组”，结合此前开池、跟注及再加注解释范围；不按起手牌高低分成能赢与会输两栏。
2. 翻后按行动前的公共范围排序的较弱牌例。价值来源较多时，列出更多较弱成牌或听牌。
3. 翻后同样排序的较强牌例。落后的范围较多时，列出更多威胁牌组。每组用代表组合，最多三组，不展开花色排列。

之后给出行动分析与具体建议。原有赔率、合法动作、成对候选模拟和保守置信界限继续决定建议，不用单手结果来判定操作。坚果结论仍穷举全部合法未知组合，不根据低权重排除可能更强的牌。

翻后示例数量比较只统计有意义的成牌与直接听牌，避免大量空气牌把价值来源夸大；展示优先覆盖不同成牌家族，再按公共范围权重补足代表组合。因此底对在多人开池底池里不会仅因领先许多空气牌，就展示更多可赢示例。两头顺、双卡顺或卡顺与同花听牌可以同时标注。这里比较的是当前成牌，强听牌仍可能有更高的摊牌权益，不能把示例数量当成获胜概率。

顶对过牌同时说明向弱牌取值的机会和保留强牌过牌的取舍。普通过牌记录不冒充已记录的埋牌；多人湿润面说明免费发牌风险，最后行动者不声称可以诱导已经不存在的本轮下注。真实埋牌分支仍按其记录解释。

完整对局动态在两个视角下方共用一个折叠区，打开复盘时收起。我的视角突出玩家自己的全部动作；对手视角突出所选对手的全部动作，同时标记当前分析动作。后续发牌和结算只在该过程展示中出现，不传入行动评分。

新机器人记录保存带版本的行动依据，包括实际执行的动作、原因、投入、听牌条件、待回应玩家和策略能力。旧记录或依据与动作不匹配时，内部标记为推断，不向玩家展示存储实现说明，也不伪造当时意图。改变难度不会重写历史记录。新玩家快照记录行动时的难度，后续候选模拟也使用这档能力；旧快照缺少难度时保留标准档假设，不根据后来设置追填。

## 五个观察指标

指标是模拟运行结果，不是难度的固定目标，也不是知名牌手的实测频率。采用 [PokerTracker 的统计定义](https://www.pokertracker.com/guides/PT3/general/statistical-reference-guide) 确定分母；本项目明确使用翻前 3-bet、翻前弃给 3-bet、翻后 AF。

| 指标          | 本项目统计口径                                                        | 影响它的主要控制                     |
| ------------- | --------------------------------------------------------------------- | ------------------------------------ |
| VPIP          | 有自愿投入的已结算手数 / 已结算手数；免费过牌和盲注不计               | 入池范围、位置、价格、筹码深度       |
| PFR           | 有翻前加注的已结算手数 / 已结算手数；每手最多一次                     | 开池与再加注范围、进攻抽样           |
| 3-bet         | 翻前第二次加注次数 / 面对一次加注且可以再加注的机会；每人每手首次机会 | 价值再加注范围、阻断轻再加注能力     |
| Fold to 3-bet | 面对翻前第二次加注后弃牌 / 面对该加注且需要回应的机会；含尚未入池玩家 | 价格、可玩性、有效后手、后续回应风险 |
| AF            | 翻后下注和加注次数 / 翻后跟注次数                                     | 价值、诈唬、控池、埋牌和跟注判断     |

没有机会时比率为 null；没有翻后跟注而有进攻时，AF 不伪造有限值，另以 afInfinite 标记。重打撤回原手统计；已保存的旧统计缺少新字段时补零。脚本输出原始分子、分母，不能用“发生再加注的局数 / 全部局数”冒充 3-bet。

## 难度与情绪

| 难度 | 能力范围                                                         | 倾向                                           |
| ---- | ---------------------------------------------------------------- | ---------------------------------------------- |
| 轻松 | 基础价值与价格判断                                               | 相对宽入池、更多平跟、较少再加注；判断误差较大 |
| 标准 | 加入位置、持续下注、听牌半诈唬、控池和强牌埋牌                   | 相对有选择地入池和进攻                         |
| 进阶 | 加入阻断诈唬、薄价值、float、延迟进攻、轻再加注、donk 和罕见诈唬 | 更多有条件的路线，判断误差较小                 |

能力集合严格递增，各能力还受原型风格、牌力、公共行动、合法动作和价格约束。同档内保留所有风格差异。进阶不意味着每个指标都更高；多人底池和强范围面前仍应收紧。

当前权益估计的随机扰动分别为 ±8、±4、±2 个百分点。策略能力、扰动和入池/再加注倾向共同区分难度；这不等于已经证明进阶档的长期胜率更高。固定牌序的小样本仅描述行为差异，仍需要更多配对局面与长期样本评估决策质量。

小对子、同花连张等结构牌可在价格与后手允许时入池；之后逐街重算牌力、私人听牌和公共范围，支持半诈唬以及进阶档的 float、延迟进攻。当前尚无完整的双方整段范围优势比较和转牌分支规划，不应把这些启发式称为求解器式多街计划。单手持有小牌不构成范围优势。

AF 是实际翻后行动的输出统计，不是机器人追逐的目标值。无前注下注和加注在引擎内统一归为 raise；全下按实际动作归为 raise 或 call，每次行动只计一次。翻前行动、过牌、弃牌不进入 AF 分子或分母；它与使用全部行动作分母的激进频率不同。情绪可以改变动作选择，动作随后影响统计；统计到的 AF 本身不反向强制机器人进攻。

情绪沿用输赢、近 4 手被同一对手施压、冷却和衰减机制。off 完全关闭倾向调整；subtle 和 lively 改变幅度，lively 的情绪还持续更久（4 手对 3 手）、冷却更短（2 手对 4 手）；它们只调整当前能力内的入池、进攻、诈唬、跟注和埋牌频率，不解锁新能力，也不绕过全下价格、加注重开或筹码面额约束。复盘读取当时实际记录的情绪及能力。

## 策略资料与使用边界

以下均为作者或教学机构的一手资料。实现是训练用启发式，不声称复现求解器频率，也不套用赛事 ICM、特殊 5 BB all-in/fold 或 Stand-Up 附加规则。

- [GTO Wizard：价值下注的原因](https://blog.gtowizard.com/reasons-for-value-betting-in-poker/)：比较被弱牌跟注和让有权益的牌弃牌；不能只看绝对牌型。
- [GTO Wizard：保护的正确理解](https://blog.gtowizard.com/the-right-way-to-think-about-protection/)：湿润面不是一律重注的理由，要避免只留下更强继续范围。
- [GTO Wizard：阻断与不阻断](https://blog.gtowizard.com/blockers-unblockers-the-secret-to-picking-great-bluffs/)：阻断价值组合与保留弃牌组合有不同作用；一张高牌不等于成功诈唬。
- [GTO Wizard：多人底池](https://blog.gtowizard.com/10-tips-multiway-pots-in-poker/)：多人共同承担防守，纯诈唬更难成功，薄价值要求提高。
- [GTO Wizard：过牌坚果](https://blog.gtowizard.com/when-checking-the-nuts-beats-betting-them/)：安全面、阻断跟注范围或诱导后续下注可以支持埋牌；河牌最后行动者过牌不能诱导不存在的后续下注。
- [GTO Wizard：抓诈唬](https://blog.gtowizard.com/the-art-of-bluff-catching-2/)：弱成牌是否跟注取决于价格、范围、阻断和后续可实现价值，不是“有一对就跟”。
- [GTO Wizard：河牌原则](https://blog.gtowizard.com/principles-of-river-play/)：大小尺度服务于不同的继续范围，强牌也需要保留薄价值和埋牌路线。
- [PokerStars：底池赔率](https://www.pokerstars.com/poker/learn/lesson/pot-odds/)：当前成本与可争夺底池比较；隐含赔率受有效后手、位置及反向隐含赔率限制。改善候选不保证获胜。
- [PokerStars：挤压](https://www.pokerstars.com/poker/learn/lesson/squeeze-play-nlhe/)：开池后已有跟注才构成挤压情境；减少人数本身不能证明再加注赚钱。
- [PokerStars：筹码底池比](https://www.pokerstars.com/poker/learn/lesson/introduction-to-stack-to-pot-ratio-spr/)：全下需要结合相对牌力和后手，不能把所有口袋对子或高张都当成自动打光。

不把“为了知道对手牌力”单独作为加注获利依据；范围优势是基于公共行动的估计，不凭一张牌就断言成立。对于跟注、弃牌、过牌、加注、全下，保留价格、牌面、位置、有效筹码和后续行动的具体因果描述。

## 性能与验证边界

共享缓存仅保存牌面与两张候选牌的纯评估，最多四个公共牌面。范围、候选分布、随机状态、价格和决策绝不跨行动缓存。每次重新准备公共范围；未知组合和补牌仍完整计算。冷缓存与热缓存必须得到完全相同的指标、候选、结论和文案。

Web Worker 每完成一步即可交付该步完整结果，最终仍等待全部步骤完成。无 Worker 回退与小程序使用相同的 600 次权益抽样和 40 次成对路线比较；小程序把对手详情改为选择时分析并在本次复盘内复用，关闭或重开时清理。不会为速度减少分析内容、抽样次数或范围条件。

微信把完整玩家决策分析放入独立本地 Worker，主线程只投递脱离原局对象的行动前公开快照、接收完整结果并生成展示数据。不会投递最终结果、对手底牌、未来牌堆或展示用后续动态。关闭、换手、重打、重置、隐藏和销毁会终止 Worker 并拒收迟到结果；不支持 Worker 或 Worker 被系统回收时，沿用同质量的分步回退，并保留已完成的完整步骤。该改动改善计算期间的界面响应，不声称 Worker 本身减少计算量。

验证记录和本机产物另见本次验证报告。单元、浏览器、编译、安装运行及实体设备验收分别列出；没有执行的项目不计通过。

## 玩家可读的复盘文案

“牌力与牌面”标题下单独展示起手牌或当前成牌、听牌和公共牌特点。多人底池的一对会说明控池与免费发牌的取舍；过牌直接解释为“不必再投入筹码”，与全下无关。

翻前只展示“对手可能牌组”，不再按起手牌点数分成能赢与会输两栏。示例沿用公开行动范围的权重，解释开池、再加注、已跟注者以及当事人持有 A 时的组合减少；不会把加注前的溜入描述为已跟住加注。开发记录来源保留在内部 `basisSource`，不进入玩家正文；未确认的埋牌意图使用“可能”，不把推测写成已知事实。
