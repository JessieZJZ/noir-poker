# 翻前重注防守与主动全下

本轮以`4ff57cb`为基线，处理强起手牌面对翻前大额加注/全下过度弃牌，以及强牌缺少主动推注路径的问题。保持八种风格、无登录本地练习、虚拟筹码和现有规则。没有把AK、KQ、TT、QQ、66统一设为必须跟注，不承诺每次拿到这些牌都会接下100BB。

## 找到的原因与修改

1. 原“大额承诺”分支通过价格检查后直接返回跟注，连AA面对仍有筹码的对手也不能继续推注。现在足够强的牌在合法、可被跟注的局面有主动承诺路线。真实全下不会凭空创造边池，未重新开放的加注也不会被绕过。
2. 原范围把深筹4-bet和更深的5-bet、多家已经跟住的线路混得太紧。现在区分实际只剩一个对手、无人等待回应，与已经出现另一家足额跟注。原来9人桌打到单挑，不再仅因开局人数多就照搬多人紧范围。
3. 20BB单挑首次推注原先仍明显偏向大对子和AQ以上，66、KQ难以继续。新的短桌/后位范围纳入中小对子和高张，深筹多次加注保留更紧范围。范围只根据公开位置、下注线路、筹码、已承诺与等待人数构造，不是真人统计或求解器结果。
4. 标准难度翻前全下原先72次抽样、进阶256次，还叠加额外随机扰动。标准/进阶现在使用512次，并去掉这类决策的额外噪声，保留风格的价格容忍差异。显式指定抽样次数仍按调用值执行，轻松难度保留原有扰动，翻后精度未改。
5. 强价值再加注采用更常规的翻前倍数。短筹有直接推注，100BB首次推注只为AA/KK保留低频取值混合；经过多次加注的强牌反推更积极。高额单次开池也接受承诺价格检查，不能因为还留一点筹码就绕过风险判断。

主动推注由`bot-preflop-commitment.js`组织，使用本人的底牌和公开状态。下注与结算继续由`poker.js`负责。所有金额以本局大盲、筹码面额和有效筹码计算，没有把100/200固定为策略金额。

## 条件重放：强牌是否还会系统性弃牌

七种在座人数2/3/5/6/7/8/9，2/3通过将五座引擎的其余座位设为已淘汰，构造对应在座人数的控制局面。覆盖标准/进阶、11类起手牌、首次10/40/75BB重注、20/50/100BB推注、3/4/5-bet和已跟注者，以及主动推注机会。

每个版本有3058个条件格、6116次权益评估、782848次条件策略决策。两权益种子428113/756137、每种风格16次策略随机数、全部八种风格固定。48928次脚本续局验证合法支付与完整结算。条件格可指向相同公共状态，不把重复随机数、不同风格或2人桌早/后位别名计为独立牌局。所有比较的本人手牌、历史、价格与合法动作逐字段一致。

下表为固定条件重放的跟注率，分母包括共享权益评估和重复策略抽签，不能当作真人或自然出现频率：

| 条件                                   | 起手牌 | 修改前 | 修改后 |
| -------------------------------------- | ------ | -----: | -----: |
| 2/3人在座、20BB首次推注                | 66     |     0% | 87.50% |
| 同上                                   | KQs    |     0% | 56.25% |
| 同上                                   | TT     | 52.15% |   100% |
| 2/3人在座、100BB 3-bet推注             | AKo    |  3.52% |   100% |
| 2/3人在座、100BB 4-bet推注             | QQ     |  4.79% |   100% |
| 同上                                   | AKo    |  5.57% |   100% |
| 5–9人在座但已闭合单挑、100BB 4-bet推注 | QQ     |  4.88% |   100% |
| 同上                                   | AKo    |     0% |    25% |

这些表格不是“强牌一律接”。例如早位4-bet的AKo仍有估计权益不足价格的弃牌，AKs、QQ与AKo不同。KQ、66面对100BB深筹5-bet仍会弃牌。已有另一家跟住的强线路保留独立范围与多人价格，不能把单挑效果外推过去。

主动推注的条件对照（分母每行3584次共享条件决策）：AA在20BB首次行动的推注率由0增至88.28%，100BB首次行动由0增至7.76%；面对25BB 4-bet由0增至94.14%，面对仍未全下的50BB 5-bet由0增至94.14%。这是对应牌力、位置、筹码和下注条件下的动作比例，不是每100手牌出现多少次全下。

## 自然完整牌局

新旧各5000手，共10000次完整执行。5–9人、标准/进阶、全部八风格轮换，种子739391/918113，每单元250手，每手恢复100BB、情绪关闭。500个初始洗牌簇在不同配置与版本间共享。Hero固定使用修改前完整决策实现，避免把Hero也变激进当成机器人改善。每手重新创建引擎状态，避免继承淘汰或整局结束标记。

| ------------------------------------ | -----: | -----: |

| 至少一位机器人主动翻前全下的手数比例 |  0.22% |  1.24% |

主动全下约为原来的5.64倍，手数比例增加1.02个百分点。按500个初始洗牌簇做配对bootstrap，95%区间为增加0.62至1.44个百分点。各人数和难度细分保存在本地。两版5000组初始手牌、位置和风格分配逐项完全一致，逐动作合法、非负整筹码和完整结算守恒均通过。这个整体频率仍受实际发到强牌、筹码和公开线路影响，不能把AA面对4-bet的条件推注率当作每手推注概率。

该实验不模拟真人偏好。不能用这批100BB自然样本宣称20BB直接推注的自然发生率，也不能将执行次数作为独立洗牌数量。

## 玩家固定推注挑战

自然基线的Hero没有主动翻前推注，不能用它证明玩家推注后的回应。因此额外锁定2/3/5–9人在座、标准/进阶、玩家20/100BB、前位/小盲位，各单元20手，种子662459，新旧各1120次完整执行。给一位尚未行动的对手按固定顺序安排AA/KK/QQ/JJ/TT/AKs/AKo/KQs/KQo/66/72o，其余活跃机器人按实际生产策略回应。

小盲位的前序弃牌属于预设，不算机器人回应。统计只覆盖玩家真正推注后的自主动作。初始洗牌只20簇，牌力分布为刻意安排，结果不能用来预测自然牌局里“大家都弃牌”的比例。

| 刻意发牌后的玩家推注挑战 |         修改前全弃 |         修改后全弃 |
| ------------------------ | -----------------: | -----------------: |
| 玩家20BB                 |  165/560（29.46%） |   96/560（17.14%） |
| 玩家100BB                |  244/560（43.57%） |  222/560（39.64%） |
| 合计                     | 409/1120（36.52%） | 318/1120（28.39%） |

指定对手的实际跟注例子：20BB的KQs从5/56变为34/56，66从2/28变为18/28；100BB的QQ从55/56变为56/56，AKo从44/56变为48/56，AA/KK两版均56/56继续。100BB的66仍为0/28继续。对手可以看到前面其他机器人的真实回应，先出现跟注与只有一家推注的情况分别定价，不能据最终隐藏牌或输赢反推决定。

新旧1120组起手牌、预设前序弃牌、位置和风格逐项一致，全部完整结算且守恒。全弃减少91次，来自这组刻意安排的测试分布，不是自然玩家推注后的总体预测。

候选2测量完成后，补齐了玩家复盘快照的人数推导：缺少count时，从完整玩家列表计算未淘汰席位，保留已弃牌座位。机器人本来就传入count，全部6116个已测机器人视角的公开范围描述与补齐前逐字段完全一致。实际机器人策略和上述模拟结果不变，最终源另行冻结并重跑工程检查，不能将源码差异隐去。

## 验证、失败与资料保留

最终发布源码完整`npm run check`：1011/1011单元、生产构建与微信生成通过。6项桌面/移动Web专项通过，含实际执行AA反推、完整金额与对手复盘，不展示开池者隐藏牌。新回归覆盖2/3残局及全部5–9人、25/100/50000小盲尺度、真实全下/近全下、多人跟注、未开放加注、错误价格、隐藏牌与未来牌序不变性。微信资源核对和19文件官方WXML/WXSS编译通过。这不是本轮新的原生App、实际DevTools或实体手机运行验收。

第一版条件矩阵完成后，发现大桌已打到单挑的4-bet仍过紧，保留该版所有结果和2459手已完成自然开发牌局，停止自己的未完成模拟后另冻候选2。没有改牌序或加种子凑通过。早期三个旧断言失败分别是AA只能平跟、非全下平跟说明分支被新反推覆盖、抽样次数仍写256。保留非全下平跟分支的固定回归种子，另增真实反推用例，金额、守恒和隐藏信息断言不放宽。

一条新增断言曾错误要求每个AKo样本都跟注。实际样本权益44.53%，价格45.39%，不应为满足测试强行继续。改为验证所有有价格支持的行动都能继续，边缘AKo仍可因价格弃牌，并检查各人数不会系统性全弃。原失败日志保留，未为这条断言继续调宽生产策略。

最终完整检查还暴露一项原有微信计时测试的随机失败：好牌动画的2600毫秒清除计时器与机器人思考区间重合，被误计为第二个思考任务。测试改为只数本次计划回调新建的计时器，仍要求恰好一个，隐藏后所有过期回调不能推进牌局。没有修改生产计时逻辑，失败原件与修正后的完整重跑一并保留。
