# 筹码与盲注配置

所有端默认小盲 100、大盲 200、起始筹码 20000（100 BB）。小盲只支持 25 的正整数倍；筹码面额等于小盲，大盲必须为面额的整数倍且大于小盲。暂不增加设置界面选项。

```js
const game = newGame(5, { smallBlind: 300, bigBlind: 600 });
// 自动派生 chipUnit = 300，startingStack = 60000
startHand(game);
configureStakes(game, { smallBlind: 25, bigBlind: 75 });
// 清除原手、筹码投入与统计，回到 idle；所有人恢复 7500 筹码
startHand(game);
```

配置在新建牌局时复制并校验。兼容传入派生字段，但它们必须等于小盲／100 BB，矛盾配置会在改变状态之前被拒绝。破产补入也使用 100 BB。

Web/App 的底层 `window.noir.setStakes({smallBlind, bigBlind})` 与微信适配器的 `setStakes` 会立即取消旧手的机器人、复盘、提示及动画任务，重开第一手并清空牌局和统计。相同盲注不重置；无效配置不改变当前牌局。引擎 `configureStakes` 本身不管理平台计时器，调用方负责取消异步工作。

每手状态、行动前公开快照与机器人视角记录实际盲注、面额。最低下注、完整加注、短全下、不重开的加注权、底池快捷项、退款和按钮顺序的奇数筹码分配使用这些值。机器人范围、情绪阈值、思考时间和复盘 BB 换算使用该手实际大盲。

普通重打恢复同一手的配置、发牌与统计。更改盲注会清除旧手的重打入口，不能恢复旧尺度的牌局。未来周期涨盲需显式区分变更整场配置与下一手等级推进；当前尚未启用涨盲模式。

显示统一用 K/M，并保留整数筹码精度，例如 20000 → 20K，1100 → 1.1K，1000100 → 1.0001M。各语言使用本地小数点，账本仍为整数。

旧规则边界测试显式使用 25/50、5000、25 的历史配置；新回归覆盖 100/200、25/75、500/1000，检查守恒、短全下、奇数分池、退款及变更后的整场重置。

微信开发者工具的实际换盲回归使用 `tests/wechat/stakes.mjs`。连接已启动的目标工程自动化端口后，传入 WebSocket 地址及报告目录：

```sh
node tests/wechat/stakes.mjs "$NOIR_WECHAT_AUTOMATION_URL" .artifacts/wechat-stakes
```

该脚本通过控制器真实行动验证结算守恒、500/1000 尺度重置、旧复盘与快速发完任务取消，以及相同／非法配置不修改状态。结束时恢复默认尺度，保留其他偏好；只在专用测试工程中运行。
