# PR70 繁中、法语与俄语定向修正

基线为 PR #70 的 `38337032eacf30eae24fdeb00da07451b1e7a099`，工作分支为 `codex/pr70-language-fixes`。本组只修改三个 locale JSON，提供独立 override 合并补丁和单元回归；公共界面、中文源文案、动态渲染与双端构建由主任务统一处理。

## 用户判断与范围

按用户导出的 `NOIR-PR70-我的问题判断.json` 执行。繁中统一使用“覆盤”；修正半池说明与 CL 补码说明。保留 CN-03a、CN-03c、CN-04a、CN-05、TW-02a、TW-02b 被否决的设计与名称，不将胜率改名为权益，也不增加新的计算器指标或改变工具入口。

法语与俄语修正规则教学、底池详情、训练参数、重打说明、结果、日志及无障碍名称的实际语义错误。没有改变牌型、合法动作、结算、统计、胜率模型或机器人策略。皇家同花顺在本应用归入同花顺类别，因此指南保留九类牌型，并补齐原法语漏掉的顺子。

## 源码核对与公共支持

`src/engine/poker.js` 的 `MAX_HERO_REBUYS` 为 3，`heroRebuysLeft` 在 `finalTable` 时返回 0。补入数值的向下取整及至少一个大盲由原实现保留；按主任务决定，简短 CL 词条不进一步扩写这些数值细节。

建议中文末句为：“决赛圈前，输光后每局最多可补码三次，每次补到当时 CL 筹码的一半；决赛圈不可补码。”完整新键已在三个 locale 和 sidecar 中提供，`index.html` 由主任务修改。

活动 AA 开池理由包含多槽模板和嵌套句子。回归直接调用 `analyzeDecision`，验证完整理由保留 AA、AK、AQ、A5、位置及金额且不泄漏汉字；没有用一条字典短句冒充完整功能通过。目录另提供有效静态分句及具体开池模板，支持当前翻译组合方式。

独立合并文件为 `.artifacts/language-fixes/override-patches-zh-fr-ru.json`，按 locale 分组，包含本组目标译文。主任务应统一合入 `src/i18n/overrides.json`，因为 overrides 的优先级高于 locale；该 sidecar 本身无需随产品发布。公共金额刷新、百分比数字格式、小屏按钮、净赢颜色、盲注进度和可关闭重打提示均由主任务处理。
