# 德州规则与回归测试

规则的权威实现位于 `src/engine/poker.js`。这里列出本项目明确覆盖的约束，改动时对应检查 `tests/unit/`。

## 位置与行动

- 从按钮位 BTN 顺时针的下一家是 **SB**，再下一家是 **BB**。
- 翻牌前从 BB 后第一位未弃牌、未全下玩家开始；大盲在无人加注且其他人跟齐时仍有加注选项。
- 翻牌、转牌、河牌从 BTN 后第一位仍可行动的玩家开始。
- 桌面人数是 5–9 人。六人桌中仅剩两人继续当前手牌，不会在这手中途改成单挑盲注位置。
- 换人数在下一手生效并开始新的练习桌；进行中的筹码和位置不被悄悄重排。

`rules-audit.test.js` 检查全部六人按钮位置、盲注和四轮顺序；`population-check.test.js` 检查 5–9 人各按钮位置。

## 下注金额

`raise` 的金额表示**本街累计下注总额**；`call` 的金额表示本次需要补齐的额外筹码。界面和工具都沿用这个约定。

最小筹码为 25，所有下注、加注、跟注、全下、玩家余额、底池与退款都必须是 25 的倍数。比例下注按最近的 25 档位取整，恰好半枚时向上；界面滑块每次移动 25。引擎拒绝非法金额，不靠显示取整隐藏错误。

例如你本轮已投 50，当前下注 150：跟注补入 100；“加注至 300”补入 250。最小完整加注按前一次完整加注的增量计算，不把当前总额误当作增量。

不足完整加注的短筹码全下，不自动重新开放所有已行动玩家的加注权。累计多个短全下可能达到重新开放条件，需要逐个玩家检查其面对的增量。只有一位未全下玩家且没有额外对手可以争夺时，不能单独制造无人可争夺的边池。

半池／底池是无限注德州的下注尺度快捷项，底池不是无限注的最高合法额。无人下注时按当前底池乘以 0.5／1；面对下注时先补齐跟注，再按更新后的底池增加对应份额。“加注至”包含本轮已投入和跟注。例如台面底池 3,075、当前下注 800、你本轮尚未投入：跟注后底池 3,875，底池加注至 4,675，半池加注至 2,750（按整枚 25 筹码取整）。快捷项仍受最小加注和剩余筹码限制，超出时使用合法边界。

2026-10-08 核对 [Poker TDA 2026 v1.0 第 45、49 条](https://www.pokertda.com/view-poker-tda-rules/)的完整加注增量、总额声明和短全下规则，以及 [PokerStars 官方底池加注示例](https://www.pokerstars.com/help/articles/poker-rules-master/)。`bet-sizing.test.js` 包含未跟注、已有投入、25 档位取整、非法金额拒绝、最小额、短全下、筹码不足和完整牌局筹码守恒的回归案例。

### 几 bet 的显示

翻前大盲在内部计数为第一级，首次开池显示 2-bet，再加注依次为 3-bet、4-bet……。翻后每条街的首次下注同样是内部第一级，但界面直接显示“加注”，不展示 1-bet；全下和短全下保留明确文案。再次加注显示 2-bet；跟注、过牌、弃牌不增加层级。按钮、座位、动态记录和双方复盘使用同一格式；金额始终是本街累计总额。

短全下按本次进攻行动的序号显示，并明确标注“短全下”。该序号只用于读懂下注顺序，**不代表重新开放加注权**；是否可以再加注仍由 `legalActions()` 对各玩家分别判断。显示格式集中在 `src/engine/action-labels.js`，不参与合法行动或分池计算。

## 分池与退还

全下额度分层形成主池和边池；弃牌者已投入的筹码保留，但不能争夺任何池。未被跟注的独有超额投入单独退还，不算赢得底池，也不增加获胜手数。

示例：四位未弃牌玩家最终投入 `100 / 200 / 400 / 500`，最后 100 无人匹配：

| 项目   | 金额 | 参与比较            |
| ------ | ---: | ------------------- |
| 主池   |  400 | 四人                |
| 边池 1 |  300 | 投入至少 200 的三人 |
| 边池 2 |  400 | 投入至少 400 的两人 |
| 退还   |  100 | 原投入 500 的玩家   |

每池分别比较牌型；主池赢家可以输掉边池。平分时以一枚 25 筹码为单位，无法平分的整枚筹码按按钮左侧顺时针的获胜玩家顺序分配，花色不用于打破平手。例如 275 两人平分得到 150 / 125，不能拆成 138 / 137。结算前后筹码总额不变，下一手余额仍全部为 25 的倍数。

`multi-pot-check.test.js` 包含不同赢家、独立平分、多级边池、退还和重复支付边界。随机牌局测试额外检查筹码守恒与正常结束。

## 摊牌与牌型

从两张底牌和五张公共牌中任选五张构成最佳手牌，可以使用 0、1 或 2 张底牌。A 可以组成 A2345，不能形成 KA234。相同牌型逐一比较有效点数与踢脚，只有最佳五张参与比较。

顺序：高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺。皇家同花顺是 A 高同花顺的视觉变体。

正常河牌轮结束、或者所有玩家已无法继续下注时，未弃牌的底牌立即公开；结算后每位参与者显示自己的最佳五张牌。弃牌者不会出现在摊牌比牌模块，可在结算后用座位旁按钮作为练习查看。

玩家弃牌后的“立刻发完”快速完成机器人剩余行动并展示结算与五张公共牌。如果机器人提前弃牌结束，本手先按弃牌获胜正常结算，再沿原牌堆顺序补齐练习公共牌，并标注“练习补牌”。补牌保存在独立的 `practiceBoard`，不改变真实公共牌、赢家、筹码、摊牌状态或复盘证据；已提前结束但公共牌不足五张时按钮仍可使用。
