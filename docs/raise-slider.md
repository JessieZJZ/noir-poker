# 加注滑轨

Web、iOS、Android 和微信共用 `src/ui/bet-sizing.js` 的展示映射；合法金额、筹码面额和加注权仍由引擎提供。

- 常规筹码深度：最左为最小合法加注，50% 位置等于“底池”快捷按钮，最右为最多全下。两段各自线性变化，并按本局筹码面额取整。
- “底池”是补齐跟注后按底池计算的本街累计投入，与现有快捷按钮完全一致。
- 当一个底池已达到全下上限，或底池值不高于最小加注时，整条轨道线性覆盖合法上下限，避免出现无效的半段轨道。
- 金额与滑轨坐标分离。Web/App 的方向键每次仍调整一个筹码单位，Home/End 到最小/全下；读屏使用实际金额。
- 小程序使用紧凑滑轨，触摸轨道任意处即可拖动。拖动只预览金额，松手提交到加注选择，不自动下注；触摸取消、切后台、换手、重打和旋转屏幕会取消旧拖动。异步测量期间移动或松手也保留最后位置。

回归包括中点与快捷按钮一致、筹码量化、单调性、短全下、键盘、整轨起拖和手势取消。浏览器和原生运行、微信编译与实际客户端验收分别报告。

原生 CI 的 iOS、Android 安装验收均包含 `raise-rail-and-vibration-preview`，通过真实触摸滑轨中部验证金额映射，并检查开启振动触发一次原生反馈。微信整轨触摸专项为 `tests/wechat/raise-rail.mjs`，音乐完整循环专项为 `tests/wechat/background-music.mjs`；它们连接当前开发工具自动化端口，和编译检查分别记录。
