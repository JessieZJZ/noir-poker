# 复盘具体性与低价同花牌入池复核

本轮接续 PR #64 的现金桌翻前尺度调整，基线为 `b535c93`，包含 Claude Code 的混合风格和移动布局更新。重点修正用户截图中的表达和 K8 同花入池边界，未增加新玩法或跨手对手学习。

## 展示行为

- 总结用真实的开池或再加注行动交代前情，删除“明显大于普通开池、不能只套常规范围”等脱离本手分析的开场提醒。
- 相同阶段、相同实际追加金额的跟入者合并成一句，保留姓名与位置。四位玩家都先跟注 20K 入池只说一次；面对后续挤压，两人各补 740K 与另一人补 570K 分开。不能把加注到 760K 写成每个人都补了 760K，已弃牌者不计入当前跟入者。
- 平跟范围写明小对子、同花牌或连接牌，也保留强牌慢打的可能。AJs 的行动说明同时解释顶对与坚果同花听牌机会；不同花 AJ 不套用同花机会。
- 等待行动的提醒改为“他们如果加注或者再加注”。规则引擎已确认短全下不重新开放加注时，仍保留不能再加注的独立分支。
- 55 在 `4♦ Q♥ A♥ 5♥` 过牌的说明交代三张红桃带来的同花威胁、23 的顺子可能、暂不做大底池、公共牌配对时改善为葫芦或四条的机会，以及对手免费见下一张的代价。尚有人可下注时，再说明遇下注需要结合金额、人数和此前行动重新判断。实际强成牌过牌不再标为“中等牌力”。这些威胁来自当时公共牌，不识别对手实际底牌。
- 新文本覆盖 Web/App 的十一种语言，微信使用共享中文内容。新增译文有完整性、占位符和实际切换检查，未进行独立母语扑克编辑审校。

## K8 同花的调整边界

截图为七名仍在桌上的玩家、UTG、约 77.5BB，尚无自愿加注，补 1BB 即可继续。旧排序值约 0.17195，略高于该局面均衡范围门槛 0.16872，因此直接弃牌；不能根据后来公共牌或“进来就会赢”判定此前弃牌是规则错误。

新分支只在普通或高难度、均衡／后位争夺、当前价格不超过 1BB、无加注与全下压力、有至少 50BB 的公开有效深度、高张至少 J 且低张至少 8 的同花牌超出原入池范围时，允许混合低价跟入。不会将其强行升级成加注。已在原范围内的手牌保留原先的主动开池路线，其他六种风格的原入池选择不随这条分支改变。

均衡在满足候选条件后采用 75% 的作者设定混合率；后位争夺在 HJ/CO/BTN 为 65%，其他位置为 35%。这些是练习策略参数，不是职业牌手频率或实战盈利证明。成本上升后重新判断，不能借这条分支跟入 6BB 加注或全下。短筹码、K8 不同花与 K3 同花不共享这条新增入口。

## 实测口径与结果

### 完整自然牌局

前后版本各 1,000 手，共 2,000 次完整执行：5–9 人、均衡／八风格混合、普通／高难度，每格 50 手，情绪关闭。轮换按钮，每手从 100BB 状态开始，Hero 固定使用旧策略，机器人分别使用前后版本。各格复用同一组 50 个发牌种子，因此这些是完整执行次数，不是 2,000 组独立发牌，也不是玩家连续交互体验。

| 指标                               | 调整前 | 调整后 |
| ---------------------------------- | -----: | -----: |
| 完整结算                           |  1,000 |  1,000 |
| 进入翻牌                           |    600 |    600 |
| 至少三人看翻牌                     |    284 |    285 |
| 至少四人看翻牌                     |    111 |    112 |
| 非全下机器人首开                   |    729 |    729 |
| 首开后、再加注前的不同冷跟入者总数 |    796 |    796 |
| 机器人首开后至少两人跟入           |    226 |    226 |
| 新分支候选／选中次数               |   0／0 | 24／19 |

新增分支没有明显改变整体多人池密度；它解决的是有限的便宜入池机会。最后一行来自策略轨迹标记，其余列由独立回放程序按原始行动重新统计。独立回放覆盖 2,000 手的 25,202 个行动，核对合法行动、52 张牌唯一、每步整筹码与非负余额、筹码守恒及最终账本一致。

### 条件决策矩阵

250 个合法行动前局面，八风格、三种情绪设置、每格 16 个固定策略种子、两个版本，共 192,000 次选择。覆盖 5–9 人、简单／普通／高难度、49.5／50／77.5／100BB、K8s／K8o／K3s、可行动位置，以及实际执行到目标玩家的 6BB 加注和全下边界。固定原公开权益估计，以分离新选择分支的影响。

| 指定七人 UTG、77.5BB、K8s、情绪关闭 | 调整前  | 调整后          |
| ----------------------------------- | ------- | --------------- |
| 普通难度，16 个策略种子             | 16 弃牌 | 11 跟注、5 弃牌 |
| 高难度，16 个策略种子               | 16 弃牌 | 12 跟注、4 弃牌 |

调整后的加注／全下边界共 7,680 次选择，新分支候选和选中均为 0。这个结论只证明没有错误走新增低价入口，不代表所有原有边界决策都必须弃牌。全部 192,000 次选择不是完整牌局，也不能当作独立牌局样本或盲评手数。

## 当前抓诈唬能力边界

所有风格都会按自己的摊牌竞争力、公开范围估计、价格、牌面与人数决定是否继续。宽松取值的跟到底倾向最高，后位争夺和大注强攻也较高；这不是抓诈唬成功率。均衡保留单挑干燥牌面的中等成牌低价防守；后位争夺允许部分有位置的翻牌浮动跟注。

范围估计使用本手翻前角色、加注次数和尺度，以及对手最新翻后行动。另有本手公开进攻比例的有限修正和进攻路线判断，但没有完整的逐街价值／失败听牌组合推断，也没有跨手统计某个对手的河牌诈唬频率。机器人行动视角不包含对手的私有风格参数、底牌或决策轨迹。近期输赢与被同一人连续压走可影响虚构情绪，不能据此说机器人已经识破对手的诈唬。
