# 标准与进阶对手的混合打法

`src/engine/bot-deception.js` 在标准难度启用新增混合，进阶提高条件触发概率，入门不启用这些新增分支。准入依据是已有原型的基础倾向，情绪波动不会把谨慎原型变成脏牌或 2–7 玩家。这些数值是本地训练控制，不是职业牌手的真实频率、实际手牌证据或 GTO 输出。

| 特性             | 使用条件                                                                                                               | 适用原型 ID                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 强牌埋牌         | KK/AA 面对一次小开池且后手深；或单挑较干燥牌面的真实强成牌。翻后可过牌，前两条街也可低价平跟；河牌只保留过牌诱导       | balanced, st, zang, jungleman, dwan, ivey, negreanu, hellmuth, haxton                             |
| 脏牌开池／再加注 | 后位、未入池或单次小开池、无跟入者；再加注还要求 A/K 阻断候选。不把弱牌误算成价值牌                                    | balanced, tan, peter, viktor, dwan                                                                |
| Donk 主动领打    | 翻牌／转牌单挑无位置，在前一街进攻者行动前先打，自身有强成牌或湿面的大听牌。持续下注、过牌后的试探、过牌加注不算此分支 | balanced, tan, peter, abao, viktor, jungleman, dwan, ivey, antonius, koon, chidwick, holz, haxton |
| 2–7 诈唬         | 未入池后位低频偷盲；或单挑有位置、对手本轮过牌、较干燥牌面且自己没有成牌／大听牌时试探                                 | balanced, tan, viktor, dwan                                                                       |

均衡原型在条件成立时，新增分支的抽样门槛如下。它们不代表全部牌局的发生率；对手此前的公开行动、位置、牌面、牌力和筹码条件会先剔除大多数局面。

| 新增分支         |  标准 |   进阶 |
| ---------------- | ----: | -----: |
| 强牌埋牌         | 14.4% | 25.92% |
| 脏牌开池／再加注 |  3.1% |  5.58% |
| Donk             |    8% |  14.4% |
| 2–7              | 1.28% | 2.304% |

埋牌门槛以原有 `trap × 0.52` 增加 4 个百分点后按难度放大；现有具备诱导倾向的原型，在符合新条件时不会因替换旧公式而降低标准档门槛。翻后埋牌以自身实际成牌为前提，排除纯公共牌强度；原先仅凭宽随机权益判断的非入门诱导收束为此条件。入门仍沿用原来的策略流程。

新增攻击只在引擎已有加注权时产生方案，用共享 `legalRaiseTo()` 对齐 25 面额；拒绝全下尺度、有效后手不足 1,000、单次新增投入超过有效后手 15% 或有全下对手的局面。埋牌另检查价格、深度、人数与牌面。2–7 没有额外奖金，也不会因抽样未命中而自动变成弱牌跟注。

普通策略已执行的翻牌／转牌领打也会识别为 donk；复盘区分价值、听牌半诈唬和只有弃牌率支撑的领打。没有执行的候选不会被叙述成已执行打法。

## 记录与复盘

实际执行时保存 `trace.deception` 的策略、门槛、有效后手、前街进攻者及具体场景，复盘在结算后读取。它解释隐藏强度、诱导继续、阻断组合、收取听牌价格、争取弃牌和失败风险。正文不展示抽样阈值或随机分支；数字仍在末尾最多两条参考信息中。

策略仅接收行动者自身牌与行动前公开视角。自己的复盘评级不读取此私有记录，不借对手底牌、未来牌序或最终输赢证明合理性。Web/iOS/Android 共用策略与十一语言文案；微信共用策略、复盘和中文适配。
