# 听牌取值、同花风险与跛入池示例

本轮针对三组截图复盘，修正取值来源、危险牌面全下的条件及示例排序。产品仍使用行动前公开信息；未修改机器人策略、范围抽样权重或结算规则。改动包括复盘候选路线、条件提示和展示，不能据此宣称真实牌手频率或最优下注尺度。

## 重建与判断

K♠10♣ 在 5♦10♥6♦ 翻牌下注 810K，行动前底池 810K、后手 2.02M。取值不仅可能来自较弱成牌，也可能来自愿意付费的顺子／同花听牌；是否跟注仍取决于价格，不能只因为存在听牌就认定它们会接整池下注。

转牌 2♦ 时底池 2.43M、后手 1.21M，全下约半池。原来持两张方块的听牌此时已经成同花，只有一张方块的底牌仍可能是听牌。当前顶对不应仅凭牌型被自动肯定为价值全下。现在先提示牌面变化，再比较过牌或较小投入，只有较弱对子或未完成听牌仍愿意支付时，才讨论全下取值。不能把“有花面”写成“只有更强牌会跟注”。

这类无同花听牌的一对／两对，在转牌或河牌投入至少 40% 底池全下时，增加一个“需要比较”的教学提示。它是作者设定的条件提醒，不是证明负收益的规则。原先常规取值尺度超过剩余筹码时会被压成全下，现在可免费过牌的危险牌面不会据此自动称其为价值全下；可以合法比较约四分之一底池或半个后手的较小候选。转牌未补花、本人还有同花听牌、筹码仅够很小比例下注等情况不机械套用。

2♣5♣ 在 8♣10♦Q♣4♣4♥ 上是小同花。截图的翻前为无人加注的跛入池。示例现在优先展示 9♣10♣、6♣7♣ 的更高同花，以及 Q4、10–4 的葫芦，而不是让 QQ、TT、AK 同花及四条占满四个位置。84 也确实能成葫芦；有限位置不会穷尽所有可能组合。

QQ、TT、AK 同花和 44 并未变成不可能。穷举“是否仍有更强牌”的证明不变，已加注底池或短筹码也不套用深筹跛入池的示例偏好。展示仍依照公开逐街路线加权，再应用教学示例的优先级：减少大对子／AK 和极少数组合的占位，兼顾同花连接牌和利用公共对子成葫芦的底牌。这些优先级不是概率，也不改变胜率计算。

8♦10♦ 在 3♦9♦Q♠7♣5♦ 河牌，底池 3.87M、后手 200K，全下仅约 5.2% 底池。继续保留有条件价值全下的比较，同时客观提醒更高同花，删掉与这种浅后手矛盾的“一成花也不能全部投入”式笼统劝阻。总结只报一次“全下至 200K”。“加注至”与实际追加金额不同时，仍分别说明两者。

截图未给出的前序行动采用合法脚本重建。K10 的 810K／2.43M 及四次 Hero 动作、跛入池的 360K／2.62M、浅后手同花的 3.87M／200K 均与截图对齐；它们不是找回的原始存档，也不是机器人自然频率或盲评数据。

## 资料边界

[Stack-to-Pot Ratio](https://blog.gtowizard.com/stack-to-pot-ratio/)用于核对筹码相对底池大小对继续门槛的影响，[Why Not Shove?](https://blog.gtowizard.com/why-not-shove/)用于区分较小取值尺度与全下，[Maximizing Value on Monotone Flops](https://blog.gtowizard.com/maximizing-value-on-monotone-flops/)用于避免只因有同花风险就一概停止取值。[Is Limping Pimping?](https://blog.gtowizard.com/is-limping-pimping/)强调跛入范围和深度的差别，不能把所有大牌从跛入范围删掉。这些文章的具体赛制、牌面、频率并不等同于本局，未导入其 solver 数值。
