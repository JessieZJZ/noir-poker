# 同街过牌文案保留

期望行为：玩家过牌后，其他人思考或加注都不清除这次过牌；再次轮到本人时显示“思考中”，完成下一次行动后更新动作。进入新的一街，尚未行动的玩家才显示“等待行动”。弃牌、全下沿用原有跨街保留规则。

Web/App 和微信现在共用 `src/ui/recent-action.js`。过牌显示直接读取引擎的本街 `checked` 状态，不再完全依赖 `action` / `lastAction` 缓存文案。引擎在跟注、加注和换街时已有相应状态更新，本次没有修改规则、筹码、机器人决策或定时器。

静态截图无法单独证明过牌是在同一街被清除，还是已进入下一街。本次回归明确覆盖了同街连续行动，以及 `checked` 仍为真但缓存文案缺失的边界，避免把正常换街重置也改成保留上一街动作。
