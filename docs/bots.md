# 电脑训练风格

应用使用原创插画和训练风格，不展示真人姓名、履历、赛事链接或肖像。均衡使用文字头像。所有策略参数是作者设计的训练控制，不是真人统计或 GTO 解。资料复核、候选合并和验证口径见 [本轮研究](style-research-2026-10-20.md)。

量化结果、失败轮次、三位 AI 反馈和各端验证范围见[完整验收报告](style-validation-2026-10-20.md)。

## 当前风格

当前保留包含均衡在内的8种：

- 均衡：常规范围与尺度，价值下注和控池的基准。
- 多街施压：较宽入池，在合适局面持续施压，不局限于听牌。
- 宽松取值：更宽地低价跟入，减少边缘再加注，强牌扩大价值投入。
- 范围纪律：更选择性地入池与防守，入池后正常取值。
- 强牌诱导：安全深筹码局面保留对手进攻，危险或浅码时保护牌力。
- 小注控池：将合适的小持续下注、薄价值和中等牌力控池组织成一条路线。
- 听牌施压：有真实成牌潜力时主动争夺，保持价格、多人和全下边界。
- 延迟进攻：合适的低价有位置Float后，在对方下一街示弱时争夺。

17→9→6→4是此前测量候选的收缩过程。用户指出合并过多后，明确选择约8种、优先保证主风格区分，因此重新拆出独立战术，仅将小注持续作为小注控池内的路线。八种的新模拟与盲评见[10月21日记录](style-validation-2026-10-21.md)。旧四种的量化与体验不得作为八种已通过的证明。

历史标签通过profile-id.js迁移，筹码、牌序和统计不因改名改写。当前混合风格包含全部8种，手动选择保持优先。此前已经保存为四种的选择不凭空猜回原始细分角色，用户可以手动选择恢复的风格。

## 决策与难度

poker.js 的 botDecision 构造本人的底牌、已出现公共牌、位置、公开历史、合法动作和公开范围权益估计，chooseBotAction 只接收这个视角。它不能读取对手隐藏牌、未来牌序、复盘输入或最终赢家。

轻松以价值和价格为主。标准加入位置、持续下注、听牌半诈唬、控池、诱导及受限的低价 Float。进阶继续加入阻断诈唬、薄价值、挤压和选择性领打。风格只有在当前难度允许的能力和合理局面中生效。情绪是独立的合成机制，不代表任何真人性格。

公开范围权益是抽样估计。多人响应、全下边池、赔率和牌型支持分别检查；它不是正 EV 证明。规则、退款、资格、合法加注和分池继续由原引擎处理。所有下注与结算使用每局的整筹码单位。

普通行动只计划一次，定时等待后执行同一策略。下一手、重打、重置或后台取消旧任务。重打恢复原手设置并撤销原结果一次；新设置仍在下一手生效。

## 测量与重跑

VPIP、PFR 统计整手事件，三次加注率使用真实机会数。特色行为使用具体可行动局面作为分母，条件重放决策与完整牌局分别报告。中奖金额、长期胜率和特色辨识不混为一个指标。

完整审计：

```sh
node scripts/style-audit.mjs --mode=matrix --hands=80 --out=.artifacts/style-audit-local
node scripts/style-audit.mjs --mode=summary --out=.artifacts/style-audit-local
node scripts/style-audit.mjs --mode=probes --corpus=.artifacts/style-audit-local --out=.artifacts/style-probes-local
```

默认需要先保存校准前源码快照，或用 --reference-root 指定已有快照：

```sh
mkdir -p .artifacts/style-audit-2026-10-20/baseline
git archive 17c0271 src | tar -x -C .artifacts/style-audit-2026-10-20/baseline
```

覆盖全部风格、5–9 人、标准与进阶、3 组种子，生产权益抽样精度，固定历史选择器与历史参数陪测策略，每手重置为 100 BB，无情绪。--root 可指定固定的历史源码快照。manifest 记录源码与测量程序摘要、人数、难度、种子和分母。每个决策的权益抽样与动作随机数分流，双方复用相同种子规则；不把因策略分歧而走出的不同后续局面当成逐手相同对照。

匿名 AI 观察包：

```sh
node scripts/style-blindpack.mjs --hands=100 --out=.artifacts/style-blind-local
```

--hands指定每代号的连续观察手数，默认50。每个评审目录只含匿名连续牌局。private 中的映射和原始策略资料不得给盲评者。不同代号使用不同牌序，避免跨会话摊牌泄漏。AI 盲评只代表公开牌谱下的 AI 判断，不替代真人试玩或原生界面运行验收。
