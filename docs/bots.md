# 电脑训练风格

应用使用原创插画和训练风格，不展示真人姓名、履历、赛事链接或肖像。均衡使用文字头像。所有策略参数是作者设计的训练控制，不是真人统计或 GTO 解。资料复核、候选合并和验证口径见 [本轮研究](style-research-2026-10-20.md)。

量化结果、失败轮次、三位 AI 反馈和各端验证范围见[完整验收报告](style-validation-2026-10-20.md)。

## 当前风格

当前保留包含均衡在内的8种：

- 均衡：常规范围与尺度，价值下注和控池的基准。
- 大注强攻：较宽入池，在合适的后街使用大尺度取值与有依据的诈唬。
- 宽松取值：更宽地低价跟入，减少边缘再加注，强牌扩大价值投入。
- 范围纪律：更选择性地入池与防守，入池后正常取值。
- 跟注诱导：低成本且范围允许时偏向跟入，安全强牌保留诱导，危险或浅码时保护牌力。
- 小注控池：将合适的小持续下注、薄价值和中等牌力控池组织成一条路线。
- 听牌施压：有真实成牌潜力时主动争夺，保持价格、多人和全下边界。
- 后位争夺：前位收紧、后位主动争夺未开启底池，Float与延迟进攻为有位置时的补充。

10月24日定向调整：均衡在标准/进阶、至少30BB的未开启底池按位置筛选后偏向正常开池，减少先跟入再被动支付。后位争夺额外在可玩牌、足够深筹码和至多两位真实跟入者时做后位隔离，并在对手已经实际过牌的干燥翻牌或转牌上择机试探。共同的昂贵弱成牌保护覆盖“口袋对子加公共对子”的情形。价格、听牌、强牌、全下与合法加注保护保留。效果与未通过项目见[定向打磨记录](style-refinement-2026-10-24.md)。

后续线路优化统一了均衡与后位争夺的战术抽样，避免已经选中的合理行动被通用随机分支再次取消。后位争夺按真实历史与转牌改善继续或停手，均衡组织常规价值、定价防守和控池。自然交锋密度与稳定辨识仍未达标，最终5400次完整执行及两阶段AI反馈见[战术线路复核](style-lines-validation-2026-10-24.md)。

17→9→6→4是此前测量候选的收缩过程。用户指出合并过多后，明确选择约8种、优先保证主风格区分，因此重新拆出独立战术，仅将小注持续作为小注控池内的路线。八种的新模拟与盲评见[10月21日记录](style-validation-2026-10-21.md)。旧四种的量化与体验不得作为八种已通过的证明。

历史标签通过profile-id.js迁移，筹码、牌序和统计不因改名改写。当前混合风格包含全部8种，手动选择保持优先。此前已经保存为四种的选择不凭空猜回原始细分角色，用户可以手动选择恢复的风格。

## 决策与难度

poker.js 的 botDecision 构造本人的底牌、已出现公共牌、位置、公开历史、合法动作和公开范围权益估计，chooseBotAction 只接收这个视角。它不能读取对手隐藏牌、未来牌序、复盘输入或最终赢家。

轻松以价值和价格为主。标准加入位置、持续下注、听牌半诈唬、控池、诱导及受限的低价 Float。进阶继续加入阻断诈唬、薄价值、挤压和选择性领打。风格只有在当前难度允许的能力和合理局面中生效。情绪是独立的合成机制，不代表任何真人性格。

情绪触发规则：单手净损失至少 25 BB 或连续三手各净损失至少 5 BB 时，奇数座位进入“急于追回”、偶数座位进入“收紧避险”；连续两手盈利且本手净赢至少 10 BB 时进入“连胜自信”；最近 4 手中有 3 手面对同一对手加注后弃牌（中间穿插其他加注者不清零）时进入“受压反击”。轻微波动持续 3 手、触发后冷却 4 手；明显波动持续 4 手、冷却 2 手，情绪未结束时也可能再次触发或被新情绪替换。模拟实测（5 与 9 人、均衡与混合风格、标准难度、每手重置 100 BB）：轻微波动下每个电脑约 95% 的手牌保持平稳，急于追回、收紧避险、连胜自信各约每百手 0.5–1 次，受压反击约每百手 0.5–0.6 次；明显波动下前三种约提高到 1.7 倍。

公开范围权益是抽样估计。多人响应、全下边池、赔率和牌型支持分别检查；它不是正 EV 证明。规则、退款、资格、合法加注和分池继续由原引擎处理。所有下注与结算使用每局的整筹码单位。

普通行动只计划一次，定时等待后执行同一策略。下一手、重打、重置或后台取消旧任务。重打恢复原手设置并撤销原结果一次；新设置仍在下一手生效。

翻前重注与主动全下由`bot-preflop-commitment.js`和公开范围共同控制。标准/进阶翻前承诺使用512次抽样并去掉额外噪声，实际已闭合单挑的4-bet与多人已跟住分别处理。短筹强牌可直接推注，深筹码不再首次推注（只有AA/KK会这样打，金额会暴露牌力），多次加注后的强价值反推更积极，价格不足、全下对手和未重新开放的加注保护保留。固定条件、自然新旧对照和玩家推注挑战分别见[验证记录](preflop-pressure-validation-2026-10-24.md)。

## 开池尺度

翻前首个主动加注（均衡与后位争夺的首次开池、后位隔离和通用价值/诈唬开池）统一由`bot-style.js`的`botOpenRaiseTo`计算。同一风格在同一位置与跛入人数下只用一个非全下金额：AA、KK、同花连张、偷盲、脏牌开池和7-2开池金额相同，金额本身不泄露牌力。

- 风格基准：默认2.5BB；进攻轴（含情绪调整）高于80为3BB；小注控池为2BB。
- 身后尚未行动的席位：至少4席加1BB（5人桌及以上的UTG、6人桌HJ、9人桌UTG至HJ），3席加0.5BB，BTN不加；人数再多也不继续放大。
- 盲位翻后无位置加0.5BB。隔离跛入者加1BB，再每位跛入者加1BB。
- 以半个大盲（即小盲，也是筹码面额）为步长，按本局大盲换算，再由`legalRaiseTo`取合法值，并保留原有非全下与起始筹码15%预算约束。

均衡在100/200的5人桌：UTG 700（3.5BB）、CO 600、BTN 500、SB 600；BTN隔离一位跛入者900，CO隔离一位跛入者1000。翻前再加注统一由`botReraiseTo`计算：有位置3倍、无位置4倍，每位平跟者再加1倍，4-bet为2.3倍；价值、轻3-bet与挤压同额。深筹码不再首次全下，短筹推注保持不变。

取舍：不单独放大强牌。只给AA更大尺度，对手看金额即可读出牌力；整体放大开池范围的尺度，强牌同样获得更大底池，偷盲与诈唬开池也不暴露。代价是边缘开池被再加注或被跟注后损失更多。

本地实测：5人桌、每手重设100BB、关闭情绪、标准难度、每种风格1000手，策略种子781、牌序种子711，其余座位为同风格，玩家座位使用均衡策略。“前”为本次修改前的同一分支源码；UTG尺度为该风格自己的非全下开池；跟注人数是开池后、出现再加注前的平跟次数。

| 宽松取值 |        2.5→3.5BB |       3.10→3.04 |    3.66→3.27 |  72.7%→55.4% |
| 范围纪律 |        2.5→3.5BB |       1.05→0.91 |    2.37→2.36 |  16.0%→13.6% |
| 跟注诱导 |        2.5→3.5BB |       2.51→2.22 |    3.17→3.11 |  63.7%→54.0% |

## 统计画像校准（10月25日）

此前各风格只有入池率拉得开：加注率、3-bet、被3-bet后弃牌、持续下注和翻后进攻性（AF）几乎相同。原因是通用分支盖过了风格：翻后价值下注设了0.75–0.92的保底概率，所有风格的`valueAttack`都在0.7–0.9；低价入池给每种风格同样的加成；已选中的诈唬还要再过一次通用进攻抽签；起手牌排序把54s排在后21%、低于Q7o和K2o。

本轮先为每种风格写目标统计画像（`scripts/style-targets.mjs`），再用测量结果校准。目标是作者设定的训练画像，按5–6人桌、100BB、标准/进阶难度编写，不是任何真人的测量频率。均衡定位为标准紧凶型（TAG）。

主要改动（规则、合法动作、整筹码与保护边界不变）：

- 起手牌排序改用Chen公式（`startingValue`），同花连张与小对子高于不同花的大间隔高牌。
- 低价入池只给可玩牌（对子、同花A、同花连张、高张）；垃圾牌不再因只补1BB就跛入。已有人跛入时，可玩牌仍可跟着便宜看牌；宽松取值、跟注诱导和小注控池保留主动先跛入。
- 面对单次开池的跟注随尺度平滑收窄（2.5BB约0.93倍范围、4BB约0.7倍、6BB约0.4倍），窗口延长到7BB，不再在4BB处突然关闭。开池者位置靠后时防守放宽；深筹码的小对子和同花连张按隐含赔率跟注；任何风格都不把AQ+和99+弃给一次小开池。
- 3-bet防守窗口与再加注尺度一致：至多20BB、开池的5倍、跟注不超过14BB、赔率不超过0.40、有效后手至少`max(20BB, 6×跟注额)`；原加注者的防守宽度按风格设定。
- 翻后：价值下注频率按风格（被动风格更多过牌/跟注）；翻前加注者的持续下注、转牌与河牌继续下注、跛入底池中被过牌后的试探下注都按风格设定一次抽签；风格自己选中的半诈唬或诈唬不再被第二次通用抽签取消。
- 面对下注时没有对子也没有听牌，除非风格会Float，否则弃牌；激进风格偶尔用诈唬加注回应。同一对手连续多街下注会逐步收窄弱对子的跟注，跟到底型风格扣减更少。
- 跛入后不再“先跛后大加注”，只有超强牌或跟注诱导例外。
- 统一的翻前再加注尺度见上节；翻后诈唬或半诈唬加注约为对方下注的2.6倍；深筹码不再首次全下。

## 测量与重跑

VPIP、PFR 统计整手事件，三次加注率使用真实机会数。特色行为使用具体可行动局面作为分母，条件重放决策与完整牌局分别报告。中奖金额、长期胜率和特色辨识不混为一个指标。

完整审计：

```sh
node scripts/style-audit.mjs --mode=matrix --hands=80 --out=.artifacts/style-audit-local
node scripts/style-audit.mjs --mode=summary --out=.artifacts/style-audit-local
node scripts/style-audit.mjs --mode=probes --corpus=.artifacts/style-audit-local --out=.artifacts/style-probes-local
```

默认需要先保存校准前源码快照，或用 --reference-root 指定已有快照：

```sh
mkdir -p .artifacts/style-audit-2026-10-20/baseline
git archive 17c0271 src | tar -x -C .artifacts/style-audit-2026-10-20/baseline
```

覆盖全部风格、5–9 人、标准与进阶、3 组种子，生产权益抽样精度，固定历史选择器与历史参数陪测策略，每手重置为 100 BB，无情绪。--root 可指定固定的历史源码快照。manifest 记录源码与测量程序摘要、人数、难度、种子和分母。每个决策的权益抽样与动作随机数分流，双方复用相同种子规则；不把因策略分歧而走出的不同后续局面当成逐手相同对照。

从测量协议v2.4开始，`style-audit.mjs`每手创建全新的引擎局面并保持按钮轮换，避免仅恢复筹码却继承上一手的淘汰或整局结束状态。5–9人的实际发牌席位均检查。此改动只影响独立100BB抽样，产品中的连续牌局、淘汰和补码规则不变。历史v2.3结果保留原协议标识，不能当作v2.4重跑结果。`--opponents=current`的manifest会记录实际当前陪测策略，与默认历史冻结陪测分别报告。

匿名 AI 观察包：

```sh
node scripts/style-blindpack.mjs --hands=100 --out=.artifacts/style-blind-local
```

--hands指定每代号的连续观察手数，默认50。每个评审目录只含匿名连续牌局。private 中的映射和原始策略资料不得给盲评者。不同代号使用不同牌序，避免跨会话摊牌泄漏。AI 盲评只代表公开牌谱下的 AI 判断，不替代真人试玩或原生界面运行验收。
