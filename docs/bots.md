# 机器人风格与情绪模拟

十六种具名风格来自公开牌局的定性归纳。数字是本项目的训练参数，**不是本人真实 VPIP、PFR 或长期行为统计**，也不是 GTO 求解结果。Peter 指 HCL 常客，阿宝使用 KPC 的 A Bao 标签，不推断本名或职业身份。

十六种具名风格使用已核对人物的真实头像。风格卡片与座位分配预览即时显示选择，牌桌头像取本手实际风格，座位配置自动保存，下一手生效、重打保持原头像。均衡风格保留文字头像；加载失败时回退为文字，尺寸与选择不变。图片来自本地静态资源，来源、署名及许可状态见 [头像来源](../public/portraits/CREDITS.md)。

设置按练习选项、难度、情绪模拟、牌手介绍和座位分配组织；使用说明常显在训练参数对比下方。难度立即生效，情绪强度紧邻难度模块，座位风格与情绪变动自动保存、下一手生效。点选牌手只预览介绍，不改变任何座位分配。移动端点击牌手时，详情以水波展开动画覆盖在当前选择区域内，无需滚动到卡片下方；关闭详情恢复选择卡片与原滚动位置。启用减少动态效果时跳过展开动画。宽屏仍在选择卡片下方常驻展示详情。

使用说明集中解释生效时间、训练参数和公开资料的局限；完整的独立制作、非真人复刻、无官方合作背书及素材使用边界见 [具名训练原型说明](persona-notice.md)。

- 入池宽度：1326 种两张牌组合按一套起手牌启发式排序，基准候选比例 `0.16 + width × 0.42`，随后按位置、人数和前序加注调整。它不等于实际 VPIP；跟注价格、权益与后续行动仍会过滤候选牌。
- 进攻：在有价值下注或诈唬机会时提高加注混合概率，另影响开池尺度。
- 诈唬：增加合理场景的纯诈唬与听牌半诈唬混合概率；多人底池压低纯诈唬。不得把条件概率当成总体诈唬率。
- 跟到底：小幅调整边缘跟注权益阈值与面对大尺度下注的弃牌倾向。
- 强牌诱导：只在安全牌面、有较高自有权益且可免费过牌时增加慢打；危险牌面优先价值与保护。
- 下注尺度：常用翻后区间；加注按照跟注后底池估算增量，最终夹在引擎合法最小值和最大值之间。阿宝原型有小翻牌持续下注、大转牌半诈唬的分支；Peter 的附加规则小对子推入不移植到普通桌。区间不是所有下注的硬上限。

## 当前牌面与行动顺序

`poker.js` 在行动前建立当前席位的公开视角。`public-action-context.js` 区分自然首轮顺序、身后首次行动席、实际待响应席、已行动但被加注重新要求响应的席位，以及仍有摊牌资格的玩家。大盲首次行动后面没有新人，不意味着早位开池者已经无需回应再加注；已全下玩家参与分池权益，但不计入待行动人数。

`public-ranges.js` 按各席位的位置、最近实际入池动作及当时已有几次加注建立权重，并结合公开成牌／听牌和下注尺度。尚未回应后来的再加注，不会提前得到对应防守范围。范围是训练假设，不是测得的真人频率；公开动作可让范围更紧，不能只按弃牌人数给底牌增加固定胜率。

普通行动使用 `public-equity.js`，重注承诺／全下沿用 `bot-allin.js`。二者分别记录独胜、平分和损失的估计比例，行动价格比较使用按有资格的主池／边池计算的预期底池份额。翻后所有仍在场的对手参与；翻前已有入池者参与，无人入池时先估计一位未来跟注者，并另外计入其他待响应席的风险。该条件假设会记录在本次私有判断中，不把全部尚未行动席当成确定摊牌者。

入池候选还按身后首次行动人数收紧；跟注价格经过范围权益和响应风险检查。少人局中有成牌或听牌支撑、且权益覆盖价格的牌可以继续承受较大下注。少了对手也可能遇到更强范围，因此不保证更宽地跟重注／全下。

范围抽牌最多提出 24 次候选，仍未接受时按当前合法牌池的同一权重完整累计抽取。不会因范围很窄退回均匀抽牌。缓存仅复用相同公共牌面与候选底牌的纯评分／补牌特征，不保存判断、价格、范围或随机状态。历史测量表描述对应旧版本；运行测量命令会得到当前策略的结果。

## 配置生命周期

`src/ui/opponents-controller.js` 管理对话框和 `noir-opponents-v1` 浏览器偏好，保存席位 1–8 的白名单风格 ID、情绪强度及混合阵容的自动分配归属，不保存牌局、底牌或牌序。未入座席位的配置仍保留。座位选择、情绪修改和混合阵容均立即写入偏好并更新待应用配置，关闭设置不撤销这些修改；查看牌手介绍不写入配置。混合阵容是可取消的选中态：只随机填充当前桌上仍为均衡的座位，取消只将这些自动分配恢复为均衡；手动选择（包括重新选择相同风格）会取得该席位的归属，取消混合不会撤销它。未入座席位的手动配置仍保留。

`table-controller.js` 保存待应用设置，仅 `nextHand()` 调用 `applyBotSettings()`。当前手不变；`retryHand()` 不应用待设置。人数变化或重新练习创建新游戏后再次应用配置。换风格时该座位的实测样本归零。

每个牌桌座位的人物标签和头像直接取自当前实际 `botProfile` 对应的完整风格目录。手机桌将头像、风格和筹码放在同一行；各尺寸的底牌查看按钮紧跟姓名行的位置标签，从发牌起为按钮保留位置，结算和查看底牌不会改变信息框尺寸。9 人桌也保留人物标签和头像。设置中的座位卡只保留姓名、头像与风格选择，不再重复展示当前风格、模拟情绪及其触发原因、VPIP/PFR。设置的信息模块常显说明自动保存与下一手生效，当前牌桌继续使用本手实际风格。

`startHand()` 在记录重打基线前衰减情绪、重置本手统计标记；`restartHand()` 从原快照恢复风格、强度、情绪和统计，撤回原结算。尚未生效的配置仍留在 UI 中，供下一手使用。

## 情绪触发与衰减

情绪是一套合成场景机制，不归因于具名真人。默认轻微波动，可选择关闭或明显波动。

| 情景     | 触发规则                                  | 状态                               |
| -------- | ----------------------------------------- | ---------------------------------- |
| 大池失利 | 单手净损失至少 25 BB                      | 奇数席位急于追回，偶数席位收紧避险 |
| 短期连败 | 连续三手各净损失至少 5 BB                 | 同上                               |
| 连胜     | 连续两手各净赢至少 5 BB，且本手至少 10 BB | 连胜自信                           |
| 连续受压 | 连续三手面对同一对手加注后弃牌            | 受压反击                           |

情绪使用机器人自己的净损益与公开下注历史。净损益包含未被跟注的退款，边池获利不会因为未拿主池而被判负；无受压的一手或跟注中断连续受压计数。没有使用对手隐藏底牌来判断“被诈唬”或“被逆转”。

触发后维持接下来两手，开始下一手时衰减，四次开手衰减后才结束冷却。轻微模式是明显模式偏移的一半。激进状态增加入池、反击、边缘跟注与部分下注尺度；避险状态收紧。所有状态仍经过同一合法动作检查，不强制每手全下。

后位未开池时，同花连张、同花小结构牌、小对子和同花 A 可以在低投入范围内混合开池与平跟；已有人跛入时不使用偷盲分支。一次小开池后的继续范围仍按价格、位置、有效后手和风格筛选，少量同花小 A 在后位保留阻断牌再加注，不扩展到连续再加注或全下。

翻后先判断便宜听牌、防守和半诈唬候选，再执行普通权益弃牌检查。直接顺子／同花成牌候选按下一张牌计算，并对对子牌面和多人底池折扣；不是保证获胜的 outs。少人干燥牌面、有主动权或延迟进攻条件时可以低频施压；大额价格、短后手、多人和全下仍会收紧。诈唬抽样命中但进攻抽样未命中时，不会因此把空气牌变成机械平跟。上述修改共享于四端，实际动作记录保留候选、价格、抽样和最终动作。

## 策略信息边界与统计

### 按局势生成行动时间

`engine/bot-timing.js` 为每次已选定的动作生成 1.2–8 秒的合成等待时间，替代固定的 650–1100 毫秒。接近范围或跟注门槛、听牌与危险牌面、反复加注／过牌加注／多街施压、多人及相对位置、有效后手和筹码承诺都会增加需要权衡的部分；常规动作通常较快。权益门槛的接近度是启发式量，不是求解器置信度。

风格参数与座位节奏、当前合成情绪影响时间分布。独立的时间随机和低概率快行动／刻意停顿让价值下注、诈唬、慢打和弃牌的时间区间重叠；没有某牌型一定快或一定慢的固定表。这里不声称复刻具名真人的思考速度或识别其真实心理。

只读取本人的底牌、已发公共牌、公开下注线和公开筹码。翻后相对位置按仍能行动的座位顺序计算；多人有效后手不让短全下者的零筹码压掉其他深筹码对手。演戏抽签和时间因素不对正在游戏的用户公开。实际执行后，计划时间、实际等待时间与加速标记只写入对手的私有执行记录，仍不进入玩家决策评级。

普通行动采用 `planBotTurn()` → 等待 → `executeBotTurn()`，只生成一次策略，不在等待结束后重新抽动作。同一轮再次安排不会重置计时；修改难度重新计划，风格配置仍下一手生效。重打、下一手和重置取消旧任务。“立刻发完”立即执行仍有效的待定计划，剩余对手直接行动，无需等待思考时间；结算、退款和补满五张公共牌的规则保持原样。

`poker.js → botDecision()` 构造本人底牌、公共牌、公开历史、位置、价格、合法动作、自有权益和当前风格/情绪的视角，交给 `chooseBotAction()`。策略模块不接收完整游戏对象，无法读取其他人的隐藏牌、剩余牌序、复盘输入或最终赢家。普通定时行动与“立刻发完”共用此入口。

权益按公开位置与下注线加权的合法对手牌抽样估计，尚未构建真人专属对手范围。跟注价格使用可争夺金额；多人和复杂边池的策略权益仍取决于范围假设，而规则、资格与分池由原引擎精确处理。复盘另保留随机范围对照，不把风格标签当成已知底牌。

底层仍记录实测 VPIP = 已完成牌局中翻前自愿跟注/加注的手数 / 已完成手数，实测 PFR = 翻前至少加注一次的手数 / 已完成手数，供策略测量和规则回归使用；设置座位卡不再展示这些统计。强制盲注不计，每手各计一次；只表示该机器人在本次练习中的表现。重打撤销被覆盖的一次样本，换风格或重新练习归零。

回归覆盖：设置清洗、隐藏信息访问保护、5–9 人各风格/情绪的合法行动与筹码守恒、短全下不重开加注、情绪阈值与冷却、连续受压中断、风格实际行为差异、退款、VPIP 分母、重复重打、座位配置持久化与移动布局。

## 低成本入池调整与测量

翻前分别计算开池、条件跟入与价值再加注候选。新增跟入范围不扩大价值再加注范围，避免边缘牌入池后连续反加注，把整桌再次赶走。面对已有加注时，价值再加注候选按独立的 `0.035 + width × 0.085`、加注次数与后位修正计算；强牌和原有独立诈唬分支仍可进攻。

- 未加注、最多补一个 BB：原范围增加 `0.14 + width × 0.20`。对子、合适同花连张／一张间隔、同花 A 或有合理踢脚的同花高张，在已有跛入者时再增加有限补偿。新增投入不超过自身筹码的 8%，不能把全部剩余筹码的短跟注当廉价入池。
- 仅一次小开池：开池及跟注额不超过 4 BB、投入不超过自身筹码的 8%、没有全下者，且跟完后的有效后手至少为 `max(20 BB, 15 × 跟注额)`，才启用价格／位置／牌型／风格修正的跟入范围。有效后手取自身跟完后的余额与开池者余额中的较小值，不用无关深筹码玩家替代短开池者。大盲保留已投入的价格优势；弱杂色 A 减少范围补偿。已有跟入者只给适合多人底池的候选有限增益，按不同且仍未弃牌的玩家计数。
- 标准／进阶的小尺度 3-bet：只在本街恰好两次加注、总额不超过 10 BB 且不超过首次开池的三倍、新增投入不超过 7 BB、总跟注压力不超过 10%、当前赔率不超过 28%、无人全下，跟完后的有效后手至少 `max(20 BB, 8 × 跟注额)` 时使用独立防守范围。自身起手牌、位置、风格及先前投入共同决定继续；KQ 等可玩牌不再只因对全桌随机牌的低摊牌权益机械弃牌。轻松难度保留原行为。
- 更大的 3-bet、4-bet、多次加注、大开池、全下或短后手：不使用低价范围候选的补偿，保留范围、权益和压力过滤。低价跟入候选现在同样核对公开范围权益与价格，并增加实际待响应席的风险缓冲；未入池席的未来参与按条件假设处理。这是训练启发式，不是正 EV 或职业级决策证明。

对手复盘区分 `affordable-entry`、`affordable-open` 和 `small-reraise-continue`，记录有效后手、已跟入人数、候选牌型、继续范围及再加注范围。本轮公开范围判断同时检查价格；旧记录没有此估计时仍保留原有解释，不编造当时未执行的计算。原则参考 [PokerStars · Calling Opens](https://www.pokerstars.com/poker/learn/lesson/calling-opens/) 的价格、隐含赔率与位置讨论；具体数值是本项目校准参数，并非文章给出的最优范围。
