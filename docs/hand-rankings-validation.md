# 牌力表入口与整体回归记录（2026-10-17）

本次变更在操作提示行右侧增加“牌力表”，覆盖 Web、iOS、Android 和微信。点击打开现有指南，将牌型强弱排序及同牌型比较说明定位到固定标题下方；重复打开重新定位，普通指南入口仍从开头打开。支持全部 11 种 Web/App 语言。

追加手机背景音乐调整：桌面资源保持原样，App、触摸浏览器和微信改用同源增强母带，实测由 −18.97 LUFS 提升到 −13.67 LUFS（+5.30 dB），峰值 −6.94 dBTP，循环长度不变。微信动作音效期间短暂降低音乐音量，650 ms 后恢复，后台/静音/释放均取消恢复计时。新母带浏览器解码、混音峰值、循环、开关及入口专项 20/20 已通过；原生重新编译与安装验收正在追加。下文 v2 整体回归是此次音乐增补前的基线，不表述为增强母带安装验证。
