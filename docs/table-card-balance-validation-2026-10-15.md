# 牌面比例、姓名与箭头验证（2026-10-15）

继续同一功能分支 `codex/game-records` / PR #45，面向 `main`，保持草稿。本轮按用户最新要求只回归 Web 运行；共享 Web/App 源码和微信原生页面均已同步修改，未重做原生编译、安装或微信 DevTools／真机验收。

## 行为

- 位置标签增加上下和左右内边距，BTN 保留更宽的左右边距。
- 公共牌优先一排。先分别计算一排与两排的可用空间，再比较缩放后的实际牌宽；一排太小且两排有明显收益时使用两排，避免为了放大牌面把整个牌桌缩得过小。
- 公共牌与玩家／牌桌左右边界预留 16 个布局像素，底牌与玩家预留 18 个布局像素。实际屏幕间距随稳定的整桌比例缩放。多人桌允许缩小底牌，双向限制公共牌和底牌的比例，保留原有首屏操作预算。
- 手机姓名基础字号增加 1px，字形上方再补 1px 内部留白，资料框外尺寸不变。
- 没有看牌图标时释放图标位置，让姓名尽量完整显示；必要时仅轻度横向适配姓名，字体高度不变。低于 75% 宽度才能放下的极长姓名仍使用省略号；出现看牌图标时允许省略号。微信通过隐藏的原始姓名文本测量实际字体宽度，沿用旧测量取消机制。
- 顶部资源菜单和局折叠箭头取消圆圈；局和手的箭头按整项垂直居中。轮换过渡、键盘菜单和减少动态效果保持可用。
- 发牌、结算、显示牌型以及浏览历史不改变同一视口下的桌高与牌面布局。
