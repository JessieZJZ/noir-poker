## 当前八种与核心区别

| 风格     | 主要训练行为                                     | 最需要避免的重合                           |
| -------- | ------------------------------------------------ | ------------------------------------------ |
| 均衡     | 常规范围、尺度与价值进攻的基准                   | 不再同时吸收专门的控池与Float偏好          |
| 大注强攻 | 更宽参与，合适的后街使用大尺度取值与有依据的诈唬 | 不把中等牌力或无支持的空气牌强行变成大注   |
| 宽松取值 | 更愿便宜跟入，成强牌后扩大价值投入               | 与进攻型区分主动性与被动支付               |
| 范围纪律 | 更严格的起手牌与昂贵防守，入池后正常取值         | 不再靠高诱导率充当身份                     |
| 跟注诱导 | 低成本、已准入的非优质牌偏跟入，安全强牌保留诱导 | 不绕过价格、范围、湿面、多人和全下保护     |
| 小注控池 | 小尺度持续下注、薄价值与中等牌力控池             | 已选择的合适小持续下注不再被控池随机数取消 |

| 后位争夺 | 前位收紧、后位主动争夺，Float和延迟进攻为补充    | 不能靠昂贵空气跟注或无限再加注制造特色     |

小注持续下注作为小注控池的一条路线，不单独增加第九种。新角色继续使用原有成熟插画，均衡保留文字头像。应用不展示真人对应关系或赛事资料。

共同质量调整仅提高已经被价值判断允许的行动的正常取值倾向，不扩大价值准入，不绕过陷阱、控池、湿面、多人和全下保护。训练风格仍是启发式，不声称最优解或长期盈利。
