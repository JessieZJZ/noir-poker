# 八种训练风格 · 重新定位与验证

用户确定包含均衡在内约8种，优先保证主风格区分明显。当前八种已恢复独立选项，模拟和新盲评正在进行，尚未宣称达到体验目标。此前四种候选的结果见[10月20日记录](style-validation-2026-10-20.md)，不外推为八种通过。

## 当前八种与核心区别

| 风格     | 主要训练行为                             | 最需要避免的重合                           |
| -------- | ---------------------------------------- | ------------------------------------------ |
| 均衡     | 常规范围、尺度与价值进攻的基准           | 不再同时吸收专门的控池与Float偏好          |
| 多街施压 | 更宽参与，选择有支持的后街继续施压       | 不依赖听牌才表现进攻                       |
| 宽松取值 | 更愿便宜跟入，成强牌后扩大价值投入       | 与进攻型区分主动性与被动支付               |
| 范围纪律 | 更严格的起手牌与昂贵防守，入池后正常取值 | 不再靠高诱导率充当身份                     |
| 强牌诱导 | 安全、足够深且对手可行动时保留其进攻     | 湿面、浅码、多人和全下边界不放开           |
| 小注控池 | 小尺度持续下注、薄价值与中等牌力控池     | 已选择的合适小持续下注不再被控池随机数取消 |
| 听牌施压 | 有真实继续潜力的听牌更积极争夺           | 价格过高、全下和多人限制保留               |
| 延迟进攻 | 合适低价有位置先跟，对手下一街示弱时争夺 | 不能无条件用空气跟注制造特色               |

小注持续下注作为小注控池的一条路线，不单独增加第九种。新角色继续使用原有成熟插画，均衡保留文字头像。应用不展示真人对应关系或赛事资料。

共同质量调整仅提高已经被价值判断允许的行动的正常取值倾向，不扩大价值准入，不绕过陷阱、控池、湿面、多人和全下保护。训练风格仍是启发式，不声称最优解或长期盈利。

## 新一轮匿名体验

观察每代号100连续手，三位全新AI各自冻结自由稿后，选两个最混淆代号各固定100手自然互动，最后才给分类菜单。Hero必须逐公开状态自主决定，不用固定范围表或自动策略辅助，不筛牌、强跟或追加到特色出现。此轮8代码的观察合计2,400手，计划直接互动600手，二者不能混成同一分母。

陪测统一为产品默认均衡，等同玩家只替换一个电脑席位；观察与互动使用同一配置。此前宽松/进攻陪测的结果保留，不能将换配置后分数变化全归因于策略改善。分类目标至少80%，三位自然策略互动体验均至少4/5。AI不是真人，不承担UI/设备或学习效果验收。
