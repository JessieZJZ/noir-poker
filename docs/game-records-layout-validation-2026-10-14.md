# 对局记录布局修订验证（2026-10-14）

本轮继续更新 PR #45，落实用户的截图反馈。此前交付与失败边界见 [初版验证](game-records-validation-2026-10-14.md)；本页记录本轮源码和新的实测结果，不继承旧安装包的通过结论。

## 改动

- 历史结算页使用实际游戏牌桌的结构、`table-scene.js` 玩家渲染、`createSettlementLayout` 和 `createPlayViewport`。移除固定 440×650 缩放及专用卡牌、头像、座位尺寸，避免玩家卡牌与公共牌相挤。
- 首次不显示额外文案，重打为彩色“重打1／重打2”标签；零净变化不显示“持平”或“赢”。局和手均显示正负号，零为 `+0`，保留用户选择的 K/M 或完整数字格式。
- 历史场景仍只读，浏览时继续实时练习。独立前缀 ID、底池明细和看牌操作指向历史视图；离开历史页销毁其观察器和待执行排布帧。持久化字符串继续转义。
- 微信历史与实时页本来就共用同一模板与布局；同步列表表现，并增加同一状态的几何对照。
