# 新手引导

顶部“玩法指南”下拉框的“新手引导”让第一次玩的人在真实牌桌上边打边学，约五分钟，打完就能上桌。

## 课程

| 手     | 位置 | 学什么                                                                 | 牌局结果                     |
| ------ | ---- | ---------------------------------------------------------------------- | ---------------------------- |
| 第一手 | BTN  | 底牌、底池、筹码单位、盲注、位置、行动顺序、过牌、跟注、下注、牌型大小 | 摊牌，同花赢一对             |
| 第二手 | CO   | 庄位移动、好牌主动加注、累计总额、踢脚、未被跟注退还                   | 对手弃牌，不亮牌赢下底池     |
| 第三手 | UTG  | 烂牌弃牌、立刻发完、结果不等于决策、已投入筹码                         | 练习补牌只展示，不影响结算   |
| 第四手 | BB   | 全下、边池、谁有资格争哪个池                                           | 主池归 Mia，边池与未跟注归你 |
| 第五手 | SB   | 自己做全部决定，教练只讲局面                                           | 随机发牌，“轻松”难度真实对手 |

每手结束有三条要点，可以“再打一遍”；全部结束后给出上桌清单。第五手可以反复再打。第一、二、四手各有一道必须答对的题，答错给提示，不扣分。

筹码单位按牌桌实际显示讲解：起始筹码是 K 就解释 K，是 M 就解释 M；大盲带 K 时再解释 K，不带字母时说明这就是实际筹码数。随后一步固定给出换算：1K = 1000，1M = 1000K = 1000000，1.5M = 1500K = 1500000。

## 工作方式

`src/engine/tutorial.js` 是 Web、App 和小程序共用的内核。它只固定发牌和电脑的选择，每枚筹码仍经过 `act()`、`advanceStreet()` 与 `settle()`，不含结算或合法性逻辑。下注写成大盲倍数，文案金额读自牌桌，所以任何起始盲注都成立，筹码面额规则不变。

引导进入后，控制器把 `game` 暂时指向教学牌局，牌桌的渲染、筹码动画、声音、牌力表和底池明细都是真实组件：

- 真实牌局暂停：取消计时器，保留计划行动的剩余时间，退出时原样恢复。
- 教学牌局不写对局记录、不进入复盘，也不改变设置。
- 引导中隐藏设置、指南菜单、重新练习、下一手、重打和复盘，这些入口在控制器里也被拒绝。
- 引导步骤只放开当前要教的按钮和金额；“继续”不能跳过必须的操作。第五手不做限制。
- 退出、后台、下一步都走既有的 `epoch` 取消，过期计时器不能写入新牌局。
- 前四手里，你按提示操作后，如果下一步是电脑行动或发牌，文案原样停留，右侧显示“继续”，牌桌按钮保持锁定；点“继续”后电脑才开始行动、文案随之切换。停留多久由你决定，不靠延长电脑思考时间。点继续后的电脑与发牌节奏不变（约 1 秒），连续的电脑行动之间不再停下，直到出现新的文案。
- 第五手是真实对手，没有剧本步骤，仍按长度留出阅读时间（约每秒十个汉字，至少 0.5 秒，最多 8 秒）再让对手行动；点“继续”表示已读完。时间按 Web 的活动时钟计算，后台不计时。
- 一手牌结算后牌桌按钮都已隐藏，“继续”移到操作区，与正式对局的“下一手”同一行、同一尺寸，教练面板只留文字。
- 聚焦框用琥珀色（`#ffc857`），与薄荷色的主按钮区分开。

Web 的界面在 `src/ui/tutorial-coach.js` 和 `src/styles/tutorial.css`。小程序在 `src/platform/wechat-controller.js` 接同一内核，界面在 `miniprogram/pages/table/table-surface.wxml` 和 `tutorial.wxss`，只提供简体中文；课程脚本放在 `tutorial` 分包，点击入口时用 `require.async` 加载，失败时提示重试。

## 屏幕与旋转

| 屏幕                    | 教练面板                               | 说明                                     |
| ----------------------- | -------------------------------------- | ---------------------------------------- |
| 手机、竖屏平板          | 固定高度，在牌桌和操作区之间           | 换步时牌桌不动，长文案在面板内滚动       |
| 高度不超过 700px 的手机 | 同上，教学步骤收起滑杆                 | 省下的高度留给牌桌                       |
| 横屏平板、宽窗口        | 牌桌右侧独立一栏，高度随牌桌，选项单列 | 练习侧栏仍在第一屏下方，面板不能撑高牌桌 |
| 平板竖屏和横屏（触屏）  | 字号 14/16/17px，触控目标 44px         | 比手机更远的观看距离                     |

手机横屏沿用全局的方向提示，引导随之冻结，转回后停在同一步。平板可以旋转：面板换位，课程进度和牌局都不变，页面回到顶部，否则旋转会保留原来的滚动位置，把面板文字留在顶栏下面。小程序的横屏平板用固定定位的右栏，引导期间没有练习面板，页面不滚动。

进入引导时会写入一条浏览历史，浏览器返回、手势返回与 Android 返回键都退出引导、回到暂停前的牌桌，不会离开页面或最小化应用；用按钮退出时这条记录同时撤回。Android 返回键先关闭弹层。

## 改动时

- 脚本改动后运行 `tests/unit/tutorial.test.js`，它在多种盲注下打完每手牌并检查筹码守恒。
- 文案变化运行 `npm run i18n:extract`，补齐 `src/i18n/overrides.json` 的十种语言，再运行 `npm run i18n:check`。按钮名称要和牌桌实际译名一致。
- 新增汉字、日文或韩文时按 [界面一致性](interface-parity.md) 重新生成字体子集。
- 小程序主包和每个分包各有 2 MiB 预算，构建时会检查；主包余量很小，见 [微信小程序](wechat.md)。

实际验证：`tests/e2e/tutorial.spec.js` 和 `tests/e2e/tutorial-viewports.spec.js`（浏览器，后者覆盖 17 种屏幕和旋转）、安装 App 的 `beginner-tutorial-guided-hand` 场景、`tests/wechat/tutorial.mjs`（微信 DevTools）。三者分别记录，互不代替。
