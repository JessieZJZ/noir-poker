# 分类说明

本文在 free-review.md 和 interactive-review.md 定稿之后、收到九个候选风格定义后完成。分类只使用之前已看过的本目录 450 手公开牌谱与匿名交互。未读取风格映射、参数、源码、其他目录或其他评审，没有标准答案提示，没有真实人物推测。

confidence 为 0–1 的证据支持度，属于本人的主观把握，未做概率校准。style 为“不确定”时，confidence 固定为 0，表示本轮拒绝作明确归属，不表示已证明该对手没有风格；最近的候选放在 confusedWith，evidence 解释为什么没有采纳。其余首选也不是通过判定。

A 的大尺度多街行动、H 的极宽参与、I 的较低参与是最稳定的证据。H 和 C 使用同一标签，但两者证据强度相差很大：H 的极宽平跟足够明显，C 只有较宽范围及成牌取值的宽轮廓，仍可能由牌序与机会结构造成。B 比 G 有更明确的小开池和小首次下注证据，所以给 B 中等把握、对 G 拒判；这不意味着我能可靠完成任意 B/G 的身份互换识别。

D 的少数平跟再反加容易使人联想到强牌诱导，但未知底牌不能补成强牌，且“安全局面诱导”的条件没有得到重复验证。G 的暗三条过牌也只有一例。过牌很多本身不能证明诱导，低参与本身也不能证明均衡。

E/F 仍沿用自由观察和交互中无法可靠区分的结论。二者都出现小翻牌下注后加大转牌压力，也都出现听牌行动，最接近的候选可以相同。但已公开的大额投入还包含普通一对、两对及葫芦价值，不能把规模变化自动解释成听牌偏好。不给其中一个“听牌施压”、另一个“均衡”或“延迟进攻”来补齐配额。

“延迟进攻”要求低价跟过翻牌、后街对手过牌后再主动。C 虽然有后街下注，但总共只有两次翻后跟注，未见足够重复的这种完整路线。“小注持续”需要在干燥高牌面上反复出现小持续下注，并考虑没有下注的机会；目前没有完成这种机会分母，不能仅举一两手小下注就归类。

没有分配全部九类。C/H 重复使用宽松取值，D/E/F/G 拒判。未分配的类别仍可能对应某个实际策略，只是本轮公开证据不足以让我可靠采纳。

交互对 E/F 的鉴别未通过，且有效双方翻后机会少、发牌和座位不对称。分类没有把旁观到的对局冒充直接施压测试，也没有用几手短期收益提升标签置信度。自由观察与交互报告均保持原文不变。
