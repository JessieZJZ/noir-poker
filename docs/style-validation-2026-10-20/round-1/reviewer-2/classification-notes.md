# 分类说明

此分类在 free-review.md 与 interactive-review.md 提交后，才收到九个候选定义。两份既有报告未作改写。未读取任何风格映射、参数、源码、其他目录、其他评审或标准答案。

classifications.json 中的置信度是我对“该标签是当前候选里最接近公开观察的首选”的主观信心，不是经过校准的分类概率，也不是策略强弱或盈利能力评分。低于 0.6 的项目应按低把握候选理解，尤其 H 与 I。没有强迫一一对应。

## 重复标签是有意保留的

- A 与 F 都首选“多街施压”。A 的中等下注尺度较常规，F 的大注、再加注和投入剩余筹码更显著，所以 F 信心更高。不能只因为候选中另有“均衡”就把 A 填过去。
- C 与 I 都首选“听牌施压”。二者都反复出现小翻牌注、大转牌注，且分别有可观察的听牌强攻击实例。原始牌谱已经难区分，短主动交互也没有证实稳定可辨认，分类不应反过来捏造两个互斥身份。I 的直接听牌证据更少、也可能更接近“小注持续”，故只有 0.49。
- D 与 G 都首选“范围纪律”。D 更常出现筛选后主动取值与承压退出；G 的依据主要是少参与，后续跟中等牌和少主动的行为与完整定义不完全吻合，故只有 0.54。这里没有把“不入池”自动提升成全面防守纪律。

## 其余候选的支持与反证

B 的极宽、以跟注为主的进入方式有多手实际摊牌支持，“宽松取值”相对最接近。但弱成牌高投入的反例很多，不能把它包装成稳定等到强牌才投入的大价值策略。

E 的强成牌过牌有具体牌力证据，但“诱导”是对意图的解释。E41 葫芦从转牌等到河牌仍没有下注，也可能是错失价值。E 与“延迟进攻”重叠，当前只以少量明确强牌过牌实例将“强牌诱导”作为略优先候选。

H 的首选最弱。题目把“均衡”定义为中等范围、常规尺度，H 的总体频次及多数下注尺度与此接近；但其前街较安静，又夹杂少量大幅反击，“延迟进攻”也能解释相当部分行为。这个选择不表示发现了 GTO、频率平衡或针对对手的适应能力。若要求可靠识别，我会将 H 视作尚未确定。

“小注控池”“小注持续”“延迟进攻”没有被分配为任何代号的首选，原因是当前观察中它们与已选标签有重叠，却没有足够强的独立证据让我优先选它们，而不是因为认为这些风格不存在：

- G 很会过牌控池，但少量实际下注并不特别小，不能仅由安静就认定“小注控池”。
- C/I 的翻牌确实偏小，但并非都有充分的“干燥高牌翻牌频繁持续下注”机会与牌谱支持；转牌明显放大及少量听牌实例让我略偏向“听牌施压”。小注持续仍是二者最容易混淆的定义。
- E/H 以及交互中的 C/I 都有延迟进攻实例。候选定义还包含低价先跟和对手过牌后再出击，而这些对手也会作为翻前开池者过牌后突然下注，不能把所有晚出手都视作一个独特风格。

## 与主动交互的关系

主分析只用 C 的 12 手和 I 的前 15 手。C 与 Hero 同进翻牌四手，I 只有两手，多次关键攻击发生在 Hero 已退出后。因此交互支持“确有某些可见行动”的结论，不足以支持“玩家能稳定区分”。I 超额的第 16 手只保留日志，不参与分类。

交互出现的 C #7 与 I #25 都是小翻牌注、大转牌注，C #8 与 I #13/#21 都有延迟河牌大注。I #24/#26 的翻前再加与 C #12 面对再加弃牌并非同牌同情景对照，不能作为确定区分依据。

## 仍然缺少的证据

要提高可辨认性判断，至少需要更多同类公共局面下的机会数：面对同一尺度的开池/再加注，干燥高牌翻牌的持续下注机会，未成听牌的半诈唬机会，以及强牌在安全牌面的过牌与主动取值机会。当前不会使用未亮底牌去填这些分母，也不会用后来的胜负判断当时是否合理。

本次分类只是九个描述与既有公开记录的匹配。它没有证明九类之间能被玩家区分，也没有证明任一类行为已经达到稳定实现或长期合理水平。
