# 分类冻结后的事实更正：H163

只核对本人 interaction-raw.jsonl 中 API163（H码内第63手）的请求前公开状态、公共事件和done后的inspection，未请求API，未查看源码、映射或其他评审。

记录确认：Hero在CO持6s6h开500，H从BB跟。翻牌Tc 2d 6c，原底池1600，Hero下注1100，R1弃，H跟1100，转牌前底池为3800。转Td后Hero下注2600，H弃。手结束inspection显示H为8d7s。

原score.md说8d7s在此翻牌“只有两个较低高张和后门顺”，其中“后门顺”错误。已有6、7、8、T，任意一张9即可组成6-7-8-9-T，因此是四张9的卡顺听牌，不需要连续两张特定牌才能成顺。这四张9是牌面上可能完成顺子的牌，不等于在所有未知对手范围下都保证获胜的四张干净补牌。

对疑点结论的影响：撤回以H163支持“没有即时听牌仍浮动”或“缺少真实继续潜力”的说法。互动复盘将它与H107、H131并列作为高牌浮动例子的解释也应相应收窄：H163应作为有卡顺潜力的边缘跟注、转牌未改善后退出的样本，不能与另外两手无即时顺花听的事实等同。转牌Td仍保留河牌9成顺的可能，但公牌已配对、对手继续下注，弃牌本身不构成策略错误。

原记录的价格没有变化：H翻牌跟1100，最终池3800，直接价格约28.9%。单凭四张卡顺补牌和这个价格，既不能证明跟注有正期望，也不能判定必错；还需考虑Hero当时未知范围、后街行动、隐含赔率及可能被压制的风险。可行的fold替代仍存在，但该手不再作为原文所述“无即时听牌”的缺陷疑点证据。不能因done后得知Hero暗三而反推H当时知道自身补牌质量。

本更正只修正事实及相关论证，不改评分。原score.md、classification.json、classification-freeze.sha256和此前冻结文件保持原样；此文件是新增更正，不回填原冻结清单。
