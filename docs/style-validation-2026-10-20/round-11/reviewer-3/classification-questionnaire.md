# 第十一轮中性分类与体验问卷

仅在三位评审的全部观察、固定200手互动、原始请求/响应和评价原稿冻结并核验后发送。

请保持此前自由稿、互动理由和复盘原样，在新文件作答。不要继续请求互动接口，不访问私有映射、其他评审或产品源码。

每个匿名代号 A–H 独立选择一个最贴近的风格。允许重复选择同一风格，也允许“不确定”，不要求八个标签恰好各用一次。请填写第一选择、可选的第二选择、置信度和对应观察依据。未摊牌时的动机只能写推测，不能用最后输赢证明当时行动好坏。

可选标签如下：

- 后位争夺：前位相对克制，后位更愿主动争夺，位置允许时也会延迟出手。
- 均衡：中等参与范围、常规下注尺度，价值进攻与适量诈唬并存。
- 听牌施压：持有真实继续潜力的听牌时，更积极用下注或加注争夺。
- 多街施压：参与范围较宽，在有支持的局面连续进攻，并使用较大后街尺度。
- 小注控池：偏好小尺度持续下注、薄价值，以及中等牌力时控制底池。
- 宽松取值：更愿低成本跟入，形成强牌后扩大价值投入。
- 范围纪律：更严格地选择起手牌与防守价格，入池后仍正常取值。
- 跟注诱导：在合适的低成本入池机会偏向跟入，安全强牌有时选择先让对手行动。
- 不确定。

请另在 score.md 中分别给出辨识度、自然策略互动体验、训练价值三个独立评分（1–5，或无法判断）。1 表示很差，3 表示一般，5 表示很好。不要根据猜中的数量反推体验分。注明评分是依据800手旁观、200手互动还是两者，并逐项说明评分原因。看牌便利属于本轮方法，不能归因为机器人策略提高。

请特别区分：自然弃牌与策略错误、机会少与缺少特色、目标对手与第三方造成的压力。提出缺陷时列出实际手号、公开牌面、当时价格和可行替代行动；无法从公开证据支持的结论直接标注不确定。

输出 classification.json，包含八个 classifications：code、firstChoice、secondChoice（可空）、confidence（0–1）、reason。另在同一个 JSON 的 scores 中分别填写 recognizability、naturalExperience、trainingValue（各为1–5或null），在 score.md 解释评分。完成后对这两个新文件及此前原稿、审计记录建立 classification-freeze.sha256，禁止改写已冻结文件。不要读取私有验收门槛、映射或其他评审结果。
