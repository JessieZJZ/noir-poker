# 固定交互体验评审（阶段 2，待分类菜单）

本稿继冻结的 free-review.md 而来，不修改阶段 1 描述。阶段 1 的两处牌型错误与交互中的文字精确性修正另见 errata.md。本次仍为匿名 AI 策略牌谱体验，未搜索真人、未读取引擎或服务器源码，未进行人类或 UI 测试，不主动猜预设标签。

## 执行与完整性

- 选择阶段 1 最易混淆的 B、D，各恰好 40 手，共 80 手。API 手号连续，B 是全局 1–40，D 是全局 41–80；下文一律引用全局手号，因此 D/49 是 D 的第 9 手。
- B 与 D 各自的 Hero 五个位置均 CO/UTG/BB/SB/BTN 各 8 手，目标自己的五个位置也各 8 手。
- 每次 start 前上一手均为 phase=done，最后 D/80 为 done；未追加或重开抽样，80 手后停止 API 操作。
- interactive-transcript.jsonl 保存了全部 228 次请求的完整 JSON 响应，其中 80 次 start、148 次 Hero action，HTTP 状态全部 200。统计脚本对未结束即 start、非 200 响应检查均无异常。未作额外 API 探测。
- Hero 的每次动作由本评审根据当时公开状态决定，辅助脚本只发送明确动作、保留原始响应、展示状态，并在当前手结束且该代码未达 40 手时开下一手，没有自动决策策略或调用默认机器人。选择理由随请求存档，最早 B/1 的弃牌理由补记为：CO A3o 面对前位 limp，弱踢脚且不同花，弃牌。
- Hero 以通常 2.5BB 未开池加注、约 4BB 对单 limper 隔离，强牌取价值，弱非同花牌在不利价格下弃牌。没有为制造目标特色而硬跟，没采用统一 check/call 或全弃策略。双方各有 34 手在某时点 Hero 弃牌；这会限制直接翻后证据，不能把所有可见目标行为称作亲身对抗。

“共同翻牌”要求双方都没有翻前弃牌，即使 Hero 在翻牌先弃、目标随后才行动，也记为共同到达。直接面对下注机会按该街最近最高下注者识别：若陪测座位已经再加注，目标接下来的响应不算面对 Hero 的下注。计数是动作机会而非独立试验；例如 D/49 三街对应三次，并不代表三手。全体目标行为包含 Hero 弃牌后公开继续的行动，和直接机会分开解释。

共同翻牌名单：B/3、9、12、18、20、24、26、32；D/41、49、50、51、55、57、63、69、71、72。

## B 的直接互动

**B/3：面对目标主动时的弱牌退出。** Hero CO 2h2s 跟 UTG 开到 500，B 大盲跟入。在 8c9c4d 翻牌，B 向 2100 池下注 1600；Hero 的 22 仅低口袋对，无梅花且仍有后手座位，因此弃牌。B 此后对 R1 转牌、河牌继续下注，未摊牌。能确认它会主动发起较大翻牌下注，不能确认底牌或诈唬。

**B/9：目标面对 Hero 河牌价值下注。** Hero BB 4s3s 在多人底池低价跟入；6h8s3c 翻牌是底对，7s 转牌增加同花听牌与 5 卡顺，双方均过牌。5c 河牌 Hero 用 4 形成 4–8 顺子，下注 1400 入 3200，B 弃牌。其底牌未知，不能说它弃了某类成牌，更不能从 Hero 的强牌反推目标弃得正确或错误。

**B/12：最完整的目标承受线。** B 小盲加到 700，Hero BB KdJd 跟入，另有 R3。Js2hTh 翻牌，Hero 顶对 K 踢脚，面对 B check 后下注 1200/2100；R3 弃，B 跟。9c 转牌使牌面更连张，Hero 仍是一对 J 并有 Q 卡顺，B check 后 Hero 控池 check。Jc 河牌 Hero 成三条 J，B 再 check，Hero 价值下注 2400/4500，B 跟。B 展示 Kh9d：翻牌 K 高及 Q 卡顺，转牌成一对 9并仍有 Q 卡顺，河牌最佳为 JJ99K 两对，低于持有 J 的三条。这里可观察到它从听牌/高张继续到河牌用较弱摊牌牌跟注，但只是一手，不能据此给整个跟注范围贴标签。没有用这手的输赢来评判此前动作。

**B/18 与 B/26：面对多人价值下注会退出。** B/18 Hero BTN JJ 加到 800，目标大盲跟入，Qs6d5d 翻牌双方过牌；5h 转牌 Hero 持 JJ55Q 两对下注 1300/3200，B 弃。B/26 Hero UTG KsQd 开到 500，五人到 3sKdTs；Hero 顶对 Q 踢脚下注 1600/2500，B 弃。两手都无目标底牌，能确认会在多人面对压力退出，不能把两次弃牌解释为只玩弱牌。

**B/20：面对再加注和两街下注的切换。** B CO 对 limp 隔离到 700，Hero BTN KcQc 再加到 2200，B 跟入单挑。6h6c8h 翻牌 B check，Hero 两高张以 1600/4900 小注，B 跟；Qs 转牌 Hero 成 QQ66K 两对，下注 4000/8100，B 弃。目标既会继续翻前 3bet 池与翻牌小注，也会在转牌升价后退出。底牌未知，不能称为听牌弃牌或某对弃牌。

**B/22、23、40：亲身感受中更醒目的翻前反击。** B/22 Hero CO A9o 隔离到 800、BTN 跟，B 小盲挤压到 3500，Hero 弃；B/23 Hero CO KTo 开到 500、SB 跟，B 大盲挤压到 1700，Hero 弃；B/40 B 先 limp，Hero BTN ATo 加到 800、两盲跟，B 再加到 4700，Hero 弃。目标三次都未亮牌，不能据此称为轻 3bet 或陷阱强牌。与静态 50 手“较少翻前主动”的初印象相比，本次实际遭遇的反击很突出，因此不能把静态频率当成稳定识别标记。

**共同翻牌中的非直接线。** B/24 Hero QJ 在 AA9/J 转牌 check 后，R1 下注 3600/3400，B 先弃、Hero 后弃，这是面对 R1 的行为。B/32 Hero Qd6d 与目标在 Jc5h3c/Jd/Th 三街都 check；B 展示 2s7s，除公共 J 对外没有命中，说明它也会无额外投入看至摊牌。Hero 未向 B 下注，不把这手计为目标抵抗压力。

## D 的直接互动

**D/41 与 D/57：Hero 强牌发起，目标翻牌退出。** D/41 Hero CO Qd9c 隔离到 800，目标 BTN 跟；Qc9d7h 彩虹翻牌，Hero 顶两对下注 2200/3300，D 弃。D/57 Hero BTN 7d6d 跟 CO 500，目标 SB 跟；7h7c3h 翻牌 Hero 三条 7下注 1400/2000，D 弃。目标底牌都未披露，不能判断是否过弃。这两手只是目标面对 Hero 翻后下注的三个机会中的两个。

**D/49：目标三街下注，Hero 以成牌跟到底。** D UTG 开到 600，Hero BB Kd3d 跟入，多人到 Ks2h5h。Hero 顶对弱踢脚 check，D 下注 800/2400，其他两人弃牌，Hero 跟。6d 转牌 Hero 仍顶对并获得 4 卡顺，D 再下注 2000/4000，Hero 跟。Kc 河牌 Hero 成 KKK65 三条，check 后面对 4000/8000 再跟。D 展示 AhAs：翻牌、转牌为超对 AA，河牌最佳为 AAKK6 两对。它在公共 K 配对后仍半池下注，没有持有三条或葫芦。这个公开例使“D 河牌下注必然非常强”不成立，但不足以区分是薄价值、抓错价值或策略性下注，不能从一手给所有河牌下注定性。

**D/69：从小持续下注到转牌大注。** Hero BB KcQd 跟 D UTG 600。Jd6h5c 翻牌 Hero 两高张无直接听牌，check 后面对 400/1300 小注跟一街。3h 转牌未改善且形成两红桃，D 下注 1700/2100，Hero 弃。目标牌未知；可确认尺度从约31%池升到约81%池，不能确认它有 J、听牌或空气。

**D/71：目标面对 Hero 河牌加注的唯一这类机会。** 五人 limp，Hero BB Kc2h 免费进入 QsTh2s，底对 check；Ts 转牌三黑桃且公共 T 对，Hero 成 TT22K 两对，继续 check。2d 河牌 Hero 成 222TT 葫芦，SB R4 向 1000 池下注 1000，Hero 加到 2800；D 在 BTN 弃牌。目标未知底牌，弃牌不能证明读对 Hero。R4 后来跟注并展示另一张 2，属于陪测行为，不算目标表现。

**D/72：共同翻牌、无压力的被动线。** Hero BB Qc9d 低价防守，D 小盲冷跟。KhQhTh 翻牌 Hero 第二对并有 J 卡顺、无红桃，D check，Hero check；7s、4d 后双方仍 check。D 展示 Ad3h：翻牌为 A 高，有一张红桃配合公共三红桃的同花听牌，以及 J 成 Broadway 的卡顺听牌；转牌、河牌均未完成，最终 A 高。其同花听牌用 3h，不能称坚果同花听牌。这表明 D 也会放慢有听牌的牌，不能将 D 一概描述为所有可打牌面都推进。

**D/50、51、55、63：共同翻牌不等于直接施压。** D/50 和51都是 SB 陪测座位先大注，Hero 低口袋对/低两对先弃；D/51 随后对 SB 加注并摊牌 Jh9s，在 A99 翻牌确为三条 9。D/55 目标在 K65/7/2 的河牌面对 R2 下注弃牌。D/63 目标在 K64/8/Q 河牌面对 SB 下注弃牌。后两例没有目标底牌，都不是目标面对 Hero 的下注。

## 补充可见行为与体验变化

本次 B 翻前 16/40 手加注、D 14/40，与阶段 1 的 11/50 与16/50 的相对次序不同。自愿入池 B 38/40、D30/40，同样不能假设重复样本会精确重现静态比率。这里有不同发牌、不同陪测行动、Hero 策略和小样本机会差异，位置均衡并不能消除牌力差异。

D 翻后主动动作 15 次（5/5/5）多于 B 9 次（1/3/5）；旁观时 D/66 从半池转超池、D/67 转河继续施压，而 B 多次平稳 check。但 B/3 也有三街主动，B/7 对 R2 河牌再加全下，二者都不能靠“有没有大下注”作简单二分。未亮牌的这些线只作为动作事实。

最实在的亲身体验差异是：这 40 手里 B 的翻前反击让我多次退出；D 的两手直接翻后下注线提供了三街跟注与转牌退出的不同压力感。目标面对 Hero 翻后下注的机会，B 只有7次、D只有3次，且D的3次全弃，不能据此断言 D 普遍更易弃牌。B 的7次为跟3、弃4，同样分散于不同牌面与街道，不能当成同条件成功率。

**目前仍保留 B/D 容易混淆的判断，同时降低对静态“B 翻前较被动、D更常加注”这一具体差异的信心。** 两者都能宽跟入、长时间过牌、翻前反击与后街主动；我更能描述各自这批机会中的反应，但不足以稳定预测所有场景。未知底牌不推成诈唬或强牌，也不将中奖或输筹码作为风格证据。80手已完成，不再为补齐某种机会扩样。
