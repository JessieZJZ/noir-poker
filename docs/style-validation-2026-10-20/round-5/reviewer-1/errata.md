# 冻结稿勘误

在交互开始前再次逐街核对时发现两处牌型文字错误。free-review.md 和其原 SHA256 保持不变。

1. D/17：Kd2c 配合 Jh8h4sQh 的转牌，没有对子、同花听牌，也没有一张河牌即可完成的顺子听牌。T 只形成 TJQK 四张连续，缺第五张，不能称为 T 卡顺听牌。因此该手转牌满池下注是已知 K 高且无直接顺/同花听牌的施压，不能称有卡顺的半诈唬。河牌 6d 仍为 K 高。free-review.md 中 D 段及 B/D 比较提到“卡顺”的两处都按此纠正。
2. D/15：Ah7d 配合 7s8c8h3h3s 的河牌，最佳五张仍为 88、77 两对加 A，而不是公共 88、33 两对加 A。它有三组可配对点数，但选择较大的 8 与 7 两对；没有葫芦。原稿声称 7 对不进入最佳五张错误。翻牌、转牌描述无变。三街跟注这一事实保留，但不能用错误的河牌降级来加重评价。

两项都不改变选择 B/D 进行固定交互的判断，不把勘误当成额外牌局证据。

## 交互记录说明文字勘误

- 交互 D/49 的河牌为 Ks2h5h6dKc，Hero Kd3d 的最佳五张是 KKK65，两个踢脚来自公共 6、5。操作理由中“三条K但3踢脚低”只是对手牌的粗略称呼，精确牌型不是以 3 作踢脚。跟注决策没有改动，完整 API 响应原样保留。
- 交互进行中的一条简短进度把 B/12 牌面粗称为“J♥类高张牌面”，实际翻牌严格为 Js2hTh（J♠2♥T♥），本次报告以该真实牌面为准。
