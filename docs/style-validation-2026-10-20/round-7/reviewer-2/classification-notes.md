# 分类菜单后的独立评分

这是 AI 策略盲评，不是人类盲测或 UI 测试。分类允许重复与未知，没有采用排除法。1–5 分中，辨认度衡量能否凭公开行为稳定认出风格；自然牌局体验衡量行动是否连贯、有适当变化和交互机会。后者不按赢筹码、输筹码或对 Hero 好不好打评分。A/D 仅有各50手阅读，B/C另有各80手固定交互，证据层级不相同。

## A

中等偏宽参与与很低的主动频率可以被描述，但其菜单拟合不够稳定。50手52% VPIP与6% PFR、翻后38次过牌和仅2次主动动作，使静默跟入成为主要感觉。第32、44手翻前再加、第40手公开K3两对后河牌大再加证明有变化，现有机会仍不足确认其是否稳定兼顾价值、控池与常规主动性。标签保留未知，辨认度2分。

自然体验2分的依据是多人底池长时间过牌和少量有明显节奏变化的事件。第19手三条T河牌仅跟也提示可能有价值遗漏，但不能凭一手确定错误。它缺少追加交互，这个体验分主要来自旁观公开行动，不能解释成与它实战80手的感受。

## B

两批数据都宽参与，追加80手31个翻后主动动作；初读第36、37手的强成牌连续取值、追加第13、28、57、74、78手的跨街加压，形成较稳定的节奏，辨认度4分。牌未摊开时，只能确认行动跨街，不能断定是听牌进攻或诈唬。

自然体验4分来自加压、控池、面对反击退出等多种公开线路。B并非每手下注，追加第31、37手与Hero共同翻牌后也有多街过牌。第64手翻牌9100入7200、第71手大河牌动作在尺寸上突兀，公开信息不能证明其策略基础。只给4分也保留了这些尺度事件与直接交手不足的不确定性：Hero仅与它共同翻牌7手，翻后直接面对其下注1次。

## C

大量便宜跟入、后续多街过牌，与强成牌时较大取值的初读证据相容。追加80手114次过牌、10次主动动作，与B的节奏差异持续可见，辨认度4分。初读第12、15、30手确实摊牌成牌后的主动取值，是“取值”部分的证据，不能将所有未摊牌下注都归为强牌。

自然体验3分：它为多人翻牌提供了较多参与，少数手会主动加压；但大量免费查看和跟后退出让后街节奏偏静。直接第109手跟Hero两街再弃河牌、第144手跟转牌再过河牌是有因果连续性的体验。Ks河牌改变了第109手的范围，不能因为其面对小注退出就断定不合理。Hero与它共同翻牌9手、翻后面对其下注仅1次，无法评价完整防守能力。

## D

低参与是最稳定的识别点，50手仅8手自愿入池。第22手55暗三条取值、第38手88再加注、第33手AA安全牌面保留行动，支持选择性参与后仍可进攻的描述。由于样本中多数只是翻前弃牌，辨认度4分主要意味着能认出低参与特征，对完整风格的置信度仅0.78。

自然体验2分：对手频繁提前离场，互动很少；少数入池手有正常后街行动，不能判为程序不会打牌。AA过两街可能是诱导，也可能漏取值，现有公开数据不能决定。D未追加交互，体验分仅是阅读观察。

## 共同信息限制

Hero实际VPIP仅13.125%，影响目标面对主动参与者的暴露。B/C的直接翻后互相面对下注机会偏少，评级主要由整个公开桌面行为支持。位置平衡不等于牌张、成牌机会、公共牌和对手行动已配对控制。因此这些分数是本轮观察下的独立判断，不能解释为总体策略强度、盈利排名或人类满意度。
