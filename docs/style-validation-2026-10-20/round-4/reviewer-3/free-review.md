# 匿名公开牌谱自由评审（冻结稿）

范围：仅阅读本评审目录 README.txt 与 A–D.jsonl。四组各连续50手真实5人牌局。以下是 AI 的牌谱及策略体验评审，不是人类研究，不涉及 UI 验收，也不证明某种应对有最优收益。未查看源码、隐藏底牌或策略映射。先写本稿，再进行另行规定的互动和分类。

## 公共行动的总体差异

我能较容易区分 C 与 D 的翻前参与方式，也能区分 A 与 C/D。A 与 B 最容易在短片段里混淆，两者都能长时间过牌，又会在较后街突然下注。A 更少入池，B 更少翻前加注，是目前最有用的区别。这里没有假定四个代号必须对应四种互斥类型。

| 指标 | A | B | C | D |
|---|---:|---:|---:|---:|
| 翻前自愿投入手数 / 全部50手 | 17/50（34%） | 23/50（46%） | 46/50（92%） | 42/50（84%） |
| 翻前至少一次加注手数 / 50 | 7/50（14%） | 2/50（4%） | 9/50（18%） | 22/50（44%） |
| 至少一次无加注底池跟入或补齐盲注 / 50 | 4/50 | 11/50 | 17/50 | 9/50 |
| 在翻牌有行动的手数 / 50 | 15/50 | 23/50 | 38/50 | 37/50 |
| 有行动的转牌 / 河牌手数 | 14 / 14 | 23 / 17 | 28 / 20 | 33 / 25 |
| 翻后行动次数：过牌 / 下注或加注 / 跟注 / 弃牌 | 34 / 7 / 4 / 1 | 45 / 16 / 6 / 4 | 68 / 12 / 9 / 16 | 60 / 17 / 18 / 8 |
| 目标确实亮牌的手数 / 50 | 11/50 | 14/50 | 18/50 | 22/50 |

自愿投入不含强制盲注与免费过牌。有翻前行动的手数 A/C 为50，B/D为49，B第5手与D第46手未轮到行动，不能记成主动弃牌。最后一行不是胜率，亮牌样本也有选择偏差。翻后次数可能同一手同一街多次，不能与手数直接相除。

按每次目标面前确有需要补足的翻后下注计算，A共6次（跟4、弃1、加1），B共12次（跟6、弃4、加2），C共25次（跟9、弃16），D共26次（跟18、弃8）。这些是行动机会数而非独立牌局数。A只有6次机会，不能据此断言其翻后特别难打退。C/D共29次翻后主动下注都发生在当时无需跟注时，本样本没有其面对下注再加注的例子。

## A：先筛掉较多起手，进入后经常等待后街

A翻前第一动作弃牌31/50，四组最常见。它也有明确的升级压力：第4手在有人加到4BB并有人跟注后，再加到16.5BB，翻牌向39BB底池下注19.5BB结束牌局。没有亮牌，不能把这手称作诈唬或强牌证明。

翻后最鲜明的是等待。第11手JJ在K55翻牌、4转牌、7河牌一路过牌，实际最终为JJ与55两对。第39手AJ在QJ3三方块翻牌持中对，之后各街过牌。第32手则前两街过牌，河牌在Q♥6♥2♦K♥2♥上，面对5BB下注加到26.5BB，摊出A♥J♦的A高同花。第44手J8在A-J-2-6-8上河牌得到两对后下注。这些支持“愿意等待后街价值”的描述，但不足以推断所有河牌下注都强。

也有不符合单纯稳健印象的行动。第14手A4在QQ2-5-5上，转牌跟3.5BB、河牌跟7BB，最终只是公共QQ55加A踢脚，对99则落后QQ99。第38手QJ在899翻牌下注5.5BB，之后停手，说明它也会用未与底牌配对的牌下注。第36手J7与Hero同为J7，在4-8-J-7-Q上都是JJ77Q两对，A河牌底池下注后跟再加注，最终平分，不能将这笔大底池简单解读为抓诈唬成功。

我的应对：翻前拿位置优势尝试较宽的偷盲，但面对其再加注要收紧。它过牌不代表没有对子或听牌，可用扎实价值牌持续收费，避免把连续过牌一概当成放弃。河牌大幅再加注目前仅有第32手这样的强价值证据，应认真考虑自己的阻断牌和能打赢的价值组合，不能机械跟注。上述是待验证的调整，不是收益结论。

体验上，A给人可等待、可观察的节奏，少数大幅升级有反差。需要改进的是价值提取与防守阈值的可理解性：有些中强牌长期不下注，而公共双对上的A高又连续支付。不能只靠提高整体攻击频率修补，两类场景需要分别处理。

## B：翻前大多跟入，翻后有明显的主动发力片段

23手自愿入池里仅2手有翻前加注。第24手AA面对3BB开池也只是跟注，9-J-7-T-5四人底池三街过牌，说明其翻前跟入范围不能轻易封顶，也显示一些价值提取机会未被使用。第39手AK跟入后，从高牌一路过牌到河牌K，仍未主动取值。

但B不是一路跟到底。第10手在五人6-5-7翻牌下注半池，转牌A面对4.5BB下注再加到15.5BB，河牌Q下注32.5BB，形成连贯的压力路线。双方都未亮牌，不能给它补上坚果、顺子或空气标签。第14手A♦Q♦在7♦6♥J♦-2♠-2♦河牌成A高同花后下注，第48手96在T-8-5-9-9上河牌成为三条9后下注，都是可核对的后街取值。

第21手J8在A-J-3翻牌只有J一对，主动下注后跟大加注，转牌8变成J8两对，又主动下注并跟全压，最终落后A3两对。这体现从较弱对子到两对时的持续投入，不能凭最后输光认定转牌跟注必错。第35手J♠T♠在9♠8♠2♠翻牌已经是J高同花，转牌强烈再加注，河牌2让Hero的99成为葫芦而胜出。这是明显的成牌价值路线，不能将其归为“没牌乱推”，河牌变化必须单独评估。第47手KT在A-K-2翻牌主动下注，转牌跟注后河牌过牌，也表明主动下注不只发生在顶对以上。

我的应对：面对翻前跟入要保留AA、AK等强牌可能，不把它当成只有弱牌。对其安静路线可以尝试用强一对取合理价值，也需防止持续加码把较差牌都赶走。面对翻后再加注，现有少量证据里有真实强成牌，应按牌面与尺度分析，不能因为翻前被动就默认其后街压力都虚。

体验上，B比A更常入池，翻前压力小，翻后偶尔突然变得很有存在感。最突兀的是AA/AK的全程安静与另一些牌的多街大额投入并置。希望这种差异能更多由位置、人数和牌面解释，否则练习者不易形成可迁移的读牌经验。

## C：极高参与，常先便宜跟入，受压后不少放弃，另有重投入的例外

46/50自愿参与，翻前第一动作只有3次弃牌。第3手A2、第18手J5、第28手T2、第35手92等已亮底牌，显示参与很宽，而不只是一轮好牌。它有17手无加注底池跟入或补盲，面对翻前加注有26次跟注、11次弃牌，没有再加注。这里也不能把26次当成26手。

C在38手翻牌行动中有10手没有后续转牌行动，翻后面对25次下注选择16次弃牌。这使它与D的持续跟注形成差别。但“便宜看牌、受压退出”也不是完整描述。第18手J5在6-2-7-4转牌，有5连接出的两头顺子听牌，向11BB底池下注11.5BB，河牌2停手，确实有可见半诈唬资源，不能叫纯空气。第40手A7在J-J-7-4-6上，以JJ77A两对跟翻牌后连打转牌、河牌半池，但Hero的88实际是JJ887两对并领先。这是一手薄价值或施压边界不清的例子，不能确认其下注意图。

更突兀的是第43手AJ在T55-7-K上连续跟5.5、13.5、27BB，最终仅有公共55加AKJ踢脚。第47手J5在2-7-7翻牌、Q转牌时都未与底牌配对，分别跟5和10BB，河牌J得到JJ77Q两对后又跟29BB。两手都比一般宽入池后及时放弃的节奏黏得多，且不能拿对方已亮强牌作为此前应该知道的事实。第42手QJ在Q-J-3翻牌已是顶两对，向32BB底池下注36BB，转牌2再投入54BB，全压时仍是两对，河牌A才让AJ反超。这手前街重投入有强牌依据，不能和第43手的公共对子跟注混在一起批评。

我的应对：用更扎实的起手牌隔离其跟入，并让价值下注覆盖其宽范围。可在有范围与牌面优势时试一次合理尺度施压，但不能因总体弃牌次数较多就自动多街诈唬。它的已知重投入例外意味着每街仍需看自身摊牌价值、听牌和对手延续范围。它过牌后的主动下注也可能是听牌、薄成牌或顶两对，而非单一强度。

体验上，C让很多牌局真正开始，练习机会丰富，容易感到“总有它”。但宽入池后退出与偶尔用极弱摊牌价值连续付费之间的切换太强。建议优先检查公共对子局面与未配对高牌的连续防守，让后街支付能被牌力、听牌或合理抓诈唬依据解释。

## D：翻前更主动地扩大底池，翻后也更常继续支付

42/50自愿参与中22手有翻前加注，比C的9手明显更多。第7手A8在Hero开到2.5BB并两人跟注后，再加到12.5BB，体现会主动争取翻前筹码。已亮的Q7（第14手）、94（第17手）、Q6（第24手）、T6（第37手）都有翻前加注，支持其主动范围较宽，而不是仅由AA/KK造成的表象。

D翻后并非每街都打。37手有翻牌动作、60次翻后过牌，很多时段安静。第29手AQ在A-9-7翻牌过牌，转牌Q成两对后打满池，河牌J再打半池，是清楚的后街取值路线。第9手K4在A-Q-J-8转牌下注7.5BB时，持K有T成顺的卡顺资源，河牌4停手。第18手J4在A-9-8-Q转牌下注9.5BB时，也有T成顺的卡顺资源，河牌4过牌。它们不是当时已经成顺，也不能称完全没有改进机会。

其支付意愿更值得警惕。第32手Q9在A-2-9-2-K上，面对Hero半池的5.5、11、22BB三次下注全部跟注，最终为9922A两对，落后Hero的AA22K。第7手A8在A-Q-T翻牌跟15BB，转牌Q和河牌6继续支付到100BB，最终只是AAQQT两对，对方三条Q。第30手KQ在T-J-Q-6-K上河牌虽有KKQQJ两对，但公共牌已有四张连续大牌，任何A或9都成顺，仍跟23BB。这个河牌防守尺度值得单独检查，不能把两对牌型名称当成相对强度。

也有容易误读的平分。第13手A5与A4在6-A-4-7-7上最终都使用AA776，两手同样强，A4原来的A4两对被公共7对替换，不能宣称A5靠“弱踢脚硬跟”输给A4。第37手T6在A-T-K-Q-6河牌成TT66A两对后跟9.5BB，赢过Hero的K一对，支持其较宽跟注能偶尔抓住薄价值，但不证明整体抓诈唬收益。

我的应对：翻前减少被其宽加注牵着走的无位置弱跟注，用强范围和位置明确反击。翻后增加有依据的价值下注，少尝试仅凭“一定打得退”而加码的诈唬。若持中等摊牌牌力，面对它的主动下注仍需防真实两对与半诈唬，两者都有公开例子。

体验上，D最容易在翻前制造竞争感，与C的跟入有明显不同。翻后持续支付给价值练习很多机会，但也可能让练习逐渐变成只等好牌收费。可改进处是高牌面压力、被公共对子稀释的两对和大额多街支付之间的相对强度判断，保持其参与感的同时减少机械延续。

## 结论与下一阶段预先承诺

最有把握的区分是“C更广泛跟入，D更常加注扩大底池”，其次是“A比C/D更筛选起手”。A与B都常过牌和后街发力，最难仅靠少量牌局区分，所以固定选择A、B各10手进行下一阶段，共20手，不因是否出现特色而追加。

以上应对是基于这200手公开样本形成的临时假设。四组不是同一批底牌的控制实验，不比较短期净输赢，不拿未知弃牌底牌当空气，也不以最终胜负反推此前必然对错。底牌只在确实摊牌后用于复盘行为，未作为当时决策可用信息。所有本文引用的摊牌牌型均独立按当前街或最终七张牌的最佳五张核对。
