# 最终分类说明与评分

最终菜单仅在自由描述与固定互动完成后使用。分类依据仍是各组50手公开牌谱，以及预先选择的B、E各10手互动，未读取其他评审、隐藏映射或源码。前两阶段文件已冻结，独立文字勘误保存在errata.md。

| 代号 | 菜单判断 | 置信度 |
|---|---|---:|
| A | 范围纪律 | 0.78 |
| B | 小注持续 | 0.62 |
| C | 宽松取值 | 0.74 |
| D | 多街施压 | 0.77 |
| E | 不确定 | 0.35 |
| F | 小注持续 | 0.60 |

置信度表示当前有限公开样本对标签适配的主观把握，未经统计校准。B与F重复标签是有意保留，不通过剩余标签排除补齐六个风格。E的“不确定”保留均衡、小注控池等候选，但证据不足以稳定选择；不表示E完全没有可描述行为。

A的选择性入池、C的广泛参与与低主动性、D的直接加注和大尺度多街压力最鲜明。B与F都出现前段小注、后段放大的路线，无法从当前证据可靠剥离。E多数等待但少数路线很强，公开底牌又不足。标签菜单对“干燥高牌翻牌”和“安全强牌诱导”等细条件有要求，整体参与量不能替代这些条件下的机会统计，所以没有给出高于0.8的把握。

- 整体可辨认程度：3/5。连续观察能分出若干明显行为，但六代号并不能稳定逐一识别。固定互动只有B三次、E两次共同翻牌，未把最难的一对充分分开。
- 策略交互体验：3/5。会促使我调整价值下注、半诈唬、控池和承受大注的方式，但大量多人池全过，以及少数与牌力脱节的大额支付，削弱了持续对抗的连贯性。
- 是否适合作为训练工具：有条件适合一般公开信息决策练习。适合练人数、位置、底池价格和牌面变化下的行动选择。尚不宜把每个标签当作稳定的对手识别答案，也没有证据验证真人学习提升或最优盈利。

最需改进的是牌力和公共牌变化对应的投入连贯性。比如D40的55在大幅翻前加注后多街支付、F25两对在连通河牌继续重投，需要有能从公开信息解释的范围与价格依据；C8、C35已成顺却过牌则提示价值提取可能不足。单手反例不直接证明规则错误，也不能只因输牌判错。

另一个体验限制是五人桌固定样本里直接目标互动较少。本次固定20手仅5手双方共同翻牌、1手单挑翻牌，我只能诚实保留这个观察缺口。更强的辨认评估应预先设计足够且条件明确的对抗机会，并保持真实连续样本，不能事后挑出特色手来证明风格。

结论只涵盖AI牌谱与策略互动评审，不涵盖UI、真人研究、真人学习效果或最优收益证明。
