# 第二阶段匿名互动评审

## 固定样本与可核验范围

在第一阶段自由评审保存并冻结后，预先选择最难区分的 B、C，固定每个10手。B 为 API 手号1–10，C 为 API 手号11–20。总计20手全部运行到 `phase=done` 后才开始下一手，没有因特色未出现追加。共65个原始公开响应、45次动作请求，逐次对照前一公开状态的 legal 检查，动作、额度和筹码单位均允许。所有响应的原始文本保留在 `interactive-transcript.jsonl` 的 `responseRaw`，同时保存请求和解析后的公开响应。

我按底牌、位置、赔率和公开行动作正常练习决策。没有为了制造反差而用弱牌强行争取大底池。Hero 弃牌后引擎继续公开的行动只算观察证据，不算本人直接对抗。最终底牌仅使用实际未弃牌摊牌者公开的部分。

| 指标 | B的10手 | C的10手 |
|---|---:|---:|
| 与Hero共同进入翻牌 | 3/10（5、6、7） | 3/10（14、16、17） |
| Hero仍在局中时目标翻后决策 | 8次 | 10次 |
| 直接面对Hero翻前加注的决策 | 2次：跟1、弃1 | 2次：跟1、弃1 |
| 直接面对Hero翻后下注的决策 | 0次 | 4次：跟2、弃2 |
| 目标翻后下注时Hero仍在局中 | 1次 | 0次 |
| 目标真实摊牌公开底牌 | 2/10 | 2/10 |

同一手可产生多个决策。“共同进入翻牌”并不保证双方互相下注，因此不能把每组10手说成10次有效施压实验。尤其 B 没有面对本人翻后下注，不能据这批互动声称已验证“B 比 C 更会接注”。

## B的直接体验

互动5：Hero 7♦4♠在小盲便宜补齐，B 大盲过牌。A♥6♣J♣、2♠、Q♥三街大家过牌，B 最后公开4♣2♣。B 翻牌有同花听牌，转牌成2的一对，未主动下注。这更像低成本看牌与保留摊牌价值，不能把翻牌过牌解释为没有后门或没有听牌。

互动6：Hero 5♦3♦在按钮跟入，J♦8♣T♥翻牌双方过牌，T♣转牌 B 向3.5BB底池打2.5BB，另一人弃牌，我也以未成牌弃牌。B 确能在转牌主动施压。但没有亮牌，无法知道是三条、其他价值、听牌还是诈唬。

互动7：Hero Q♥7♥在CO开2.5BB，B大盲跟注，三人进入8♠T♣4♦翻牌。7♣转牌和5♣河牌后一路过牌，B公开 A♥6♦。最佳牌是4、5、6、7、8的8高顺子，已经胜过我的一对7。B 在三张梅花河牌选择过牌，可能在保留摊牌价值、等待身后下注或谨慎控制底池，不能自动判定漏取值错误。不过这次直接互动让我明显感受到：它的河牌过牌范围中仍有成顺强牌，并非只剩高牌或弱对。

互动8发生在我翻前弃牌后，仅为观察：B 面对2BB开局和一位跟注再加到6BB，6♥4♦6♣翻牌过牌跟12BB，5♣转牌面对39BB弃牌。它有翻前反加与转牌及时停止的能力，不能沿用“总是跟到底”的印象。未知牌保持未知。

B 的10手中直接碰到的翻后压力不多，我主要感受到的是等待和小底池。第一阶段关于其接注更多的判断未被这批直接互动检验，不能增加该点置信度。

## C的直接体验

互动14：Hero K♥8♥在大盲跟2BB的多人底池。4♠Q♠4♦翻牌全员过牌，K♠转牌我得到 K、4两对，向8BB底池下注3.5BB，C与另外两人均弃牌。这是一次实际转牌退出，C未亮牌，不能认定它放弃了中强牌或被纯诈唬逼走。

互动16是本批最有内容的直接交锋：C 在CO开2BB，我在按钮用T♠6♠跟入，三人看到8♦3♥9♦。C过牌，我用卡顺听牌打2.5BB，C跟；7♠转牌我成T高顺子，向11.5BB底池下注8BB，C继续跟；A♦河牌完成三张方片，C过牌，我以顺子向27.5BB底池下注12BB，C弃牌。C 的路线为翻前主动、翻牌低价继续、转牌继续、河牌再评估。它并没有在我的较大转牌下注下立即退出，说明第一阶段“转牌较常弃牌”应保留牌面条件和小样本限制。因它没有摊牌，不能把两次跟注说成抓诈或把河牌弃牌说成错弃成牌。

互动17：我以 Q♣T♦在CO开2.5BB，C按钮跟，三人看到J♣5♥2♥。我和 C 在翻牌、4♠转牌均过牌。9♥河牌大盲打4BB，我弃牌后 C 跟4BB，公开 J♠T♣，对方K♥6♥为K高同花，C只有一对J。C 的顶对中等踢脚采用控池后接河牌的路线，既有合理的摊牌价值，也不是“只小注、从不接注”。因为 C 跟注发生在我弃牌之后，此处不计入对我的直接回应次数。

互动19：C按钮隔离到3BB，我持A♦Q♥在大盲再加到12BB，C弃牌。这只增加一次真实面对反加的行为证据，无法确认其开局范围的具体牌。

互动12是我弃牌后的观察证据：C 的 J♠T♣在9♥5♦Q♦翻牌有两头顺听牌，向12BB底池下注3.5BB，约29%；A♦转牌和9♠河牌停下。这个小额半诈唬符合其小尺寸与按牌面继续的感觉，但只有一次，且这不是翻前加注者的持续下注，不应算作“已经观察到大量小持续下注”。

## 互动后的判断

B、C 的“跟入—过牌—后街重新判断”仍明显重叠。C 的小额听牌进攻和实际两街接注提供了新细节，B 的成顺过牌强化了其控池倾向。互动未提供相同牌、位置、下注条件下的对照，也没有足够 B 面对本人下注的机会，因此没有把两者强行拆成互斥类型。

作为策略练习，这些对手能够承接正常选牌、价值下注、控池和面对下注的练习，某些底池会迫使我按公共牌变化更新判断。局限是大量回合的压力较低、关键反加和多街对抗稀少，20手无法证明长期辨认性、盈利性或真人学习效果。本阶段没有 UI、时钟、设备或可视化验收。
