# PR70 多语言问题修正

本次从原始体验报告使用的 PR70 提交 `38337032eacf30eae24fdeb00da07451b1e7a099`
创建独立工作树及 `codex/pr70-language-fixes` 分支，没有混入 PR70 后续提交。

## 用户选择

按 2026-11-06 从报告页面导出的 13 条判断执行。认可的 7 项为 CN-01、CN-02、CN-07、
TW-01、TW-04、TW-05、TW-06；否决的 CN-03a、CN-03c、CN-04a、CN-05、TW-02a、
TW-02b 保留原设计。未标注项仅处理已核对的文案、翻译和布局问题；可选收藏、计算
假设和统计口径不属于这次功能修改。

- 盲注下方直接显示本手之后剩余的手数；不显示级别编号或可展开的下一档金额。
  计数直接读取引擎级别状态，重打不推进级别；封顶和下一手涨盲分别显示对应状态。
- 牌桌提示和可关闭的本手重打标记位于左侧，倒计时位于右侧；关闭仅影响本手提示。
  长译文在右栏内自然换行，左栏为重打文字与关闭按钮保留实际最小宽度，避免遮挡。
  倒计时最多使用原提示行内的两行，关闭标记边框不额外占高；各语言与入桌前后共用行高。
- 切语言重新格式化当前牌桌、设置与已打开复盘的金额，不重发牌或重启计时与分析。
- 底池名单使用对应语言的分隔符；对手翻前加注记录使用完整句式，避免残留中文句号。
  局内动态与复盘按当前语言格式化筹码、百分比与 BB 比例小数，处理拼接句末标点，
  保留正负号、每枚筹码、原有小数位、姓名、网址与牌面。
- 繁中功能名统一使用“覆盤”。净赢为绿色，净亏为粉色，与记录页含义一致。
- 翻译恢复动作、九类牌型、边池资格、退款、重打撤回结算和统计等准确含义。
  日志先翻译完整句子，再插入玩家姓名和位置徽标；保留金额、姓名、牌面和原始规则数据。
- 复盘保留中文源片段，仅在插入界面时翻译一次；活动日志整体翻译后直接安全插入，
  避免日文汉字被再次当作中文短语处理。
- 结算按钮使用紧凑标签，保留完整无障碍名称；参数表保留可读列宽，并在需要时提示横滑。
- 英文座位区用 SB / BB 紧凑标记盲注，完整含义保留在无障碍名称和说明中；
  设置说明使用 Tap 并保留句间空格。
- 短筹码标题不再声称只有两个合法选择；实际判定与推荐算法保持原样。
- 安卓英雄信息行及姓名、筹码子元素使用独立绘制层，处理模拟器 WebView 中观察到的文字压缩；
  不改变行高、字号或桌面几何，不改 iOS 样式与原生硬件加速策略。

## 语言核对来源

本次为 AI 定向审校，以官方规则和术语核对中文源文及应用实际行为；没有直接采用
机器翻译 API 的整段输出，也不代表整个词库已获真人母语认证。逐语言来源、原卡编号
和证据边界记录在以下文件；未触发的分支不能以普通页面截图代替现场复现。

- [英语、西班牙语、意大利语、葡萄牙语](pr70-language-fixes-en-es-it-pt.md)
- [日语、韩语、德语](pr70-language-fixes-ja-ko-de.md)
- [繁中、法语、俄语](pr70-language-fixes-zh-fr-ru.md)

`src/i18n/translation-provenance.json` 记录本次基线及有效译文修改数量。原始草稿翻译
来源仍保留，定向审校不会将全目录的语言审查状态改为通过。
