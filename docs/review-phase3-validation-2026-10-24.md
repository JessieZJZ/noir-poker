# 复盘优化三期 · 2026-10-24

本轮使用当前八种风格和翻前承诺策略，审查的是复盘的行动建议、事实与新手解释。保留自然牌局入口，没有加入产品内情境选择器。详细牌谱、AI反馈、失败原件、冻结源码和运行截图只保存在本机，不提交Git。

## 语料与口径

- 4,000手完整结算，3,200手随机发牌、800手定向场景。5–9人各800手，覆盖入门/标准/进阶、八种风格、关闭/细微/明显三种情绪模式、不同盲注和筹码深度。
- 20类定向场景各40手，包括三同花色暗三条、四同花色三条、四连通牌面、公共最大顺子、低同花听牌、组合听牌、AK/KQ/QQ翻前重注、短全下未重开、多人/边池、过小取值与过度全下等。底牌与未来公共牌仅供构造测试牌序，不进入之前决策的评分。
- 随机发牌不等于所有参与者自主行动。Hero使用生产策略、跟注过牌、施压、谨慎四种测试路线，对手执行生产策略。定向前缀、展示探针与真正生产选择分开标记，不能用定向样本推算自然频率。
- 每手独立种子，基种子202610243。语料复盘使用600次范围评估、12次继续策略试验。默认产品600/40另用16个保存快照定点检查，包含14个Hero数值分析与2个对手纯解释。末轮默认专项实际做过26次数值调用，最终版本通过动作、候选行、数值与源码对应复用，不冒称又做26次。职业视角另对两个不同保存快照各做一次默认600/40生产复现，与这16例分开计数。
- 数值来源与最新呈现来源分别保存。只改措辞、事实分类和候选动作未变的条目保留原数值。真正改变事实、建议动作或有序候选行的条目完整重算。旧analysis.coaching是历史证据，最终显示读取entry.review或presentationAnalysis，不把旧缓存当最新文案。

## 已修正的主要问题

| 问题                                    | 最终处理                                                                                                                               |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 暗三条过牌只叫控池，原因缺失            | 说明三同花色需对手两张同花色底牌、四同花色只需一张，解释为什么先控制投入、可能损失弱牌价值与让对手免费改善。三条仍可改善为葫芦或四条。 |
| 机械警告不可能的四条/较小葫芦           | 根据本人底牌和公共牌排除阻断组合，较弱成牌类别取全部合法未知底牌，不从有限展示例推断存在性。                                           |
| 公共对子贡献的两对被当成私人强两对      | 解释对子来源、踢脚和共享部分，避免用强两对模板自动扩大投入。公共最大顺子说明分池，不虚构更强牌。                                       |
| 正文倡导过牌，末尾却建议下注            | 明确实际行为的取舍与主建议，取值需要较弱牌愿意跟注，不能由危险牌面直接推出必须过牌。                                                   |
| 全下后继续安排本人跟注、再加注          | 本人筹码耗尽后停止未来决策。其他玩家待回应、短全下未重开与覆盖对手筹码分别说明，规则权限仍由引擎判断。                                 |
| 河牌还说等待牌面变化/免费看下一张       | 区分最后行动直接摊牌与后面仍能下注，本轮风险不再写成未来公共牌风险。                                                                   |
| 低花/顺子听牌数字与弃牌建议缺少因果     | 同时说当前摊牌机会、改善候选、脏补牌、多人与后续成本，改善概率不当成全部获胜率。                                                       |
| 弱牌超池全下被包装为保护/强牌无条件取值 | 结合实际金额、较弱继续目标与强继续范围解释尺度，强牌也比较较小投入，正常小下注仍保留保护与取值可能。                                   |
| 已面对下注却建议过牌                    | 按合法条件比较较小加注或跟注，无人下注时才比较过牌。                                                                                   |
| AK被说成可能输给更好高牌踢脚            | 改为顶对顶踢脚潜力与AA/KK、价格和继续范围风险，AQ/KQ确有踢脚压制的对照保留。                                                           |
| 远处翻前过牌遮盖最近连续施压            | 最近连续两街/三街下注优先说明，真实下注—过牌—再下注仍解释停火后重新进攻。                                                              |
| QQ/AK多次加注的总结、条件、练习不一致   | 三处同步核对弱牌跟注取值与仍有筹码对手弃掉更好牌的假设，不统一说成纯诈唬。                                                             |
| 脚本/旧记录被编造策略或情绪动机         | 缺执行依据、动作不符或只记录脚本动作时，用实际牌力、价格和动作客观解释，合法生产执行依据及情绪说明保留。                               |

所有判断只读取行动前本人牌与公开快照。隐藏牌、未来牌和赢家仅在独立规则/账本重放中使用，不能用于解释决策好坏。对照测试包含隐藏牌getter与修改后的结果不变。

## 保留的失败与边界

原始两批各2,000手均写完，但末尾脚本版本保护报错：运行期间审查分组元数据和仅刷新分支的辅助逻辑被更新。两个非零退出和原文件均保留，没有把原任务说成正常全绿。固定源码独立重放4,000手、60,823个行动，全部文件SHA与运行中检查点一致，初始牌序、每个引擎行动及最终结算逐字段一致。没有重新生成Monte Carlo策略提案，也不把规则重放称为新4,000手独立样本。

中途候选、被评审否定的文案、翻译缺项、主动中断的呈现刷新/Web轮次和审查器误报均保留。后续修复有独立的新报告，不覆盖旧失败。审查器错误读取旧analysis.coaching造成的“大推注仍被保护文案包装”误报已撤回，最终呈现的对应修复确实存在。

主建议不是solver最优性证明。低频牌型、真实用户满意度、实体设备与商店/微信上架审核不由这批离线或模拟器检查证明。少量不影响当前合法行动和建议的可读性问题继续标记为P3，未冒称全部表述完美：3206/7有听牌张数和封口表述重复，部分过牌听牌给出张数但没有逐个列点数，三个待回应者筹码只够跟注的自然例被笼统称作“没有重新加注权”，以及低中对子开池的两类收益还可更清晰区分。后面玩家不能再加注的结论本身正确。
