## P1：必须在最终图前修正

1. **同一画面显示两个当前行动者。** 三套桌面与 iOS 9 人牌桌均显示 Knox 高亮且“思考中…”，下方同时显示“轮到你行动”并提供激活的跟注/加注按钮。最终图需要是同一个合法可理解状态。此组建议采用本人回合：取消 Knox 的思考描边和“思考中…”，改成上一手公开行动；只高亮本人或行动栏。视频在对手思考时应禁用本人行动按钮，并在轮到本人时统一切换。
2. **桌面 9 人桌同时显示两个 BTN。** Vale 的名字旁是 BTN，本人标签也为 BTN；同桌角色标记必须唯一。建议保留本人 BTN，按顺时针依次把下一座设为 SB、再下一座 BB，并去掉 Vale 的 BTN。手机隐藏了小标记，不能因此放过桌面错误。
3. **B 方案中文标题依赖系统宋体。** CSS 使用 `Georgia, 'Songti SC', serif`，截图中的宋体来自系统；这不能作为 iOS、Android、微信一致还原依据。建议本轮改为本地 Noto，使用较轻字重和 0.04–0.06em 字距区分 B；若坚持宋体，需要本地合法字体和微信包预算，并重新输出所有参考图。此项是交付一致性问题，而非否定宋体气质。

## P2：视觉优化后复核

4. **共用：移动 9 人桌字号偏小。** CSS 风格名/座位行动为 8px，姓名和筹码为 10px。在 393px 宽原图中必须靠近放大才容易辨识。建议姓名/筹码至少 11px、风格/行动至少 10px；可略减少头像到 22–23px，保留牌面≥34px，座位块增高到54px。若长风格省略，需要完整名称入口。不要把中心卡牌再放大挤压座位。
5. **C：轮廓体系跨页面不统一。** 极夜牌手框是方形，手机设置与复盘外卡片仍是 12px 圆角，与 A 几乎相同。建议在移动断点之后追加 polar 的 content-card / review-content / practice / table-wrap / style-card 的 6–8px 圆角，弱化圆润私人会所气质。A 保留12–16px，B使用6–8px。
6. **B：桌布出现较强橄榄黄色。** 目前牌桌整体比牌面和主行动更吸睛，私享感转向黄绿桌布。建议大面积底色向炭黑暖灰收，顶光保留暖金，金色主要留在外轨和主按钮。牌面暖象牙已经足够表达方向。
7. **共用：素材角色的辅助名色偏灰。** 9人桌公开行动可适度提高文字亮度，尤其已弃牌、思考、跟注不可因为背景材质而消失。不要用强光晕代替文字可读性。
8. **已知问题：home indicator 出现在长截图正文中间。** parent 已发现并安排修复。本轮仍记录：复盘的总结句、设置分组标题、本局练习均被系统手势条横线盖住，最终图必须消除。长图需要平台壳与文档内容分离，不能在正文中留下系统控件。

## 内容准确性转交

读取原型源码时还发现底池示例称“你 A 一对赢主池，Knox K 一对赢你也参与的边池”，同一公共牌与双方参与资格下不成立。建议调整成你仅参与主池、边池由另两位参与，且确保奖励、退还与总额相符。此项已告知 parent，交由 UX/规则审阅，不将 UI 原图效果等同于真实引擎行为。

## 保留的优点

三套原图都保持了清楚的卡牌黑红花色、主行动内完整金额、足够安静的背景、现有原创角色和共同页面信息结构。正文复盘已有“按当时信息判断”的边界，输赢与决策评价的色彩没有直接混淆。方案差异已体现在牌面、桌边、头像框、标题，而非仅更换主色。下一轮优先修正 P1 与小屏字号，再复核原图，不建议增加额外粒子或持续光效。
