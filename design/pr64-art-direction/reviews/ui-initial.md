## 所有方向共同遵守的 UI 层级

1. 牌桌首屏的视觉注意力依次为公共牌与本人牌、当前金额/应跟金额、主行动、对手公开行动、局号盲注，最后才是装饰。
2. 保留中轴椭圆桌与下方本人位置。桌面右侧为练习/动态；移动端把辅助信息放到牌桌下方可滚动区域，不能挤压行动区。
3. 不用持续发光、漂浮粒子、镜头晃动或大面积雾气制造沉浸；用桌布微纹、顶部光、接触阴影、筹码厚度和声音空间感完成。
4. 数值使用 Manrope 的 tabular-nums；中文使用 Noto Sans SC。主品牌、正文、牌面均复用本地字体，不新增依赖网络的字体。文字可读性胜过材质表现。
5. 用户已确认的原创角色插画不替换；头像使用统一裁切与细描边。思考/当前行动用清晰描边+文字表达，避免只靠颜色。
6. 弃牌、跟注、加注均保持固定位置与稳定大小。主要行动最低 48px；加注金额在按钮内完整显示，筹码和盲注不缩写到无法判断。
7. 赢家可用金色小皇冠和+筹码；复盘的建议/代价/条件用语义标签，不把输赢直接映射为行动质量。

## 全页面应用方式

- 启动：品牌黑桃+单次低亮度光晕，首屏不建立额外启动流程。
- 待入座：牌桌、对手围桌、中心入座 CTA，保留虚拟筹码/本地练习说明；不做登录/大厅/广告。
- 行动中：材质主要集中在桌面和卡牌；辅助面板低对比，轮到本人时仅行动栏和本人边框提亮。
- 摊牌与结算：保留牌桌几何，按赢家→奖励→最佳五张牌排序。不可同时让所有对手闪烁。
- 本局结束：冠军/出局分别表现；不以负向大红渲染普通输牌。
- 对局记录：按局分组、最新优先，数字对齐，手牌缩略图保留花色文字；整行可点击。
- 历史牌局：显示只读身份与日期，返回上下文清楚，不伪装可继续下注。
- 我的复盘：宽屏时间线左侧+正文右侧，手机时间线横向/上方；先结论再信息和练习重点。
- 对手复盘：以具名角色与公开牌面建立关联，明确估计边界，保留按需分析状态。
- 设置：声音/音乐/振动与对手、人数、盲注分区；待下一手生效提示必须邻近发生变化的控件。
- 角色资料：大头像与风格在上，观察与应对分块，不出现真人履历；风格差异用文字说明。
- 指南/牌力表/术语：降低装饰、提高行距，标题目录固定且可回到牌桌。
- 底池：主池/边池分卡，先奖励归属再参与者明细，金额对齐。
- 重置确认：标题解释结果，取消按钮仍清楚可用；不让金属/发光主按钮掩盖风险。
- 关于/隐私：沿用信息页面系统，清楚说明本地存储和虚拟筹码。
- 横屏提示：仅手机显示旋转提示；平板需要根据可用内容尺寸决定布局，不把所有横屏视为不支持。

## 跨端一致性与小屏边界

桌面 1440×900、平板 1024×1366、移动 Web 390×844、iOS 393×852、Android 412×915、微信 393×852 分别输出参考。系统栏/胶囊/底部安全区必须是不同平台壳，内容 token 与组件相同。微信无语言设置，其他端保留语言入口。手机主行动在手势区之上，系统返回/弹层关闭在顶部保持44px触区。

五至九人桌需要独立验证；九人桌不得通过过度放大中心牌挤压座位。卡牌宽度至少34px，主要金额与行动仍清晰。最长风格标签允许省略，但长按/点击展开完整名称的入口不能丢。设置与复盘正文可滚动，底部 CTA 不能遮住正文。

## 动效与声音建议

A：320ms 翻牌、280ms 筹码入池、600ms 获胜柔光；B：360ms 翻牌、300ms 筹码厚实滑动、750ms 细金边点亮；C：240ms 翻牌、220ms 筹码轨道移动、450ms 单次蓝色回合描边。各方案保留用户已选“原视频节奏”筹码声，可通过混音的空间感表现差别，但不更改批准的节奏素材。演示视频必须有可辨认的声音轨，注明预览音量与耳机建议。静音、减少动态均提供降级，动作取消遵循下一手/重打/重置/后台原有语义。

## 第一轮交付前核验重点

每套方案至少看一张桌面、手机主牌桌、复盘和设置原图。检查牌面/数字对比、字号、行动优先级、风格区别、材料噪声、移动安全区、整体页面一致性。缺失页面或只换色不能称完整方案。
