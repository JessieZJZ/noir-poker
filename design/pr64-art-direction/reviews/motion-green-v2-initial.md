## 新一轮的核心变化

主牌桌、主行动、背景氛围统一进入绿色家族。三方案的区别主要来自房间、灯光、桌边与卡筹材质，而非把主色改成金色或蓝色。情绪四种颜色、强牌轻紫色语义和冠军小面积金色可以作为已存在的反馈语义保留，不能成为整屏主色。

沉浸感应同时来自“有厚度的物体在桌面上运动”和房间纵深。新room后景只是底层；实际动态必须包括：卡牌从牌堆到座位、卡面翻转与牌边厚度、玩家筹码到下注区、各下注区收至底池、获胜五张牌高亮与牌型文字、底池筹码移到赢家。

镜头、牌桌、按钮与本人位置保持稳定，避免镜头缩放或漂移取代真正的牌筹运动。

| 轮到本人     | 160–220ms显现，之后静止                                              | 本人牌与行动区薄绿边、短亮点；按钮位置不动，跟注价格和加注至金额优先                             | 不让其他玩家同时处于“本人行动”高亮                                                        |

| 单手赢家高亮 | 120–180ms提亮，保留约800–1100ms                                      | 最佳五张牌边缘绿光＋一次表面反光，其他牌仅降低约25%饱和度；本人获胜牌增加清楚的厚度与接触阴影    | 最佳五张来自既有结算结果，不能硬编码“所有牌都亮”或用最终赢家评价复盘                      |

| 筹码发给赢家 | 高亮出现后约900ms开始，320–420ms飞行，180–240ms数值归位              | 底池堆沿短弧线收至获胜者筹码锚点；到达时显示实际奖励与更新后的余额；这是单手结算的第二个明显高潮 | 发奖/退款金额直接读取引擎；多赢家按实际份额分支；中间显示也按本局筹码单位对齐；不重复结算 |

卡牌厚度建议为桌面约2px、手机约1–1.5px的可辨侧边，正面暖白、底边略暗；靠接触阴影与边缘高光表达厚度，不能把牌做成厚重按钮。筹码以浅绿/深绿面额与简洁白色切口构成，正面、边缘和堆叠阴影分层。房间亮度应低于台面，台面亮度低于卡面，保证画面主次。

以上时序是设计目标，不改变当前规则引擎或合法行动判断。A/B/C允许小幅速度差异，语义顺序、路径起终点、终态和金额保持一致。

## 与已有效果的衔接

已读取当前共享常量：强牌延迟1150ms、紫光2600ms；补码1300ms；金冠2300ms；撒花3800ms；出局2800ms。

- 强牌：保留牌缘与少量向外火花，只在本人起手牌附近播放完整2.6秒；不要以整屏紫雾压过绿色场景，也不能暗示必胜。
- 四类情绪：保留橙火焰/蓝盾牌/金星星/红闪电及各自环动，房间加深后降低光晕半径，让图标与头像仍清楚。稳定状态不显示环。
- 补码：保留1.3秒上浮金额与计数，先准备下一手再恢复行动；计数不得改变引擎筹码。
- 冠军：保留2.3秒升冠/飞冠和3.8秒双侧撒花，场景局部压暗；金光集中于金冠和获胜本人，不把所有绿桌材质刷成黄色。
- 出局：保留2.8秒灰卡与淡环，不用红色爆炸、破碎牌或强失败惩罚表现。
- 区分单手赢家与本局冠军：单手用牌面、牌型和筹码发奖；金冠和全屏撒花只属于本局冠军。

## 声音

继续使用已经批准的 NOIR 510ms筹码PCM、当前发牌/过牌/获胜提示和背景音乐母带；冠军/出局使用现有 `ceremonySamples`。不提取或复制参考视频声音。

- 筹码声与主筹码堆落桌/到达同步，每次实际下注或收筹码最多一个主要碰撞声，不能为每一颗筹码重复播放。
- 单手win提示与赢家高亮对齐；派奖音若与win重叠，应沿用共享限幅，不突然压低背景音乐。
- 2.4秒音乐入场渐入和独立音乐/音效偏好保留。样片记录PCM来源、混音峰值及AAC解码后的峰值，不能把文件测量称为实体手机听感。

## 新视频建议：36秒反馈片段合集

| 片段           | 时段   | 必须实际看到                                      |
| -------------- | ------ | ------------------------------------------------- |
| 发牌与落桌     | 0–3s   | 两轮牌从发牌点到各座位，本人翻面与侧边厚度        |
| 翻牌与卡面质感 | 3–6s   | 牌背→侧边→正面，桌面接触阴影                      |
| 本人行动       | 6–9s   | 价格、行动区、本人牌同时建立清晰关系              |
| 下注入桌       | 9–12s  | 玩家筹码锚点→该玩家下注区，原筹码节奏             |
| 街末收池       | 12–15s | 多个下注区→中心底池，明确的实际运动               |
| 摊牌           | 15–18s | 真实摊牌牌面翻开，输家仍可读                      |
| 单手赢家与派奖 | 18–22s | 最佳五张牌高亮、牌型文字、中心筹码→赢家、金额归位 |
| 强起手牌       | 22–25s | 既有2.6秒完整语义                                 |
| 四类情绪       | 25–27s | 四种图标/环的差异                                 |
| 补码           | 27–29s | 上浮金额、对齐本局筹码单位的计数                  |
| 本局冠军       | 29–33s | 完整冠与撒花                                      |
| 本局出局       | 33–36s | 完整灰卡淡出                                      |

这些是各独立状态的反馈样例，不伪装为一手连续合法牌局。每套提供桌面/iOS片，最终再做三方案同时间线并排片，仅用一条声音轨。正式渲染前先给UI/UX查看强度关键帧；主视觉冻结后再渲全片。

## 跨端与审阅门槛

- 路径依据同一可用牌桌矩形、座位与底池锚点归一化，不能在所有端硬编码相同130px位移；iOS/Android安全区与微信胶囊不参与台面坐标。
- 手机5–9人保留3+2公共牌，运动路径避开玩家信息框、本人牌与操作区。卡牌落定后牌面和金额不因动画仍处于模糊状态。
- 后台、换手、重打、重置与页面退出立即取消旧效果。恢复前台不能突然继续上手筹码飞行；视觉计数不得再次发奖。
- 减少动态时直接显示已确定的终态、赢家描边与金额；关闭音效时无静音后残留回调；不引入新闪烁。
- 验收除逐页静态图外，必须检查：发牌中间帧、筹码半途、最佳五张与未选中牌、牌型文字不遮牌、派奖前后金额、平分/边池/退款分支、5–9人路径、安全区。
- 本轮没有完成任何新v2视频、原生安装版或微信实际运行验收。报告只定义候选动效和后续审阅标准。
